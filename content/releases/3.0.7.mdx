We implemented `TraditionalForm`, which was missing in WLJS. Under the hood, it attempts to convert expressions to LaTeX and render them in the output.

## Settings Hot Reload & Dark Mode Update
Now you don't have to restart WLJS every time you change a setting (for the most part). All open notebooks will automatically reload once you change something.

In addition, we added contrast and brightness adjustments for dark mode, so you can tune it continuously until it feels comfortable for your eyes.


![](./attachments/Screenshot-2026-06-03-at-16.55.40-ddd.png)

## Window Manager Refactor & Offscreen Rendering
We simplified and improved many things in our codebase. `Rasterize` and many other system features no longer require open windows and work seamlessly in the background. However, for most users, this will not make a huge difference; for future maintenance and advanced WLJS usage, it makes a big difference.

If you are using the WLJS desktop application, try:

<WLJSWrapper><wljs-editor display="codemirror" type="Input" editable="true"  >{`Rasterize[Plot[x, {x,0,1}]]`}</wljs-editor></WLJSWrapper>

`CellPrint` no longer requires additional parameters when used without an evaluation context, for example inside a `Button`.

<WLJSWrapper><wljs-editor display="codemirror" type="Input" editable="true"  >{`Button["Print", CellPrint[RandomColor[]]]`}</wljs-editor></WLJSWrapper>

## MCP Update
With help from @Hachann, we significantly improved tools for AI agents and reduced token consumption.

## AF Update
The animation framework got an update. It is more stable and renders animations for export fully offscreen at up to 2K resolution, using native NodeJS I/O to write frames to disk and bypass the Wolfram Kernel entirely.
