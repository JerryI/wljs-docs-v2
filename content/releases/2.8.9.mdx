## Create, open, save and evaluate external notebooks
We completed the implementation of Notebook API to the point, where you can safely:

### Import and evaluate
Import a WLN notebook from a file and then evaluate it (only initialization cells) and collect the last output cell:

<WLJSWrapper><wljs-editor display="codemirror" type="Input" editable="true"  >{`pianoNotebook = NotebookOpen[FileNameJoin[{"attachments", "Piano.wln"}], Visible->False];

## NextJS & MDX Export
We improved our integration with Next.js & React system. Now all assets are served statically within the library: no CDNs, everyhting is local. And Tailwind framework is no longer required! 

Check it out:

- [wljs-notebook-react](https://github.com/WLJSTeam/wljs-notebook-react)
- [wljs-nextjs-example](https://github.com/WLJSTeam/wljs-nextjs-example)

## Minor Bug Fixes
- The `Triangle` and `StadiumShape` symbol is missing its graphical representation.
- `Tooltip` was not rendered inside `Graphics`.
- The copying button was missing in the cell properties.
- There was a bug with printing slide cells.
- Automatic cache flushing occurs after an update.
