## TeXView
We added a shorthand symbol for rendering expressions as $\LaTeX$:

<WLJSWrapper><wljs-editor display="codemirror" type="Input" editable="true"  >{`TeXView[1/2]`}</wljs-editor></WLJSWrapper>

or directly on LaTeX string:

<WLJSWrapper><wljs-editor display="codemirror" type="Input" editable="true"  >{`TeXView["\\\\frac{1}{2}"]`}</wljs-editor></WLJSWrapper>

It works on slides, markdown and in a normal Wolfram output cells.

## Tooltip
A multitool for labelling data on plots or any other expressions:

<WLJSWrapper><wljs-editor display="codemirror" type="Input" editable="true"  >{`Tooltip[x, Graphics[Disk[], ImageSize->100]]`}</wljs-editor></WLJSWrapper>

A tooltip can be used on graphics primitives as well

<WLJSWrapper><wljs-editor display="codemirror" type="Input" editable="true"  >{`Plot[{Tooltip[Sin[x], "This is sine"], Tooltip[Cos[x], "This is cosine"]}, {x,0,2Pi}]`}</wljs-editor></WLJSWrapper>

Moreover it supports `Offload`, that means you can make it dynamic manually or automatically:

<WLJSWrapper><wljs-editor display="codemirror" type="Input" editable="true"  >{`Animate[ArrayPlot[
	  SeedRandom[123];
	  Table[Evaluate[Sum[Sin[RandomReal[10, 2] . {x, y} + t], {5}]], {x, 0, 
	   5, .1}, {y, 0, 5, .1}], ImagePadding->None], {t,0,8Pi, 0.1}, RefreshRate->60]`}</wljs-editor></WLJSWrapper>

Here is another example:

<WLJSWrapper><wljs-editor display="codemirror" type="Input" editable="true" fade="true" >{`rasterDensityPlotAnim[f_, {xs_, xmin_, xmax_}, {ys_, ymin_, ymax_}, {ts_, tmin_, tmax_}, OptionsPattern[]] := 
	 With[{
	   time = Unique[], buffer = Unique[], 
	   cf = With[{c=ColorData[OptionValue[ColorFunction]]}, (List@@c[#])&], 
	   pts = OptionValue[PlotPoints]//N,
	   dt = (tmax-tmin)/OptionValue[PlotPoints]//N
	  },
	  {
	   raw := Table[
	    f /. {xs -> j, ys -> i, ts -> time} // N, {i, ymin, 
	     ymax, (ymax - ymin)/(pts - 1)}, {j, xmin, 
	     xmax, (xmax - xmin)/(pts - 1)}]
	  },
	  
	  time = tmin;
	   
	  buffer = Map[cf, raw // Rescale, {2}];
	  
	  Graphics[{
	    Raster[buffer//Offload, {{xmin, xmax}, {ymin, ymax}}],
	    EventHandler[AnimationFrameListener[buffer//Offload], Function[Null,
	      buffer = Map[cf, raw // Rescale, {2}];
	      time = If[time >= tmax, tmin, time + dt];
	    ]]
	  }, Frame->True]
	]
	
	Options[rasterDensityPlotAnim] = {ColorFunction->"AvocadoColors", PlotPoints->100};`}</wljs-editor></WLJSWrapper>
