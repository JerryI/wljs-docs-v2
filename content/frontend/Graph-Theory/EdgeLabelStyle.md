---
title: EdgeLabelStyle
---

`EdgeLabelStyle` is an option and property for `Graph` and related functions that specifies the style to use for edge labels.

## Examples

Style edge labels:

```wolfram
Graph[{1 -> 2, 2 -> 3}, EdgeLabels -> "Name", EdgeLabelStyle -> Red]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EdgeLabelStyle.html) for more details.*
