---
title: EdgeCapacity
---

`EdgeCapacity` is an option and annotation for `Graph` and related functions that specifies an edge capacity.

## Examples

Create graph with edge capacities:

```wolfram
Graph[{1 -> 2, 2 -> 3}, 
  EdgeWeight -> {1 -> 2 -> 5, 2 -> 3 -> 3}]
```

Used in network flow calculations.

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EdgeCapacity.html) for more details.*
