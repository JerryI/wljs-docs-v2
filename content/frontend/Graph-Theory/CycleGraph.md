---
title: CycleGraph
---

`CycleGraph[n]` gives the cycle graph C_n with n vertices connected in a cycle.

## Examples

Create cycle graphs:

```wolfram
CycleGraph[6]
(* Hexagonal cycle *)
```

Triangle (3-cycle):

```wolfram
CycleGraph[3]
```

Edge count equals vertex count:

```wolfram
EdgeCount[CycleGraph[10]]
(* 10 *)
```
