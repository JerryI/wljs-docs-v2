---
title: PathGraphQ
---

`PathGraphQ[g]` yields True if the graph g is a path and False otherwise.

## Examples

```wolfram
PathGraphQ[PathGraph[{1, 2, 3, 4}]]
(* True *)
```

```wolfram
PathGraphQ[CycleGraph[4]]
(* False *)
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PathGraphQ.html) for more details.
