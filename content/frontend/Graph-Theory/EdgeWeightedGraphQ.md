---
title: EdgeWeightedGraphQ
---

`EdgeWeightedGraphQ[g]` yields `True` if the graph g is an edge-weighted graph and `False` otherwise.

## Examples

Check if a graph has edge weights:

```wolfram
EdgeWeightedGraphQ[Graph[{1 -> 2}, EdgeWeight -> {5}]]
```
