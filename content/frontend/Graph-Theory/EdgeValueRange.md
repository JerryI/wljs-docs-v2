---
title: EdgeValueRange
---

`EdgeValueRange` is an option for `GeoGraphValuePlot` that specifies the range of edge values to include in a plot.

## Examples

Specify edge value range:

```wolfram
GeoGraphValuePlot[data, EdgeValueRange -> {0, 100}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EdgeValueRange.html) for more details.*
