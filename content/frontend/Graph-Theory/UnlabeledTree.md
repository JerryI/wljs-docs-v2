---
title: UnlabeledTree
---

`UnlabeledTree[tree]` returns a tree of the same shape as tree in which the nodes and edges are displayed without labels.

## Examples

```wolfram
tree = Tree[a, {Tree[b, {c, d}], e}];
UnlabeledTree[tree]
```
