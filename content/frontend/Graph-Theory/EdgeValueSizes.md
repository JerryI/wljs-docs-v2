---
title: EdgeValueSizes
---

`EdgeValueSizes` is an option for GeoGraphValuePlot that specifies the thicknesses used to show edge values in a plot.

## Examples

Specify custom edge value sizes:

```wolfram
GeoGraphValuePlot[data, EdgeValueSizes -> {1, 5}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EdgeValueSizes.html) for more details.*
