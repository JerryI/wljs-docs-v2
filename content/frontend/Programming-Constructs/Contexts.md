---
title: Contexts
---

`Contexts[]` gives a list of all contexts.

`Contexts["string"]` gives a list of the contexts that match the string.

## Examples

List all contexts matching a pattern:

```wolfram
Contexts["System`*"]
```

Get all available contexts:

```wolfram
Length[Contexts[]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Contexts.html) for more details.*
