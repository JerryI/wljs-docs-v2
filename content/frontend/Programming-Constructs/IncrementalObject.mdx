---
title: IncrementalObject
---

```wolfram
IncrementalObject[type][args]
```

creates an object that returns values one at a time according to the incremental object `type`. This can avoid constructing a complete result in memory.

## Example

```wolfram
obj = IncrementalObject["Identity"][{val[1], val[2]}];

NextValue[obj]
NextValue[obj]
```

When no values remain, [NextValue](../Programming-Constructs/NextValue) returns a failure object.

See the official [Wolfram Language reference](https://reference.wolfram.com/language/ref/IncrementalObject.html) for available incremental object types.
