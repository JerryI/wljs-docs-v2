---
title: ExceptionTypeRegisteredQ
---

```wolfram
ExceptionTypeRegisteredQ[sym]
```

returns `True` when `sym` is registered as a symbolic exception type, and `False` otherwise.

## Example

```wolfram
RegisterExceptionType[FileReadError];
ExceptionTypeRegisteredQ[FileReadError]
```

Use [ExceptionTypes](../Programming-Constructs/ExceptionTypes) to list registered types and their subtypes.

See the official [Wolfram Language reference](https://reference.wolfram.com/language/ref/ExceptionTypeRegisteredQ.html) for more details.
