---
title: Clear
---

`Clear[s1, s2, ...]` clears values and definitions for the symbols.

## Examples

Clear a variable:

```wolfram
x = 5;
Clear[x]
x
(* x *)
```

Clear multiple symbols:

```wolfram
Clear[f, g, h]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Clear.html) for more details.*
