---
title: Set
---

`lhs = rhs` evaluates rhs and assigns the result to be the value of lhs.

## Examples

Assign a value:

```wolfram
x = 5
x
(* 5 *)
```

Multiple assignments:

```wolfram
{a, b} = {1, 2}
a
(* 1 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Set.html) for more details.*
