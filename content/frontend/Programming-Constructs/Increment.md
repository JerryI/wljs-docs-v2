---
title: Increment
---

`x++` increases the value of x by 1, returning the old value of x.

## Examples

Post-increment:

```wolfram
x = 5;
x++
(* 5 *)
x
(* 6 *)
```

In a loop:

```wolfram
i = 0;
While[i++ < 3, Print[i]]
```
