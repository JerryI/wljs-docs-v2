---
title: UnmanageObject
---

`UnmanageObject[man]` takes ownership of memory wrapped in a managed object.

## Examples

```wolfram
obj = CreateManagedLibraryExpression["myExpr", head];
UnmanageObject[obj]
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/UnmanageObject.html) for more details.
