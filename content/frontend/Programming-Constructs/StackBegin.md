---
title: StackBegin
---

`StackBegin[expr]` evaluates expr, starting a fresh evaluation stack.

## Examples

```wolfram
StackBegin[1 + 2]
```

```wolfram
StackBegin[Stack[_]]
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/StackBegin.html) for more details.
