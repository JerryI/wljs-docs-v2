---
title: Print
---

`Print[expr]` prints expr as output.

## Examples

Print a message:

```wolfram
Print["Hello, World!"]
(* Hello, World! *)
```

Print multiple expressions:

```wolfram
Print["x = ", 5]
(* x = 5 *)
```
