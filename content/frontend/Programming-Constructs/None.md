title: None
---

`None` is a setting used for certain options to indicate no value or disabled feature.

## Examples

Disable frame on a plot:

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, Frame -> None]
```

Check for None:

```wolfram
result = None;
result === None
(* True *)
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/None.html) for more details.
