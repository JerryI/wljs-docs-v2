---
title: MathieuS
---

`MathieuS[a, q, z]` gives the odd Mathieu function with characteristic value a and parameter q.

## Examples

Compute Mathieu S function:
```wolfram
MathieuS[1, 0.5, Pi/4]
```

Plot the function:
```wolfram
Plot[MathieuS[1, 2, z], {z, 0, 2 Pi}]
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MathieuS.html) for more details.
