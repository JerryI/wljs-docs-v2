---
title: PrimePowerQ
---

`PrimePowerQ[expr]` yields True if expr is a power of a prime number, and yields False otherwise.

## Examples

Test if a number is a prime power:

```wolfram
PrimePowerQ[8]
(* True *)
```

Test a non-prime power:

```wolfram
PrimePowerQ[12]
(* False *)
```
