---
title: SpheroidalS2
---

`SpheroidalS2[n, m, γ, z]` gives the radial spheroidal function of the second kind.

## Examples

Evaluate a spheroidal function of the second kind:

```wolfram
SpheroidalS2[2, 1, 0.5, 1.5]
(* -0.326547 *)
```

Plot the function:

```wolfram
Plot[SpheroidalS2[2, 0, 1, z], {z, 1, 3}]
```
