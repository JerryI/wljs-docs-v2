---
title: Reals
---

`Reals` represents the domain of real numbers, as in x∈Reals.

## Examples

Solve over the reals:

```wolfram
Solve[x^2 == 2, x, Reals]
(* {{x -> -Sqrt[2]}, {x -> Sqrt[2]}} *)
```

Test membership:

```wolfram
Element[Pi, Reals]
(* True *)
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Reals.html) for more details.
