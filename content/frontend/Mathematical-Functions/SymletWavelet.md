---
title: SymletWavelet
---

`SymletWavelet[]` represents the Symlet wavelet of order 4.

- `SymletWavelet[n]` represents the Symlet wavelet of order n.

## Examples

Default Symlet wavelet:

```wolfram
SymletWavelet[]
```

Symlet of order 8:

```wolfram
SymletWavelet[8]
```

Plot the wavelet:

```wolfram
WaveletPsi[SymletWavelet[4], {x, 0, 8}]
```
