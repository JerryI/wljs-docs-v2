`MathieuGroupM24[]` represents the sporadic simple Mathieu group M24.

## Examples

Create the group:

```wolfram
MathieuGroupM24[]
```

Group order:

```wolfram
GroupOrder[MathieuGroupM24[]]
(* 244823040 *)
```

Group elements:

```wolfram
GroupElements[MathieuGroupM24[], 5]
```
