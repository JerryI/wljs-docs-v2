---
title: LeviCivitaTensor
---

`LeviCivitaTensor[d]` gives the d-dimensional Levi-Civita totally antisymmetric tensor.

## Examples

3D Levi-Civita tensor:

```wolfram
LeviCivitaTensor[3]
```

2D case:

```wolfram
LeviCivitaTensor[2] // Normal
(* {{0, 1}, {-1, 0}} *)
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LeviCivitaTensor.html) for more details.
