---
title: PaulWavelet
---

`PaulWavelet[]` represents a Paul wavelet of order 4.

- `PaulWavelet[n]` represents a Paul wavelet of order n.

## Examples

Default Paul wavelet:

```wolfram
PaulWavelet[]
```

Order 8 Paul wavelet:

```wolfram
PaulWavelet[8]
```

Plot the wavelet:

```wolfram
WaveletPsi[PaulWavelet[], {x, -5, 5}]
```
