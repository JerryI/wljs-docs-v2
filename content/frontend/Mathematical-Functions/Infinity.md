title: Infinity
---

`Infinity` or `∞` is a symbol that represents a positive infinite quantity.

## Examples

Use in limits:

```wolfram
Limit[1/x, x -> 0, Direction -> -1]
(* Infinity *)
```

In sums:

```wolfram
Sum[1/n^2, {n, 1, Infinity}]
(* Pi^2/6 *)
```
