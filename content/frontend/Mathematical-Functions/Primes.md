---
title: Primes
---

`Primes` represents the domain of prime numbers, as in x∈Primes.

## Examples

Test if a number is prime:

```wolfram
7 ∈ Primes
(* True *)
```

Find primes in a range:

```wolfram
Select[Range[20], # ∈ Primes &]
(* {2, 3, 5, 7, 11, 13, 17, 19} *)
```
