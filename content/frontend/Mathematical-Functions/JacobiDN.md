---
title: JacobiDN
---

`JacobiDN[u, m]` gives the Jacobi elliptic function dn(u|m).

## Examples

Compute Jacobi DN:
```wolfram
JacobiDN[0.5, 0.3]
```

Plot the function:
```wolfram
Plot[JacobiDN[x, 0.5], {x, 0, 10}]
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/JacobiDN.html) for more details.
