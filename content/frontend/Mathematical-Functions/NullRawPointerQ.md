---
title: NullRawPointerQ
---

`NullRawPointerQ[ptr]` gives True if ptr is a null pointer, and False otherwise.

## Examples

```wolfram
NullRawPointerQ[ToRawPointer[]]
```

```wolfram
NullRawPointerQ[ptr]
```
