---
title: EulerE
---

`EulerE[n]` gives the Euler number E_n. `EulerE[n, x]` gives the Euler polynomial E_n(x).

## Examples

Euler numbers:

```wolfram
Table[EulerE[n], {n, 0, 6}]
(* {1, 0, -1, 0, 5, 0, -61} *)
```

Euler polynomial:

```wolfram
EulerE[2, x]
(* x^2 - x *)
```
