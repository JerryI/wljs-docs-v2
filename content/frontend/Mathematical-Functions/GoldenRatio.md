title: GoldenRatio
---

`GoldenRatio` is the golden ratio φ = (1 + √5)/2, with numerical value ≈ 1.61803.

## Examples

Numerical value:

```wolfram
N[GoldenRatio]
(* 1.61803 *)
```

Golden ratio property:

```wolfram
GoldenRatio^2 - GoldenRatio - 1 // Simplify
(* 0 *)
```
