title: EulerGamma
---

`EulerGamma` is Euler's constant γ, with numerical value ≈ 0.577216.

## Examples

Numerical value of Euler's constant:

```wolfram
N[EulerGamma]
(* 0.577216 *)
```

Use in expressions:

```wolfram
Limit[Sum[1/k, {k, 1, n}] - Log[n], n -> Infinity]
(* EulerGamma *)
```
