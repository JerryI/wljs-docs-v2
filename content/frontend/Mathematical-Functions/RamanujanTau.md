---
title: RamanujanTau
---

`RamanujanTau[n]` gives the Ramanujan τ function τ(n).

## Examples

First few values:

```wolfram
Table[RamanujanTau[n], {n, 1, 10}]
(* {1, -24, 252, -1472, 4830, ...} *)
```

Verify the first value:

```wolfram
RamanujanTau[1]
(* 1 *)
```

Famous value at n=2:

```wolfram
RamanujanTau[2]
(* -24 *)
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RamanujanTau.html) for more details.
