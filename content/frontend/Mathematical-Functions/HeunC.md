---
title: HeunC
---

`HeunC[q, α, γ, δ, ϵ, z]` gives the confluent Heun function.

## Examples

```wolfram
HeunC[1, 2, 3, 4, 5, 0.5]
```

```wolfram
Plot[HeunC[1, 1, 1, 1, 1, x], {x, 0, 1}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/HeunC.html) for more details.*
