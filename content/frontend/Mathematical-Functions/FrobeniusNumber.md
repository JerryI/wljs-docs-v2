---
title: FrobeniusNumber
---

`FrobeniusNumber[{a1, ..., an}]` gives the Frobenius number of a1, ..., an.

## Examples

Find the Frobenius number for two values:

```wolfram
FrobeniusNumber[{3, 5}]
```

For three values:

```wolfram
FrobeniusNumber[{6, 9, 20}]
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/FrobeniusNumber.html) for more details.
