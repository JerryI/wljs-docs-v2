---
title: MandelbrotSetPlot
---

`MandelbrotSetPlot[{zmin, zmax}]` plots the portion of the Mandelbrot set inside the rectangle with corners zmin and zmax.

`MandelbrotSetPlot[]` plots the Mandelbrot set over a default rectangle.

## Examples

Plot the Mandelbrot set:

```wolfram
MandelbrotSetPlot[]
```

Zoom into a region:

```wolfram
MandelbrotSetPlot[{-0.5 + 0.5 I, 0.5 + I}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MandelbrotSetPlot.html) for more details.*
