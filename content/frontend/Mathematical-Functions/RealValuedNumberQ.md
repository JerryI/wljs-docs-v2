---
title: RealValuedNumberQ
---

`RealValuedNumberQ[expr]` returns True if expr is a number with a real value and False otherwise.

## Examples

```wolfram
RealValuedNumberQ[3.14]
```

```wolfram
RealValuedNumberQ[2 + 3 I]
```
