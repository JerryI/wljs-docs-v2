---
title: RealAbs
---

`RealAbs[x]` gives the absolute value of the real number x.

## Examples

Get the absolute value of a negative number:

```wolfram
RealAbs[-5]
(* 5 *)
```

RealAbs works with symbolic expressions:

```wolfram
RealAbs[-x] /. x -> 3
(* 3 *)
```
