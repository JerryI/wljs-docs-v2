---
title: TicksStyle
---

`TicksStyle` is an option for graphics functions which specifies how ticks should be rendered.

## Examples

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, TicksStyle -> Red]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TicksStyle.html) for more details.*
