---
title: MeshFunctions
---

`MeshFunctions` is an option for plotting functions that specifies functions to use to determine the placement of mesh divisions.

This option controls how mesh lines are drawn on plot surfaces.

## Examples

```wolfram
Plot3D[Sin[x] Cos[y], {x, 0, Pi}, {y, 0, Pi}, 
  MeshFunctions -> {#1 &, #2 &}]
```

```wolfram
Plot3D[x^2 + y^2, {x, -2, 2}, {y, -2, 2}, 
  MeshFunctions -> {Sqrt[#1^2 + #2^2] &}]
```

```wolfram
ParametricPlot3D[{Cos[u], Sin[u], v}, {u, 0, 2 Pi}, {v, 0, 2}, 
  MeshFunctions -> {#4 &}]
```

*See the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MeshFunctions.html) for more details.*
