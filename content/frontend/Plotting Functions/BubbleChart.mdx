```wolfram
BubbleChart[{{x1,y1,z1}, ...}]
```
creates a bubble chart for a list of triples

## Examples
Simple bubble plot of random triplets

```wolfram
BubbleChart[RandomReal[1, {10, 3}]]
```

multiple datasets

```wolfram
BubbleChart[RandomReal[1, {5, 7, 3}]]
```
