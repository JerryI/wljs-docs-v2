```wolfram
AnimatePlot[f_, {x, min, max}, {t, min, max}, opts___]
```

a dynamic alternative to [Plot](../Plotting%20Functions/Plot) and Mathematica's `Animate`, that samples all frames and creates live animation using them.

`f` has return `_Real` or `{__Real}` (in a case of multiple curves)

<Callout type="info">
The output is safe for exporting as a static HTML file, since it keeps all data inside the notebook. No Wolfram Kernel is required for playing the animation.
</Callout>

the set of parameters are not limited and accepts the following forms

## Options
### `"SamplingPoints"`
A number of points used in sampling. The default value is `200`

It inherits some of [Graphics](../Graphics/Graphics) options as well

### `AnimationRate`
Specifies the number of updates *per second*

### `TransitionType`
See [TransitionType](../Graphics/TransitionType)

### `TransitionDuration`
See [TransitionDuration](../Graphics/TransitionDuration)

### `ImageSize`
Accepts `{width, height}`

### `PlotStyle`
Specifies colors for each curve

### `Epilog`
### `Prolog`
Appends graphics primitives to the plot. See [Graphics](../Graphics/Graphics)

## Exporting
See "exporting" section of [Animate](../GUI/Animate)

## Example
Plot the simplest sine function

```wolfram
AnimatePlot[{Sin[x c], Sinc[x c]}, {x,-10,10}, {c,1,10,0.1}]
```

## Portability
Fully portable
