---
title: Region
---

`Region[reg]` represents a geometric region.

- `Region[reg, options]` gives a region that uses the specified options.

## Examples

Create a disk region:
```wolfram
Region[Disk[{0, 0}, 1]]
```

Region with styling:
```wolfram
Region[Ball[], PlotTheme -> "Detailed"]
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Region.html) for more details.
