---
title: RegionDistanceFunction
---

`RegionDistanceFunction[reg, …]` represents a function whose values give the distance from a point to the region reg.

## Examples

```wolfram
rdf = RegionDistanceFunction[Disk[]];
rdf[{2, 0}]
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RegionDistanceFunction.html) for more details.
