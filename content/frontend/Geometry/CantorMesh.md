---
title: CantorMesh
---

`CantorMesh[n]` gives a mesh region representing the nth-step Cantor set.

`CantorMesh[n, d]` gives the nth-step Cantor set in dimension d.

## Examples

Create a Cantor set:

```wolfram
CantorMesh[3]
```

2D Cantor dust:

```wolfram
CantorMesh[3, 2]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CantorMesh.html) for more details.*
