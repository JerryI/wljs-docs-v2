---
title: EmptyRegion
---

`EmptyRegion[n]` represents the empty subset of ℝ^n.

## Examples

Create an empty region in 2D:

```wolfram
EmptyRegion[2]
```

Check if a point is in an empty region:

```wolfram
RegionMember[EmptyRegion[2], {0, 0}]
(* False *)
```
