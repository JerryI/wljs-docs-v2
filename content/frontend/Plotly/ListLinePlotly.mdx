```wolfram
ListLinePlotly[{data1_, data2_, ...}]
```

```wolfram
ListLinePlotly[{{x1,y1}, ... {xn,yn}}]
```

```wolfram
ListLinePlotly[{y1, y2, y3 ...}]
```

mimics the native function [ListLinePlot](../Plotting%20Functions/ListLinePlot) using Plotly library (see [Plotly](../Plotting%20Functions/Plotly)). It is limited, there is __no options supported__.

An alternative plotting function to [ListLinePlot](../Plotting%20Functions/ListLinePlot), that supports updates, panning, zoom out of the box

## Dynamics
It fully supports updates. This is the first ever high order function, that does this unlike [ListLinePlot](../Plotting%20Functions/ListLinePlot). 

<Callout type="tip">
To use full features of Plotly, please, use [Plotly](../Plotting%20Functions/Plotly) and [PlotlyAnimate](../Plotly/PlotlyAnimate) or [PlotlyAddTraces](../Plotly/PlotlyAddTraces)
</Callout>

## Example

```wolfram
ListLinePlotly[Accumulate[RandomReal[{-1, 1}, {250, 2}]]]
```

<Callout type="warn">
No styling possible
</Callout>

## Examples with dynamics
As an advantage of it, you can directly feed it with offloaded variables

```wolfram
dirs = {{0,0}, {0,0}};
ListLinePlotly[dirs // Offload]
```

```wolfram
task = SetInterval[dirs = Append[dirs, Last[dirs] + RandomChoice[{{1,0}, {-1,0}, {0,1}, {0,-1}}]], 300];
SetTimeout[TaskRemove[task], 6000];
```
