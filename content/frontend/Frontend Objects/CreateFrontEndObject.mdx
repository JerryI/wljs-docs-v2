creates a reference to the inner expression and stores it into frontend objects storage  shared with Kernel and Notebook

```wolfram
CreateFrontEndObject[expr_, id_String | Null, opts___Rule] _FrontEndExecutable
```

Returns [`FrontEndExecutable`](../Frontend%20Objects/FrontEndExecutable) object with a given `id` or generated.

See more about it in [Frontend Objects](frontend/Advanced/Frontend%20interpretation/Frontend%20Objects)

This is a fundamental component  for `Graphics`, `InputRange`... and other interactive elements, which are too large to be stored inline in the editor.

<Callout type="tip">
If you do not want to apply [CreateFrontEndObject](../Frontend%20Objects/CreateFrontEndObject) on your symbol manually, consider to define [MakeBoxes](../Formatting/MakeBoxes) for [StandardForm](../Formatting/StandardForm). Then it can be applied automatically once it goes to the output cell.
</Callout>

## Options
### `"Store"`
Specifies which to storage to use for an expression (`"Frontend"`, `"Kernel"`, or `All`). The default values is `All`.

Each time you create `Graphics` or any other frontend object, it makes two copies of it: the first one is shared with a browser (WLJS), while  the second one is a *private* copy used by Wolfram Kernel once fetched by [FrontEndRef](../Frontend%20Objects/FrontEndRef) or evaluated for a second time (see [ViewBox](../Formatting/Low-level/ViewBox)).

## Applications
It is mostly used for storing *heavy* expressions to be executed as [WLJS Functions](frontend/Advanced/Frontend%20interpretation/WLJS%20Functions) such as [Graphics](../Graphics/Graphics), [Graphics3D](../Graphics3D/Graphics3D), [Audio](../Sound/Audio) and etc.

Other use cases are provided by its derivative - [FrontEndExecutable](../Frontend%20Objects/FrontEndExecutable), which has an UpValue for [StandardForm](../Formatting/StandardForm) and [WLXForm](../Formatting/WLXForm) used for printing the data for output wolfram language cells and [Slides](frontend/Cell%20types/Slides).

## Exporting
Created stored objects are fully portable and can be automatically exported to [Static HTML](frontend/Exporting/Static%20HTML), [Interactive HTML](frontend/Exporting/Interactive%20HTML), [Static Slides](frontend/Exporting/Static%20Slides) or as [Figures](frontend/Exporting/Figures)
