---
title: LimitsPositioningTokens
---

`LimitsPositioningTokens` is an option for selections that specifies a set of characters for which the option `LimitsPositioning` is set to `True` by default.

## Examples

```wolfram
Style[expr, LimitsPositioningTokens -> {"Sum", "Product"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LimitsPositioningTokens.html) for more details.*
