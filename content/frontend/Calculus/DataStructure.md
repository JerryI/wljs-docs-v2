---
title: DataStructure
---

`DataStructure["type",data]` represents a data structure.

## Examples

Create a stack data structure:

```wolfram
DataStructure["Stack", {1, 2, 3}]
(* DataStructure["Stack", ...] *)
```

Create a hash map:

```wolfram
DataStructure["HashTable", {"a" -> 1, "b" -> 2}]
```
