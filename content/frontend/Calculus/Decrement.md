---
title: Decrement
---

`x--` decreases the value of x by 1, returning the old value of x.

## Examples

Decrement a variable:

```wolfram
x = 5;
x--
(* 5 *)
x
(* 4 *)
```

In a loop:

```wolfram
i = 3;
While[i-- > 0, Print[i]]
(* prints 2, 1, 0 *)
```
