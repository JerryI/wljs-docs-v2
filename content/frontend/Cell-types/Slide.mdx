## Basics

### Creating Individual Slides

Each `.slide` cell creates a single presentation slide. You can write multiple slides across different cells in your notebook:

<WLJSWrapper>
<span className="absolute -inset-1 bg-gradient-to-r from-fd-primary/50 to-purple-500/50 rounded-lg blur-xl opacity-15 group-hover:opacity-50 transition duration-500" />
<wljs-editor lazy="true" type="Input" display="codemirror">{`.slide
# First Slide
Content for the first slide
`}</wljs-editor>
</WLJSWrapper>

<WLJSWrapper>
<span className="absolute -inset-1 bg-gradient-to-r from-fd-primary/50 to-purple-500/50 rounded-lg blur-xl opacity-15 group-hover:opacity-50 transition duration-500" />
<wljs-editor lazy="true" type="Input" display="codemirror">{`.slide
# Second Slide
Content for the second slide
`}</wljs-editor>
</WLJSWrapper>

### Separating Slides Within a Cell

Within a single `.slide` cell, you can create multiple slides by separating them with `---`:

<WLJSWrapper>
<span className="absolute -inset-1 bg-gradient-to-r from-fd-primary/50 to-purple-500/50 rounded-lg blur-xl opacity-15 group-hover:opacity-50 transition duration-500" />
<wljs-editor lazy="true" type="Input" display="codemirror">{`.slide
# First Slide
This is the first slide

---

# Second Slide
This is the second slide

---

# Third Slide
This is the third slide
`}</wljs-editor>
</WLJSWrapper>

### Merging All Slides

To combine all slides from different cells across your notebook into a single presentation, use the plural form:

<WLJSWrapper>
<span className="absolute -inset-1 bg-gradient-to-r from-fd-primary/50 to-purple-500/50 rounded-lg blur-xl opacity-15 group-hover:opacity-50 transition duration-500" />
<wljs-editor lazy="true" type="Input" display="codemirror">{`.slides

Thank you for the attention
`}</wljs-editor>
</WLJSWrapper>

This will merge and render all slide cells in the notebook as one continuous presentation, allowing you to navigate through all slides sequentially.

## Fragments

Fragments allow you to reveal content incrementally on a slide. Use the `<!-- .element: class="fragment" -->` comment syntax to make elements appear one at a time when you advance the presentation:

<WLJSWrapper>
<span className="absolute -inset-1 bg-gradient-to-r from-fd-primary/50 to-purple-500/50 rounded-lg blur-xl opacity-15 group-hover:opacity-50 transition duration-500" />
<wljs-editor lazy="true" type="Input" display="codemirror">{`.slide
# Incremental Content

This appears first
<!-- .element: class="fragment" -->

This appears second
<!-- .element: class="fragment" -->

This appears third
<!-- .element: class="fragment" -->
`}</wljs-editor>
</WLJSWrapper>

## LaTeX Support

Slides use KaTeX as the rendering engine for mathematical equations. Wrap inline equations in single `$` symbols, or use `$$` for block equations:

<WLJSWrapper>
<span className="absolute -inset-1 bg-gradient-to-r from-fd-primary/50 to-purple-500/50 rounded-lg blur-xl opacity-15 group-hover:opacity-50 transition duration-500" />
<wljs-editor lazy="true" type="Input" display="codemirror">{`.slide
# Mathematical Equations

Inline equation: $E = mc^2$

Block equation:
$$
E = \\\\hbar \\\\omega
$$
`}</wljs-editor>
</WLJSWrapper>

### Animated equations

> This particular technique was developed by [Cian Luke Martin](https://www.cianlm.dev/) and is essentially a post-processing engine for SVGs generated from LaTeX equations

You can create Manim-like animated equations:

<WLJSWrapper>
<span className="absolute -inset-1 bg-gradient-to-r from-fd-primary/50 to-purple-500/50 rounded-lg blur-xl opacity-15 group-hover:opacity-50 transition duration-500" />
<wljs-editor lazy="true" type="Input" display="codemirror">{`.slide

## Animated LaTeX

$$
\\\\begin{align*}
\\\\mathbf{E}(t,x) &= \\\\sum_{\\\\omega} \\\\mathbf{E}_0^{\\\\omega} ~ exp\\\\Big( i\\\\omega t - \\\\frac{i\\\\hat{n}(\\\\omega) \\\\omega x}{c}\\\\Big) \\\\\\\\ &= \\\\sum\\\\mathbf{E}_0^{\\\\omega} \\\\colorbox{white}{$exp(-\\\\frac{\\\\alpha x}{2})$} ~exp\\\\Big(i\\\\omega t - \\\\frac{i n \\\\omega x}{c}\\\\Big)
\\\\end{align*}
$$ <!-- .element: data-eq-speed="0.1" -->

`}</wljs-editor>
</WLJSWrapper>

## Drawings

Slides integrate the [Excalidraw](https://excalidraw.com/) editor for creating drawings directly within your presentations. To create a drawing, type: `!![]`

This will open the Excalidraw editor, and the resulting drawing will be saved as an SVG image in the output cell.

Slides support automatic image uploading:

- **Drop a file**: Drag and drop image files directly onto your slide

## Events
To capture events such as slide or fragment reveals, use [SlideEventListener](./../Slides/SlideEventListener):

<WLJSWrapper>
<span className="absolute -inset-1 bg-gradient-to-r from-fd-primary/50 to-purple-500/50 rounded-lg blur-xl opacity-15 group-hover:opacity-50 transition duration-500" />
<wljs-editor lazy="true" type="Input" display="codemirror">{`.slide

# 1st Slide
Nothing

---

# 2nd Slide
A message pops up

Another message <!-- .element: class="fragment" data-fragment-index="1" -->

<SlideEventListener Id={"myEvent"}/>
`}</wljs-editor>
</WLJSWrapper>

Before evaluating, attach an event handler:

<WLJSWrapper>
<span className="absolute -inset-1 bg-gradient-to-r from-fd-primary/50 to-purple-500/50 rounded-lg blur-xl opacity-15 group-hover:opacity-50 transition duration-500" />
<wljs-editor lazy="true" type="Input" display="codemirror">{`
EventHandler["myEvent", {
    "Slide" -> (Print["Hey there!"]&),
    "fragment-1" -> (Print["Hey there from fragment!"]&)
}]
`}</wljs-editor>
</WLJSWrapper>

The identifier acts as an event object with these patterns:

<Card>

- `"Slide"` — fired when a slide is revealed
- `"Mounted"` - fired when the presentation is ready to show
- `"Left"` - fired when you left the slide
- `"Destroy"` - fired when this slide cell was destroyed
- `"fragment-INDEX"` — fired when a fragment `INDEX` is revealed

</Card>

<Callout type="tip">You can assign as many listeners to the same slide as you want. Use this feature to scope events to [your components](./../Advanced/Component-based-markup)</Callout>

### JavaScript Code
Any `script` tag will execute after slides are mounted and __scoped to the slide__ (aka module):

<WLJSWrapper>
<span className="absolute -inset-1 bg-gradient-to-r from-fd-primary/50 to-purple-500/50 rounded-lg blur-xl opacity-15 group-hover:opacity-50 transition duration-500" />
<wljs-editor lazy="true" type="Input" display="codemirror">{`.slide

<div id="dtext">Hello World</div>

<script>
  document.getElementById('dtext').style.background = "yellow"
</script>
`}</wljs-editor></WLJSWrapper>



<Callout type="warning">
If you use unique `id` for elements on the slide, please, remove the output cell before reevaluating the input one. Otherwise two identical elements might coexist on the same page, which then cause issues with bindings to JS.
</Callout>
