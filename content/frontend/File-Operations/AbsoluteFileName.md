---
title: AbsoluteFileName
---

`AbsoluteFileName["name"]` gives the full absolute path for a file.

## Examples

Get absolute path:

```wolfram
AbsoluteFileName["data.txt"]
(* "/Users/username/project/data.txt" *)
```

Resolve relative paths:

```wolfram
AbsoluteFileName["../other/file.m"]
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AbsoluteFileName.html) for more details.
