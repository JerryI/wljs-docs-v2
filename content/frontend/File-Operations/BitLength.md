---
title: BitLength
---

`BitLength[n]` gives the number of binary bits necessary to represent the integer n.

## Examples

Number of bits for small integers:

```wolfram
BitLength[7]
(* 3 *)
```

```wolfram
BitLength[255]
(* 8 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/BitLength.html) for more details.*
