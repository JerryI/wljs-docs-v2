---
title: FileBaseName
---

`FileBaseName["file"]` gives the base name without extension.

## Examples

Get base name:

```wolfram
FileBaseName["document.pdf"]
(* "document" *)
```

```wolfram
FileBaseName["/path/to/image.png"]
(* "image" *)
```
