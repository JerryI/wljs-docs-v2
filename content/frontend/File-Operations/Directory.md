---
title: Directory
---

`Directory[]` gives the current working directory.

## Examples

Get current directory:

```wolfram
Directory[]
(* "/Users/username/project" *)
```

Use with FileNames:

```wolfram
FileNames["*.txt", {Directory[]}]
```
