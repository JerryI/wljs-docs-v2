---
title: DeleteDirectory
---

`DeleteDirectory["dir"]` deletes the specified directory.

## Examples

Delete an empty directory:

```wolfram
DeleteDirectory["emptyFolder"]
```

Delete with contents:

```wolfram
DeleteDirectory["myFolder", DeleteContents -> True]
```
