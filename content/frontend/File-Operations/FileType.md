---
title: FileType
---

`FileType["file"]` gives the type of a file, typically File, Directory, or None.

## Examples

Check the type of a file:

```wolfram
FileType["/path/to/file.txt"]
(* File *)
```

Check a directory:

```wolfram
FileType["/path/to/folder"]
(* Directory *)
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/FileType.html) for more details.
