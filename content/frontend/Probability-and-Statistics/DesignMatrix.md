---
title: DesignMatrix
---

`DesignMatrix[{{x11, x12, ..., y1}, {x21, x22, ..., y2}, ...}, {f1, f2, ...}, {x1, x2, ...}]` constructs the design matrix for the linear model β₀ + β₁f₁ + β₂f₂ + ....

## Examples

```wolfram
DesignMatrix[{{1, 1}, {2, 2}, {3, 4}}, {x, x^2}, x]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DesignMatrix.html) for more details.*
