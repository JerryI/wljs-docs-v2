---
title: NakagamiDistribution
---

`NakagamiDistribution[μ,ω]` represents a Nakagami distribution with shape parameter μ and spread parameter ω.

## Examples

Create a Nakagami distribution:

```wolfram
dist = NakagamiDistribution[2, 1]
```

Compute the mean:

```wolfram
Mean[NakagamiDistribution[2, 1]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NakagamiDistribution.html) for more details.*
