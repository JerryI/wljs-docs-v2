---
title: SpatialEstimatorFunction
---

`SpatialEstimatorFunction[...]` represents a function generated by `SpatialEstimate` and predicts spatial field values from locations.

## Examples

```wolfram
data = {{0, 0} -> 1, {1, 0} -> 2, {0, 1} -> 3};
estimator = SpatialEstimate[data]
```

```wolfram
estimator[{0.5, 0.5}]
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SpatialEstimatorFunction.html) for more details.
