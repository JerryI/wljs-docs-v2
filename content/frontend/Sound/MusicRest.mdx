```wolfram
MusicRest[]
MusicRest[duration]
MusicRest[properties]
```

represents a period of musical silence. `duration` accepts the same forms as [MusicDuration](../Sound/MusicDuration).

```wolfram
MusicRest[1/8]
```

The defining property is `"Duration"`:

```wolfram
rest = MusicRest[MusicDuration["Quarter"]];
rest["Duration"]
```

## Playback

Inside [Sound](../Sound/Sound), a rest advances the musical timeline without producing a note:

```wolfram
Sound[{
  MusicNote["C4", 1/4],
  MusicRest[1/4],
  MusicNote["G4", 1/2]
}]
```

Rests count toward the displayed event count and total duration, but do not create piano-roll rectangles.

See the [Wolfram Language reference](https://reference.wolfram.com/language/ref/MusicRest.html) for the complete symbolic API.
