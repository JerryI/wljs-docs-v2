```wolfram
Alert[message_String]
```

pops up a default alert message on the frontend

## Example
This is purely frontend symbol, which has to be called either using [FrontSubmit](../Frontend-IO/FrontSubmit) or from [ViewBox](../Formatting/Low-level/ViewBox)

```wolfram
FrontSubmit[Alert["Hello World"]]
```
