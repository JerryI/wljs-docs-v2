---
title: DateFunction
---

`DateFunction` is an option for `DateListPlot` and `TemporalData` that specifies how dates given as input should be interpreted.

## Examples

```wolfram
DateListPlot[{{"2020-01-01", 10}, {"2020-02-01", 20}}, DateFunction -> "ISODate"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DateFunction.html) for more details.*
