title: And
---

`e1 && e2 && ...` is the logical AND function. It gives `False` immediately if any argument is `False`, and `True` if all are `True`.

## Examples

Logical AND:

```wolfram
True && True
(* True *)

True && False
(* False *)
```

With conditions:

```wolfram
x = 5;
x > 0 && x < 10
(* True *)
```
