title: Booleans
---

`Booleans` represents the domain of Booleans, as in x∈Booleans.

## Examples

Test if a value is in the Booleans domain:

```wolfram
Element[True, Booleans]
(* True *)
```

```wolfram
Element[1, Booleans]
(* False *)
```
