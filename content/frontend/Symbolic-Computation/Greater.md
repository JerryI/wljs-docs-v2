---
title: Greater
---

`x > y` yields `True` if x is greater than y.

`x1 > x2 > x3` yields `True` if the values form a strictly decreasing sequence.

## Examples

Comparison:

```wolfram
5 > 3
(* True *)

3 > 5
(* False *)
```

Chained comparison:

```wolfram
3 > 2 > 1
(* True *)
```
