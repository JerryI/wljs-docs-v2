---
title: Positive
---

`Positive[x]` gives `True` if x is a positive number.

## Examples

Test for positive numbers:

```wolfram
Positive[5]
(* True *)
```

```wolfram
Positive[-3]
(* False *)
```

Filter positive numbers:

```wolfram
Select[{-2, -1, 0, 1, 2}, Positive]
(* {1, 2} *)
```
