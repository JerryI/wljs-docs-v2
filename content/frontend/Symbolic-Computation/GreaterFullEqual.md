---
title: GreaterFullEqual
---

`GreaterFullEqual[x,y,…]` displays as x≧y≧….

## Examples

Create a greater-or-equal chain:

```wolfram
GreaterFullEqual[a, b, c]
(* a ≧ b ≧ c *)
```

Use in an expression:

```wolfram
GreaterFullEqual[5, 3, 1]
(* 5 ≧ 3 ≧ 1 *)
```
