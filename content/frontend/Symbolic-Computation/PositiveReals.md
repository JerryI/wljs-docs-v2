---
title: PositiveReals
---

`PositiveReals` represents the domain of strictly positive real numbers.

## Examples

Test if a number is in PositiveReals:

```wolfram
Element[5, PositiveReals]
(* True *)
```

Use in assumptions:

```wolfram
Simplify[Sqrt[x^2], x ∈ PositiveReals]
(* x *)
```
