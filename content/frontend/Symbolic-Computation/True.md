title: "True"
---

`True` is the symbol for the Boolean value true.

## Examples

Logical operations:

```wolfram
True && True
(* True *)

True || False
(* True *)
```

Conditional:

```wolfram
If[True, "yes", "no"]
(* "yes" *)
```
