---
title: "False"
---

`False` is the symbol for the Boolean value false.

## Examples

Logical operations:

```wolfram
False && True
(* False *)

False || True
(* True *)
```

Conditional:

```wolfram
If[False, "yes", "no"]
(* "no" *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/False.html) for more details.*
