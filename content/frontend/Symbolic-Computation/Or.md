---
title: Or
---

`e1 || e2 || ...` is the logical OR function. It gives `True` immediately if any argument is `True`, and `False` if all are `False`.

## Examples

Logical OR:

```wolfram
True || False
(* True *)

False || False
(* False *)
```

With conditions:

```wolfram
x = 15;
x < 0 || x > 10
(* True *)
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Or.html) for more details.
