---
title: NonNegative
---

`NonNegative[x]` gives `True` if x is a non-negative number (zero or positive).

## Examples

Test for non-negative numbers:

```wolfram
NonNegative[5]
(* True *)
```

```wolfram
NonNegative[0]
(* True *)
```

```wolfram
NonNegative[-3]
(* False *)
```
