---
title: NotSucceedsTilde
---

`NotSucceedsTilde[x, y, ...]` displays as x⋩y⋩....

## Examples

Display the not-succeeds-tilde relation:

```wolfram
NotSucceedsTilde[a, b]
```

Multiple arguments:

```wolfram
NotSucceedsTilde[x, y, z]
```

In mathematical expressions:

```wolfram
Row[{x, " ", NotSucceedsTilde[a, b], " ", y}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NotSucceedsTilde.html) for more details.*
