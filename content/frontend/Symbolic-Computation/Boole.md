---
title: Boole
---

`Boole[expr]` yields 1 if expr is True and 0 if it is False.

## Examples

Convert boolean to number:

```wolfram
Boole[True]
(* 1 *)

Boole[False]
(* 0 *)
```

Use in calculations:

```wolfram
Boole[5 > 3] + Boole[2 > 4]
(* 1 *)
```
