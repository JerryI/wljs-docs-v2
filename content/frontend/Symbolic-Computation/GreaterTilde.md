---
title: GreaterTilde
---

`GreaterTilde[x,y,...]` displays as x≳y≳....

## Examples

Display the greater-tilde relation:

```wolfram
GreaterTilde[a, b, c]
(* a ≳ b ≳ c *)
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GreaterTilde.html) for more details.
