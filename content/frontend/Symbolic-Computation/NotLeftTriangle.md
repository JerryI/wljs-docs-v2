---
title: NotLeftTriangle
---

`NotLeftTriangle[x, y, ...]` displays as x⋪y⋪....

## Examples

Basic usage:

```wolfram
NotLeftTriangle[a, b]
```

Multiple arguments:

```wolfram
NotLeftTriangle[x, y, z]
```

In expressions:

```wolfram
NotLeftTriangle[f[x], g[y]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NotLeftTriangle.html) for more details.*
