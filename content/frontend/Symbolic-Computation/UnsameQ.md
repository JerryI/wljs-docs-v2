---
title: UnsameQ
---

`lhs =!= rhs` yields `True` if the expression lhs is not identical to rhs, and `False` otherwise.

## Examples

Test for non-identical expressions:

```wolfram
1.0 =!= 1
(* True *)
```

```wolfram
{1, 2} =!= {1, 2}
(* False *)
```

Different symbols:

```wolfram
x =!= y
(* True *)
```
