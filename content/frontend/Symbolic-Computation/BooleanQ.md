---
title: BooleanQ
---

`BooleanQ[expr]` returns True if expr is either True or False.

## Examples

Test boolean values:

```wolfram
BooleanQ[True]
(* True *)

BooleanQ[False]
(* True *)
```

Non-boolean:

```wolfram
BooleanQ[1]
(* False *)
```
