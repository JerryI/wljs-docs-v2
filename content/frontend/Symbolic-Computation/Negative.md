---
title: Negative
---

`Negative[x]` gives `True` if x is a negative number.

## Examples

Test for negative numbers:

```wolfram
Negative[-5]
(* True *)
```

```wolfram
Negative[3]
(* False *)
```

Filter negative numbers:

```wolfram
Select[{-2, -1, 0, 1, 2}, Negative]
(* {-2, -1} *)
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Negative.html) for more details.
