---
title: ValueQ
---

`ValueQ[expr]` gives `True` if a value has been defined for expr, and gives `False` otherwise.

## Examples

```wolfram
x = 5;
ValueQ[x]
(* True *)
```

```wolfram
ValueQ[y]
(* False *)
```
