---
title: NonPositive
---

`NonPositive[x]` gives True if x is a non‐positive number.

## Examples

Test if a number is non-positive:

```wolfram
NonPositive[-5]
(* True *)

NonPositive[0]
(* True *)

NonPositive[3]
(* False *)
```
