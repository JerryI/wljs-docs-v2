---
title: ProofObject
---

`ProofObject[…]` represents a proof object generated by `FindEquationalProof`.

## Examples

Generate a proof:

```wolfram
proof = FindEquationalProof[a == c, {a == b, b == c}]
(* ProofObject[...] *)
```

Extract the proof steps:

```wolfram
proof["ProofGraph"]
```
