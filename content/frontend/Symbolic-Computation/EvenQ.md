---
title: EvenQ
---

`EvenQ[expr]` gives `True` if expr is an even integer, and `False` otherwise.

## Examples

Test if a number is even:

```wolfram
EvenQ[4]
(* True *)
```

```wolfram
EvenQ[7]
(* False *)
```

Filter even numbers from a list:

```wolfram
Select[Range[10], EvenQ]
(* {2, 4, 6, 8, 10} *)
```
