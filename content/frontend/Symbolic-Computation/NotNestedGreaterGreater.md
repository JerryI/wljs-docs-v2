---
title: NotNestedGreaterGreater
---

`NotNestedGreaterGreater[x, y, ...]` displays as x⪢̸y⪢̸....

## Examples

Display not nested greater notation:
```wolfram
NotNestedGreaterGreater[a, b, c]
```

Use in expressions:
```wolfram
NotNestedGreaterGreater[x, y]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NotNestedGreaterGreater.html) for more details.*
