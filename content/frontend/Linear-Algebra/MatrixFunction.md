---
title: MatrixFunction
---

`MatrixFunction[f, m]` gives the matrix generated by the scalar function f at the matrix argument m.

## Examples

Matrix sine:

```wolfram
MatrixFunction[Sin, {{0, 1}, {-1, 0}}]
```

Apply exponential:

```wolfram
MatrixFunction[Exp, {{1, 0}, {0, 2}}]
(* {{E, 0}, {0, E^2}} *)
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MatrixFunction.html) for more details.
