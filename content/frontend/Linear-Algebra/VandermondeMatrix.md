---
title: VandermondeMatrix
---

`VandermondeMatrix[{x1, x2, ..., xn}]` gives an n×n Vandermonde matrix corresponding to the nodes xi.

- `VandermondeMatrix[{x1, x2, ..., xn}, k]` gives an n×k Vandermonde matrix.
- `VandermondeMatrix[vmat]` converts a Vandermonde matrix vmat to a structured array.

## Examples

```wolfram
VandermondeMatrix[{1, 2, 3}]
```

```wolfram
VandermondeMatrix[{a, b, c, d}, 3]
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VandermondeMatrix.html) for more details.
