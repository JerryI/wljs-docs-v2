---
title: MatrixPower
---

`MatrixPower[m, n]` gives the nth matrix power of the matrix m.

## Examples

Square a matrix:

```wolfram
MatrixPower[{{1, 1}, {1, 0}}, 2]
(* {{2, 1}, {1, 1}} *)
```

Fibonacci via matrix power:

```wolfram
MatrixPower[{{1, 1}, {1, 0}}, 10]
(* {{89, 55}, {55, 34}} *)
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MatrixPower.html) for more details.
