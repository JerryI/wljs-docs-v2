title: CDFWavelet
---

`CDFWavelet[]` represents a Cohen–Daubechies–Feauveau wavelet of type "9/7".

`CDFWavelet["type"]` represents a Cohen–Daubechies–Feauveau wavelet of type "type".

## Examples

Create a CDF 9/7 wavelet:

```wolfram
CDFWavelet[]
```

Create a CDF 5/3 wavelet:

```wolfram
CDFWavelet["5/3"]
```
