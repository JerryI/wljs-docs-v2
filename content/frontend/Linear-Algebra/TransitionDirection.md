---
title: TransitionDirection
---

`TransitionDirection` is an option for `PaneSelector` that specifies the direction in which a transition moves.

## Examples

```wolfram
PaneSelector[{1 -> "A", 2 -> "B"}, Dynamic[x], TransitionDirection -> Right]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TransitionDirection.html) for more details.*
