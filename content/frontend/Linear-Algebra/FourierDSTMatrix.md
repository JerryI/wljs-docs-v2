---
title: FourierDSTMatrix
---

`FourierDSTMatrix[n]` returns an n×n discrete sine transform matrix of type 2.

`FourierDSTMatrix[n, m]` returns an n×n discrete sine transform matrix of type m.

## Examples

Generate a 4×4 DST matrix:

```wolfram
FourierDSTMatrix[4]
```
