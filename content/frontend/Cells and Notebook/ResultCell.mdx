returns an future output cell identifier as an [RemoteCellObj](../Cells%20and%20Notebook/RemoteCellObj) *even if it was not yet created* from the evaluation context

```wolfram
ResultCell[] _RemoteCellObj
```

<Callout type="note">
Works in all output cells: Wolfram Language, [WLX](frontend/Cell%20types/WLX) and [Slides](frontend/Cell%20types/Slides)
</Callout>
