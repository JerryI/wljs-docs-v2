---
title: URLQueryDecode
---

`URLQueryDecode["string"]` decodes a URL-style query string into a list of key-value rules.

## Examples

```wolfram
URLQueryDecode["name=John&age=30"]
```

```wolfram
URLQueryDecode["key=value%20with%20spaces"]
```
