---
title: IPAddress
---

`IPAddress["address"]` is a symbolic representation of an IPv4 or IPv6 IP address.

## Examples

Create an IPv4 address:

```wolfram
IPAddress["192.168.1.1"]
(* IPAddress["192.168.1.1"] *)
```

Create an IPv6 address:

```wolfram
IPAddress["::1"]
(* IPAddress["::1"] *)
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/IPAddress.html) for more details.
