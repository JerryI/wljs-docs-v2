# AutoIndent

`AutoIndent` is an option for `Style` and `Cell` that specifies what automatic indentation should be done at the beginning of a new line after an explicit return character has been entered.

## Examples

```wolfram
Cell["code", "Input", AutoIndent -> True]
(* creates a cell with auto-indentation enabled *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AutoIndent.html) for more details.*
