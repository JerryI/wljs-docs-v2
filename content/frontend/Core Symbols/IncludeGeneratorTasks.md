# IncludeGeneratorTasks

`IncludeGeneratorTasks` is an option controlling the scope of scheduled task listings.

## Examples

```wolfram
ScheduledTasks[IncludeGeneratorTasks -> True]
(* List of all scheduled tasks including generator tasks *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/IncludeGeneratorTasks.html) for more details.*
