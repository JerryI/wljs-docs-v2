# URLShorten

`URLShorten["url"]` creates a shortened URL that redirects to "url".

- `URLShorten[CloudObject[…]]` creates a shortened URL that redirects to the URL for the specified cloud object.

## Examples

```wolfram
URLShorten["https://www.wolfram.com/mathematica/"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/URLShorten.html) for more details.*
