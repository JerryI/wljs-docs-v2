# SpellingCorrectionList

`SpellingCorrectionList["word"]` gives a list of possible spelling corrections for "word".

## Examples

Get spelling suggestions:

```wolfram
SpellingCorrectionList["teh"]
(* {"the", "tea", "ten"} *)
```

Correct a misspelled word:

```wolfram
SpellingCorrectionList["progam"]
(* {"program"} *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SpellingCorrectionList.html) for more details.*
