# DoubleBracketingBar

`DoubleBracketingBar[x, y, ...]` displays as ⟦x, y, ...⟧.

## Examples

Display with double bracketing bars:

```wolfram
DoubleBracketingBar[a, b, c]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DoubleBracketingBar.html) for more details.*
