# PowerDistribution

`PowerDistribution[k, a]` represents a power distribution with domain parameter k and shape parameter a.

## Examples

```wolfram
dist = PowerDistribution[2, 3]
```

```wolfram
Mean[dist]
```

```wolfram
RandomVariate[PowerDistribution[1, 2], 5]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PowerDistribution.html) for more details.*
