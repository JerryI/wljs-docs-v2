# PairwiseListPlot

```
PairwiseListPlot[{{y11,…,y1n},…,{ym1,…,ymn}}] creates an array of scatter plots by plotting the data columns against each other in pairs.

PairwiseListPlot[{data1,data2,…}] plots multiple sets of data in each plot panel.
```
