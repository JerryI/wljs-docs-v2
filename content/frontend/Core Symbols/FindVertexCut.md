# FindVertexCut

```
FindVertexCut[g] finds a smallest vertex cut of the graph g.

FindVertexCut[g,s,t] finds a smallest s-t vertex cut of the graph g.

FindVertexCut[{v->w,…},…] uses rules v->w to specify the graph g. 
```
