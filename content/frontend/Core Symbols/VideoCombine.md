# VideoCombine

`VideoCombine[{obj1, obj2, ...}]` creates a multi-track video by combining all audio, video and subtitle tracks in all *obji*.

## Examples

```wolfram
VideoCombine[{Video["video.mp4"], Audio["audio.wav"]}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VideoCombine.html) for more details.*
