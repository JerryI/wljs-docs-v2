# WebColumn

`WebColumn[{expr1, expr2, ...}]` represents an HTML column containing the expri.

- `WebColumn[expr, options]` displays with expr formatted using the specified option settings.

## Examples

```wolfram
WebColumn[{"Item 1", "Item 2", "Item 3"}]
```

```wolfram
WebColumn[{Button["Click"], InputField[]}, ImageSize -> 200]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/WebColumn.html) for more details.*
