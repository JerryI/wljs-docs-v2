# BatchSize

`BatchSize` is an option for `NetTrain` and related functions that specifies the size of a batch of examples to process together.

## Examples

Train with specific batch size:

```wolfram
NetTrain[net, trainingData, BatchSize -> 32]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/BatchSize.html) for more details.*
