# LeftUpVector

`LeftUpVector[x, y, ...]` displays as x↿y↿….

## Examples

```wolfram
LeftUpVector[a, b]
```

```wolfram
LeftUpVector[x, y, z] // TraditionalForm
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LeftUpVector.html) for more details.*
