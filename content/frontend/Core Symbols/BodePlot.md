# BodePlot

```
BodePlot[lsys] generates a Bode plot of a linear time-invariant system lsys.

BodePlot[lsys,{ωmin,ωmax}] plots for the frequency range ωmin to ωmax.

BodePlot[expr,{ω,ωmin,ωmax}] plots expr using the variable ω.
```
