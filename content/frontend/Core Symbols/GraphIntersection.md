# GraphIntersection

```
GraphIntersection[g1,g2] gives the graph intersection of the graphs g1 and g2.

GraphIntersection[g1,g2,…] gives the graph intersection of g1, g2, … .

GraphIntersection[{v->w,…},…] uses rules v->w to specify the graph g.
```
