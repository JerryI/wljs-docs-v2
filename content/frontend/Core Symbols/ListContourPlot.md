# ListContourPlot

```
ListContourPlot[{{f11,…,f1n},…,{fm1,…,fmn}}] generates a contour plot from an array of values fij.

ListContourPlot[{{x1,y1,f1},…,{xk,yk,fk}}] generates a contour plot from values fi specified at points {xi,yi}. 
```
