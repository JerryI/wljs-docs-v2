# SimplePolyhedronQ

`SimplePolyhedronQ[poly]` gives `True` if the polyhedron poly is simple and `False` otherwise.

## Examples

```wolfram
SimplePolyhedronQ[Tetrahedron[]]
```

```wolfram
SimplePolyhedronQ[Cuboid[]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SimplePolyhedronQ.html) for more details.*
