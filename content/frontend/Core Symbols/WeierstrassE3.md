# WeierstrassE3

`WeierstrassE3[{g2, g3}]` gives the value $e_3$ of the Weierstrass elliptic function ℘ at the half-period $ω_3(g_2, g_3)$.

## Examples

```wolfram
WeierstrassE3[{1, 0}]
```

```wolfram
WeierstrassE3[{4, 0}] // N
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/WeierstrassE3.html) for more details.*
