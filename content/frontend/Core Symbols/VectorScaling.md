# VectorScaling

`VectorScaling` is an option for `VectorPlot` and related functions that determines how the magnitudes of vectors are scaled for visualization.

## Examples

```wolfram
VectorPlot[{y, -x}, {x, -2, 2}, {y, -2, 2}, VectorScaling -> Automatic]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VectorScaling.html) for more details.*
