# AiryAi

`AiryAi[z]` gives the Airy function Ai(z).

## Examples

Evaluate the Airy function at a point:

```wolfram
AiryAi[0]
(* 1/(3^(2/3) Gamma[2/3]) *)
```

Plot the Airy function:

```wolfram
Plot[AiryAi[x], {x, -10, 5}]
```
