# CoulombH1

`CoulombH1[l, η, r]` gives the outgoing irregular Coulomb wavefunction Hl(+)(η, r).

## Examples

Compute outgoing Coulomb wavefunction:

```wolfram
CoulombH1[0, 1, 2.0]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CoulombH1.html) for more details.*
