# ImageDemosaic

```
ImageDemosaic[image,cfa] reconstructs a color image using the specified color filter array cfa.

ImageDemosaic[image,{"cfa",{row,col}}] aligns the top-left pixel of the pattern with the {row,col} pixel of image.
```
