# Ellipsoid

```
Ellipsoid[p,{r1,…}] represents an axis-aligned ellipsoid centered at the point p and with semiaxes lengths ri.

Ellipsoid[p,Σ] represents an ellipsoid centered at p and weight matrix Σ.
```
