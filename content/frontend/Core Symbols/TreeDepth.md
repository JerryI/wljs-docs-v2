# TreeDepth

`TreeDepth[tree]` gives the maximum level of tree.

- `TreeDepth[tree, pattern]` gives the maximum level of the subtree with data matching pattern.

## Examples

```wolfram
TreeDepth[Tree[a, {Tree[b, {c, d}], e}]]
```

```wolfram
TreeDepth[Tree[1, {Tree[2, {3}], 4}]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TreeDepth.html) for more details.*
