# LeftTeeArrow

`LeftTeeArrow[x, y, ...]` displays as x↤y↤….

## Examples

```wolfram
LeftTeeArrow[a, b]
```

```wolfram
LeftTeeArrow[x, y, z] // TraditionalForm
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LeftTeeArrow.html) for more details.*
