# TimeDirection

`TimeDirection` is an option for `Sunrise`, `Sunset`, and related functions that specifies whether the next or last event should be returned.

## Examples

```wolfram
Sunrise[TimeDirection -> "Next"]
```

```wolfram
Sunset[TimeDirection -> "Previous"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TimeDirection.html) for more details.*
