# RightTriangle

`RightTriangle[x, y, ...]` displays as x⊳y⊳….

## Examples

```wolfram
RightTriangle[a, b]
```

```wolfram
RightTriangle[x, y, z] // TraditionalForm
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RightTriangle.html) for more details.*
