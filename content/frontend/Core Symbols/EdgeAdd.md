# EdgeAdd

```
EdgeAdd[g,e] makes a graph by adding the edge e to the graph g.

EdgeAdd[g,{e1,e2,…}] adds a collection of edges to g.

EdgeAdd[{v->w,…},…] uses rules v->w to specify the graph g. 
```
