# DistanceMatrix

```
DistanceMatrix[{u1,u2,…}] gives the matrix of distances between each pair of elements ui, uj. 

DistanceMatrix[{u1,u2,…},{v1,v2,…}] gives the matrix of distances between each pair of elements ui, vj.
```
