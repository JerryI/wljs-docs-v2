# ToDiscreteTimeModel

```
ToDiscreteTimeModel[lsys,τ] gives the discrete-time approximation, with sampling period τ, of the continuous-time systems models lsys.

ToDiscreteTimeModel[tfm,τ,z] specifies the transform variable z.
```
