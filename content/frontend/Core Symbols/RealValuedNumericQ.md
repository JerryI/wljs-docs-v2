# RealValuedNumericQ

`RealValuedNumericQ[expr]` gives True if expr is a real-valued numeric quantity, and False otherwise.

## Examples

Check real-valued numbers:

```wolfram
RealValuedNumericQ[3.14]
(* True *)
```

```wolfram
RealValuedNumericQ[2 + 3 I]
(* False *)
```

```wolfram
RealValuedNumericQ[Pi]
(* True *)
```
