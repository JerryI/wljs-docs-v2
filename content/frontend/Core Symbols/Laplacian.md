# Laplacian

```
Laplacian[f,{x1,…,xn}] gives the Laplacian ∂2f/∂x12+…+∂2f/∂xn2.

Laplacian[f,{x1,…,xn},chart] gives the Laplacian in the given coordinates chart.
```
