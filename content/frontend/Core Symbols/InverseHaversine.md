# InverseHaversine

`InverseHaversine[z]` gives the inverse haversine function hav⁻¹(z).

## Examples

Compute inverse:

```wolfram
InverseHaversine[0.5]
(* 1.5708 *)
```

Verify relationship:

```wolfram
Haversine[InverseHaversine[0.25]]
(* 0.25 *)
```
