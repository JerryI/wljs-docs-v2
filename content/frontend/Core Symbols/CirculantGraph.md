# CirculantGraph

```
CirculantGraph[n,j] gives the circulant graph Cn(j) with n vertices and jump j.

CirculantGraph[n,{j1,j2,…}] gives the circulant graph Cn(j1,j2,…) with n vertices and jumps j1, j2, ….
```
