# FindEdgeCut

```
FindEdgeCut[g] finds a smallest edge cut of the graph g.

FindEdgeCut[g,s,t] finds a smallest s-t edge cut of the graph g.

FindEdgeCut[{v->w,…},…] uses rules v->w to specify the graph g.
```
