# Clip

```
Clip[x] gives x clipped to be between -1 and +1. 

Clip[x,{min,max}] gives x for min≤x≤max, min for x<min and max for x>max. 

Clip[x,{min,max},{vmin,vmax}] gives vmin for x<min and vmax for x>max. 
```
