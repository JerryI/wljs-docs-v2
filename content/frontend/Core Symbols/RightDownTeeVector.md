# RightDownTeeVector

`RightDownTeeVector[x, y, ...]` displays as x⥝y⥝….

## Examples

```wolfram
RightDownTeeVector[a, b]
```

```wolfram
RightDownTeeVector[x, y, z] // TraditionalForm
```
