# AxesEdge

`AxesEdge` is an option for three-dimensional graphics functions that specifies on which edges of the bounding box axes should be drawn.

## Examples

```wolfram
Graphics3D[Sphere[], Axes -> True, AxesEdge -> {{-1, -1}, {1, -1}, {-1, -1}}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AxesEdge.html) for more details.*
