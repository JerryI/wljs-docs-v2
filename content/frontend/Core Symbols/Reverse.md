# Reverse

`Reverse[expr]` reverses the order of the elements in expr.

## Examples

Reverse a list:

```wolfram
Reverse[{1, 2, 3, 4, 5}]
(* {5, 4, 3, 2, 1} *)
```

Reverse a string:

```wolfram
StringReverse["hello"]
(* "olleh" *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Reverse.html) for more details.*
