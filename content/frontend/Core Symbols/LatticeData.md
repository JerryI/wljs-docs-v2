# LatticeData

`LatticeData[lattice, "property"]` gives the specified property for a lattice.

`LatticeData[n]` gives a list of named lattices of dimension n.

## Examples

List 2D lattices:

```wolfram
LatticeData[2]
```

Get properties of a lattice:

```wolfram
LatticeData["FCC", "BasisVectors"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LatticeData.html) for more details.*
