# DateGranularity

`DateGranularity` is an option that determines the calendar granularity of generated dates.

## Examples

Set date granularity to month:

```wolfram
DateRange[{2020, 1, 1}, {2020, 12, 31}, DateGranularity -> "Month"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DateGranularity.html) for more details.*
