# SpanFromLeft

`SpanFromLeft` is a symbol that can appear at a particular position in a `Grid` or related construct to indicate that the corresponding position is occupied by a spanning element that appears to its left.

## Examples

Create a grid with a cell spanning two columns:

```wolfram
Grid[{{"Wide cell", SpanFromLeft}, {"a", "b"}}, Frame -> All]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SpanFromLeft.html) for more details.*
