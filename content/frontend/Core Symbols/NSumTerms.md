# NSumTerms

`NSumTerms` is an option for `NSum`. `NSumTerms -> n` explicitly includes n terms in the sum before extrapolation.

## Examples

```wolfram
NSum[1/n^2, {n, 1, Infinity}, NSumTerms -> 100]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NSumTerms.html) for more details.*
