# AutoItalicWords

`AutoItalicWords` is an option for `Cell` that gives a list of words that should automatically be put in italics when they are entered.

## Examples

Create a cell with automatic italicization:

```wolfram
Cell["Text", AutoItalicWords -> {"emphasis", "important"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AutoItalicWords.html) for more details.*
