# EdgeWeight

`EdgeWeight` is an option and annotation for `Graph` and related functions that specifies an edge weight.

## Examples

Create weighted graph:

```wolfram
Graph[{1 -> 2, 2 -> 3}, EdgeWeight -> {1, 2}]
```

Access edge weights:

```wolfram
PropertyValue[{g, 1 -> 2}, EdgeWeight]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EdgeWeight.html) for more details.*
