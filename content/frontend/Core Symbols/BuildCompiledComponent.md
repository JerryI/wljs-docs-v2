# BuildCompiledComponent

`BuildCompiledComponent[comp]` builds the compiled component comp.

`BuildCompiledComponent[comp, dest]` builds the compiled component comp, placing the result in dest.

## Examples

Build a compiled component:

```wolfram
BuildCompiledComponent[myComponent]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/BuildCompiledComponent.html) for more details.*
