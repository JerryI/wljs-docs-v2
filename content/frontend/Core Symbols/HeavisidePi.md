# HeavisidePi

```
HeavisidePi[x] represents the box distribution Π(x), equal to 1 for x<1/2 and 0 for x>1/2.

HeavisidePi[x1,x2,…] represents the multidimensional box distribution Π(x1,x2,…) which is 1 if all xi<1/2.
```
