# NProductFactors

`NProductFactors` is an option for `NProduct`. `NProductFactors -> n` explicitly includes n factors in the product before extrapolation.

## Examples

```wolfram
NProduct[1 + 1/i^2, {i, 1, Infinity}, NProductFactors -> 10]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NProductFactors.html) for more details.*
