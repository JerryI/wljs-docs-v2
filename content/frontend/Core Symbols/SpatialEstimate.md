# SpatialEstimate

```
SpatialEstimate[{loc1->val1,loc2->val2,…}] creates a spatial prediction from values vali given at locations loci. 

SpatialEstimate[{loc1,loc2,…}->{val1,val2,…}] generates the same result. 
```
