# NotebookEvaluate

`NotebookEvaluate[nb]` evaluates the initialization cells of the notebook and returns the result of the last Wolfram Language cell.

> **Note:** Not recommended to use! Consider `NotebookEvaluateAsync` instead.

## Examples

```wolfram
NotebookEvaluate["~/notebook.nb"]
```

```wolfram
NotebookEvaluate[NotebookOpen["example.nb"]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NotebookEvaluate.html) for more details.*
