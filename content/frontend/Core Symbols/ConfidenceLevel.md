# ConfidenceLevel

`ConfidenceLevel` is an option for LinearModelFit and other fitting functions that specifies the level to use in various confidence and prediction intervals and bands.

## Examples

Set a 99% confidence level:

```wolfram
LinearModelFit[data, x, x, ConfidenceLevel -> 0.99]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ConfidenceLevel.html) for more details.*
