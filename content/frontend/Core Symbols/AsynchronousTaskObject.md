# AsynchronousTaskObject

`AsynchronousTaskObject["name", id, sessionid]` is an object that represents asynchronous evaluations from a particular asynchronous task.

## Examples

Get task object from running tasks:

```wolfram
tasks = AsynchronousTasks[];
(* Returns list of AsynchronousTaskObject[...] *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AsynchronousTaskObject.html) for more details.*
