# NotTildeTilde

`NotTildeTilde[x,y,…]` displays as x≉y≉….

## Examples

Display a NotTildeTilde expression:

```wolfram
NotTildeTilde[a, b, c]
(* a ≉ b ≉ c *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NotTildeTilde.html) for more details.*
