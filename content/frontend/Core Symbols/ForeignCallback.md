# ForeignCallback

`ForeignCallback[func]` represents a foreign callback that can be called from external libraries loaded via `LibraryLink`.

## Examples

Create a callback function:

```wolfram
cb = ForeignCallback[Print]
(* ForeignCallback[...] *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ForeignCallback.html) for more details.*
