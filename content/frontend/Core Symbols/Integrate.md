# Integrate

`Integrate[f, x]` gives the indefinite integral.

`Integrate[f, {x, xmin, xmax}]` gives the definite integral.

## Examples

Indefinite integral:

```wolfram
Integrate[x^2, x]
(* x^3/3 *)
```

Definite integral:

```wolfram
Integrate[Sin[x], {x, 0, Pi}]
(* 2 *)
```
