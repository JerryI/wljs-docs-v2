# HodgeDual

```
HodgeDual[tensor] gives the Hodge dual of the tensor

HodgeDual[tensor,dim] dualizes tensor in the slots with dimension dim

HodgeDual[tensor,dim,slots] dualizes tensor in the given slots.
```
