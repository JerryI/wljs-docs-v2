# EdgeConnectivity

```
EdgeConnectivity[g] gives the edge connectivity of the graph g.

EdgeConnectivity[g,s,t] gives the s-t edge connectivity of the graph g.

EdgeConnectivity[{v->w,…},…] uses rules v->w to specify the graph g. 
```
