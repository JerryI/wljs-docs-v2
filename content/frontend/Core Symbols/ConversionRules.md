# ConversionRules

`ConversionRules` is an option for `Cell` that can be set to a list of rules specifying how the contents of the cell are to be converted to external formats.

## Examples

Set conversion rules for a cell:

```wolfram
Cell["text", ConversionRules -> {"HTML" -> "custom HTML"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ConversionRules.html) for more details.*
