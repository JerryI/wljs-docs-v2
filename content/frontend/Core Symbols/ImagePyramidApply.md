# ImagePyramidApply

```
ImagePyramidApply[f,pyr] applies f to all images in the ImagePyramid object pyr.

ImagePyramidApply[f,{pyr1,pyr2,…}] applies f to the sequence of corresponding levels taken from each pyri.
```
