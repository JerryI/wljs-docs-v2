# RegionPlot3D

```
RegionPlot3D[pred,{x,xmin,xmax},{y,ymin,ymax},{z,zmin,zmax}] makes a plot showing the three-dimensional region in which pred is True. 

RegionPlot3D[{pred1,pred2,…},…] plots several regions corresponding to the predi.
```
