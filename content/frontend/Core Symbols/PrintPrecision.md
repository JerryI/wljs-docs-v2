# PrintPrecision

`PrintPrecision` is an option for selections that specifies the maximum number of digits used for displaying a machine-precision number.

## Examples

```wolfram
N[Pi, 20] (* full precision *)
```

```wolfram
Style[N[Pi, 20], PrintPrecision -> 5]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PrintPrecision.html) for more details.*
