# Subset

`Subset[x, y, ...]` displays as x⊂y⊂….

## Examples

Display subset notation:

```wolfram
Subset[a, b, c]
(* a ⊂ b ⊂ c *)
```

Use in TraditionalForm:

```wolfram
TraditionalForm[Subset[A, B]]
```
