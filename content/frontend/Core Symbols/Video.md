# Video

`Video[file]` represents video stored in the given file.

- `Video[url]` represents video stored in the given URL.

## Examples

Load a video from a file:
```wolfram
Video["ExampleData/sampleVideo.mp4"]
```

Import a video from URL:
```wolfram
Video["https://example.com/video.mp4"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Video.html) for more details.*
