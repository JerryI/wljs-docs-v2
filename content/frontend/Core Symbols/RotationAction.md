# RotationAction

`RotationAction` is an option for three-dimensional graphics functions that specifies how to render 3D objects when they are interactively rotated.

## Examples

```wolfram
Graphics3D[Sphere[], RotationAction -> "Clip"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RotationAction.html) for more details.*
