# RegionBoundary

`RegionBoundary[reg]` represents the boundary of the region reg.

## Examples

Get the boundary of a disk:

```wolfram
RegionBoundary[Disk[]]
(* Circle[{0, 0}] *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RegionBoundary.html) for more details.*
