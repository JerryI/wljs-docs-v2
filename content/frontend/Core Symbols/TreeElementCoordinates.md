# TreeElementCoordinates

`TreeElementCoordinates` is an option for `Tree` and related functions that specifies the coordinates to use to place the center of subtree elements.

## Examples

```wolfram
Tree[{1, 2, 3}, TreeElementCoordinates -> Automatic]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TreeElementCoordinates.html) for more details.*
