# NotLeftTriangleEqual

`NotLeftTriangleEqual[x,y,…]` displays as x⋬y⋬….

## Examples

Display with not-left-triangle-equal notation:

```wolfram
NotLeftTriangleEqual[a, b]
(* a⋬b *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NotLeftTriangleEqual.html) for more details.*
