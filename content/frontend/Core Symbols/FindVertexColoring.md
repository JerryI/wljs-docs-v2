# FindVertexColoring

```
FindVertexColoring[g] finds a coloring with minimal size for the vertices in the graph g. 

FindVertexColoring[g,{c1,c2,…}] finds a coloring {c1,c2,…,ck} for the vertices in the graph g.
```
