# NotPrecedesEqual

`NotPrecedesEqual[x, y, ...]` displays as x⋠y⋠….

## Examples

```wolfram
NotPrecedesEqual[a, b]
```

```wolfram
NotPrecedesEqual[x, y, z] // TraditionalForm
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NotPrecedesEqual.html) for more details.*
