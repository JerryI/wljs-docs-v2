# ColorFunctionBinning

`ColorFunctionBinning` is an option for plotting functions that divides values into a limited set of bins for styling.

## Examples

```wolfram
DensityPlot[x + y, {x, 0, 1}, {y, 0, 1}, ColorFunctionBinning -> 5]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ColorFunctionBinning.html) for more details.*
