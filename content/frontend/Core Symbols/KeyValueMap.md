# KeyValueMap

```
KeyValueMap[f,<|key1->val1,key2->val2,…|>] gives the list {f[key1,val1],f[key2,val2],…}.

KeyValueMap[f] represents an operator form of KeyValueMap that can be applied to an expression.
```
