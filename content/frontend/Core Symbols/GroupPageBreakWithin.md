# GroupPageBreakWithin

`GroupPageBreakWithin` is an option for `Cell` that specifies whether a page break should be allowed within the group of cells if the notebook that contains the group is printed.

## Examples

```wolfram
Cell["Content", GroupPageBreakWithin -> False]
```

```wolfram
Cell["Example", "Text", GroupPageBreakWithin -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GroupPageBreakWithin.html) for more details.*
