# WienerFilter

```
WienerFilter[data,r] removes noise from data by applying a range-r Wiener filter.

WienerFilter[data,r,ns] assumes an additive noise power value ns.

WienerFilter[data,{r1,r2,…},…] uses radius ri at level i in data.
```
