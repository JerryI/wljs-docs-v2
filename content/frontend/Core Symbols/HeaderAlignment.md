# HeaderAlignment

`HeaderAlignment` is an option for `Dataset` that specifies how the contents of a header should be aligned within the available area in the header.

## Examples

```wolfram
Dataset[{{1, 2}, {3, 4}}, HeaderAlignment -> Center]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/HeaderAlignment.html) for more details.*
