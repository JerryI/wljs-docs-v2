# ContinuedFractionK

```
ContinuedFractionK[f,g,{i,imin,imax}] represents the continued fraction Κi=iminimaxf/g.

ContinuedFractionK[g,{i,imin,imax}] represents the continued fraction Κi=iminimax1/g.
```
