# FindEdgeColoring

```
FindEdgeColoring[g] finds a coloring with minimal size for the edges in the graph g.

FindEdgeColoring[g,{c1,c2,…}] finds a coloring {c1,c2,…,ck} for the edges in the graph g.
```
