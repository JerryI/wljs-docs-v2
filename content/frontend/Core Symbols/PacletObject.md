# PacletObject

`PacletObject[...]` is the representation of a paclet in the Wolfram Language.

## Examples

```wolfram
PacletObject["MyPaclet"]
```

```wolfram
PacletFind["PacletManager"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PacletObject.html) for more details.*
