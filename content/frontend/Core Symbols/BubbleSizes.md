# BubbleSizes

`BubbleSizes` is an option to BubbleChart and related functions that specifies the range of sizes used for bubbles.

## Examples

Customize bubble sizes:

```wolfram
BubbleChart[{{1, 2, 1}, {3, 4, 2}, {5, 1, 3}}, 
  BubbleSizes -> {0.05, 0.2}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/BubbleSizes.html) for more details.*
