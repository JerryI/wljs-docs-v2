# SocketWaitAll

`SocketWaitAll[{socket1,socket2,…}]` waits until there is data ready to read on all of the socketi.

## Examples

```wolfram
SocketWaitAll[{socket1, socket2}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SocketWaitAll.html) for more details.*
