# EdgeLabeling

`EdgeLabeling` is an option for `GraphPlot` and related functions that specifies whether labeling specified for edges should be displayed by default.

## Examples

Show edge labels in a graph plot:

```wolfram
GraphPlot[{1 -> 2, 2 -> 3}, EdgeLabeling -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EdgeLabeling.html) for more details.*
