# Backward

`Backward` is a symbol that represents the backward direction for purposes of motion and animation.

## Examples

Use in animation direction:

```wolfram
Animate[Plot[Sin[x + t], {x, 0, 2 Pi}], {t, 0, 2 Pi}, 
  AnimationDirection -> Backward]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Backward.html) for more details.*
