# SplicedDistribution

```
SplicedDistribution[{w1,w2,…,wn},{c0,c1,…,cn},{dist1,dist2,…,distn}] represents the distribution obtained by splicing the distributions dist1, dist2, … truncated on the intervals {c0,c1}, {c1,c2}, … with weights w1, w2, … .
```
