# RotateRight

`RotateRight[expr, n]` cycles the elements in expr n positions to the right.

`RotateRight[expr]` cycles one position to the right.

## Examples

Rotate right by 1:

```wolfram
RotateRight[{a, b, c, d, e}]
(* {e, a, b, c, d} *)
```

Rotate right by 2:

```wolfram
RotateRight[{a, b, c, d, e}, 2]
(* {d, e, a, b, c} *)
```
