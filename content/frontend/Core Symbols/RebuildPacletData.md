# RebuildPacletData

The experimental function `RebuildPacletData` is now obsolete and is superseded by `PacletDataRebuild`.

## Examples

```wolfram
(* Use PacletDataRebuild instead *)
PacletDataRebuild[]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RebuildPacletData.html) for more details.*
