# NumericArrayType

`NumericArrayType[array]` gives the underlying type of values used for each element in the NumericArray object.

## Examples

Get the type of a numeric array:

```wolfram
arr = NumericArray[{1, 2, 3}, "Integer32"];
NumericArrayType[arr]
(* "Integer32" *)
```
