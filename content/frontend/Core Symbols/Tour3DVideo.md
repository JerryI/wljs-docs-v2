# Tour3DVideo

`Tour3DVideo[g]` generates a video giving a standard tour around a 3D object *g*.

- `Tour3DVideo[g, tour]` generates the named video tour.
- `Tour3DVideo[g, steps]` generates a video tour from *steps*.

## Examples

```wolfram
Tour3DVideo[Graphics3D[Sphere[]]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Tour3DVideo.html) for more details.*
