# FourierSinTransform

```
FourierSinTransform[expr,t,ω] gives the symbolic Fourier sine transform of expr. 

FourierSinTransform[expr,{t1,t2,…},{ω1,ω2,…}] gives the multidimensional Fourier sine transform of expr. 
```
