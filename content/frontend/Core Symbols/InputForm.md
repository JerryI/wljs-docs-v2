# InputForm

`InputForm[expr]` prints expr in a form suitable for input to the Wolfram Language.

## Examples

Show input form:

```wolfram
InputForm[Sqrt[2]]
(* Sqrt[2] *)
```

```wolfram
InputForm[a/b + c]
(* c + a/b *)
```

Convert to string:

```wolfram
ToString[Pi, InputForm]
(* "Pi" *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/InputForm.html) for more details.*
