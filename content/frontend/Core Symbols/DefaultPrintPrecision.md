# DefaultPrintPrecision

`DefaultPrintPrecision` is an option for NumberForm, DecimalForm and related functions that specifies the default number of digits of precision with which to print machine numbers.

## Examples

Set default print precision:

```wolfram
NumberForm[Pi // N, DefaultPrintPrecision -> 10]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DefaultPrintPrecision.html) for more details.*
