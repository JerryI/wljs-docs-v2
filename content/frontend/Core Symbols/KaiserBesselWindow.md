# KaiserBesselWindow

`KaiserBesselWindow[x]` represents a Kaiser–Bessel window function of x.

## Examples

```wolfram
Plot[KaiserBesselWindow[x], {x, -1/2, 1/2}]
```

```wolfram
KaiserBesselWindow[0]
(* 1 *)
```
