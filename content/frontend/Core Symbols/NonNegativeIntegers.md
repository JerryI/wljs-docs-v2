# NonNegativeIntegers

`NonNegativeIntegers` represents the domain of non-negative integers, as in x ∈ NonNegativeIntegers.

## Examples

Test membership:

```wolfram
Element[0, NonNegativeIntegers]
(* True *)
```

Negative fails:

```wolfram
Element[-1, NonNegativeIntegers]
(* False *)
```
