# GaugeStyle

`GaugeStyle` is an option for gauge functions that specifies styles in which the markers are to be drawn.

## Examples

Style a gauge marker:

```wolfram
AngularGauge[75, GaugeStyle -> Red]
```

Use multiple styles:

```wolfram
BulletGauge[{50, 75}, GaugeStyle -> {Blue, Orange}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GaugeStyle.html) for more details.*
