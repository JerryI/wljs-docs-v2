# DelimiterMatching

`DelimiterMatching` is an option for selections that specifies whether an opening delimiter will match only its respective closing delimiter or any closing delimiter.

## Examples

Set delimiter matching behavior:

```wolfram
Cell["text", DelimiterMatching -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DelimiterMatching.html) for more details.*
