# LessThan

`LessThan[y]` is an operator form that yields `x < y` when applied to an expression `x`.

## Examples

```wolfram
LessThan[5][3]
```

```wolfram
Select[{1, 5, 10, 15}, LessThan[10]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LessThan.html) for more details.*
