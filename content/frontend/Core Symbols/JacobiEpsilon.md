# JacobiEpsilon

`JacobiEpsilon[u, m]` gives the Jacobi epsilon function ℰ(u|m).

The Jacobi epsilon function is related to elliptic integrals and is used in the theory of elliptic functions.

## Examples

```wolfram
JacobiEpsilon[0.5, 0.3]
```

```wolfram
N[JacobiEpsilon[1, 1/2]]
```

```wolfram
Plot[JacobiEpsilon[u, 0.5], {u, 0, 4}]
```

*See the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/JacobiEpsilon.html) for more details.*
