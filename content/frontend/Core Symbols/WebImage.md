# WebImage

`WebImage[url]` gives an image of the webpage specified by url.

- `WebImage[list]` gives images specified by URLs in list.

## Examples

Capture a screenshot of a webpage:
```wolfram
WebImage["https://www.wolfram.com"]
```

Capture multiple webpages:
```wolfram
WebImage[{"https://www.wolfram.com", "https://www.wolframalpha.com"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/WebImage.html) for more details.*
