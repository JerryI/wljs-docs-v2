# AtomLabelStyle

`AtomLabelStyle` is an option for `MoleculePlot` and `MoleculePlot3D` that specifies the style to use for atom labels.

## Examples

Custom atom label style:

```wolfram
MoleculePlot[Molecule["water"], AtomLabelStyle -> {Bold, 12}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AtomLabelStyle.html) for more details.*
