# HTTPRequestData

`HTTPRequestData["prop"]` gives the value of the specified property of the current HTTP request.

- `HTTPRequestData[]` gives an association with values of properties of the current HTTP request.

## Examples

```wolfram
HTTPRequestData["Method"]
```

```wolfram
HTTPRequestData["Body"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/HTTPRequestData.html) for more details.*
