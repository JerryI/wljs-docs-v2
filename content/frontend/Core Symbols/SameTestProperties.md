# SameTestProperties

`SameTestProperties` is an option for set operations on entity classes whose setting gives the properties that are used to decide whether two given entities are the same.

## Examples

```wolfram
EntityClassIntersection[class1, class2, SameTestProperties -> {"Name"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SameTestProperties.html) for more details.*
