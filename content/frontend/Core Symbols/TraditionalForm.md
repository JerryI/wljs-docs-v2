# TraditionalForm

`TraditionalForm[expr]` prints as an approximation to the traditional mathematical notation for expr.

## Examples

```wolfram
TraditionalForm[x^2 + 2x + 1]
(* Displays in traditional mathematical notation *)
```

```wolfram
TraditionalForm[Integrate[f[x], x]]
(* Displays as ∫f(x)dx *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TraditionalForm.html) for more details.*
