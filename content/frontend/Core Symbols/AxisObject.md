# AxisObject

`AxisObject[path]` is a Graphics primitive that represents an axis with a quantitative scale along the path path.

`AxisObject[path, scale]` uses the scale specified by scale.

## Examples

Create a horizontal axis:

```wolfram
Graphics[AxisObject[{{0, 0}, {1, 0}}, {0, 10}]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AxisObject.html) for more details.*
