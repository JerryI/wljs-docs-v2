# VectorLess

```
xy or VectorLess[{x,y}] yields True for vectors of length n if xi<yi for all components 1≤i≤n.

xκy or VectorLess[{x,y},κ] yields True for x and y if y-x∈interior(κ), where κ is a proper convex cone.
```
