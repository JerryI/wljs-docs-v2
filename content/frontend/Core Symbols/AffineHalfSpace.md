# AffineHalfSpace

```
AffineHalfSpace[{p1,…,pk+1},w] represents AffineSpace[{p1,…,pk+1}] extended in the direction w.

AffineHalfSpace[p,{v1,…,vk},w] represents AffineSpace[p,{v1,…,vk}] extended in the direction w.
```
