# RawMemoryFree

`RawMemoryFree[ptr]` frees the raw memory at a pointer ptr.

## Examples

```wolfram
ptr = RawMemoryAllocate["Integer64", 10];
RawMemoryFree[ptr]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RawMemoryFree.html) for more details.*
