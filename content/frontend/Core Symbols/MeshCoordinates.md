# MeshCoordinates

`MeshCoordinates[mreg]` gives a list of coordinates in the mesh region mreg.

## Examples

```wolfram
mr = MeshRegion[{{0, 0}, {1, 0}, {1, 1}}, Triangle[{1, 2, 3}]];
MeshCoordinates[mr]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MeshCoordinates.html) for more details.*
