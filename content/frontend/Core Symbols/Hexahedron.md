# Hexahedron

```
Hexahedron[{p1,p2,…,p8}] represents a filled hexahedron with corners p1, p2, …, p8.

Hexahedron[{{p1,1,p1,2,…,p1,8},{p2,1,…},…}] represents a collection of hexahedra.
```
