# ListDensityPlot

```
ListDensityPlot[{{f11,…,f1n},…,{fm1,…,fmn}}] generates a smooth density plot from an array of values fij.

ListDensityPlot[{{x1,y1,f1},…,{xk,yk,fk}}] generates a density plot with values fi defined at specified points {xi,yi}. 
```
