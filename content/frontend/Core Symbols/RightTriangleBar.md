# RightTriangleBar

`RightTriangleBar[x, y, ...]` displays as x⧐y⧐….

## Examples

```wolfram
RightTriangleBar[a, b]
```

```wolfram
RightTriangleBar[x, y, z] // TraditionalForm
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RightTriangleBar.html) for more details.*
