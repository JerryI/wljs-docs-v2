# RegisterExternalEvaluator

`RegisterExternalEvaluator[sys, evaluator]` registers the *evaluator* for use as an external evaluator with the language or system *sys*.

- `RegisterExternalEvaluator[sys, evaluator, name]` registers the evaluator using the assigned *name*.

## Examples

```wolfram
RegisterExternalEvaluator["Python", "/usr/bin/python3"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RegisterExternalEvaluator.html) for more details.*
