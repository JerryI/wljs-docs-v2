# LessEqualGreater

`LessEqualGreater[x, y, ...]` displays as x⋚y⋚....

## Examples

Display the less-equal-greater relation:

```wolfram
LessEqualGreater[a, b]
```

Multiple arguments:

```wolfram
LessEqualGreater[x, y, z]
```

In expressions:

```wolfram
Row[{"Compare: ", LessEqualGreater[1, 2, 3]}]
```
