# ArcTanh

`ArcTanh[z]` gives the inverse hyperbolic tangent tanh⁻¹(z) of the complex number z.

## Examples

Compute the inverse hyperbolic tangent:

```wolfram
ArcTanh[0.5]
(* 0.549306 *)
```

Symbolic evaluation:

```wolfram
ArcTanh[0]
(* 0 *)
```
