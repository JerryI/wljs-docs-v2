# Parallelogram

`Parallelogram[p,{v1,v2}]` represents a parallelogram with origin p and directions v1 and v2.

## Examples

Create a parallelogram:

```wolfram
Graphics[Parallelogram[{0, 0}, {{1, 0}, {0.5, 1}}]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Parallelogram.html) for more details.*
