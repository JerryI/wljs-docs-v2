# KirchhoffGraph

```
KirchhoffGraph[kmat] gives the graph with Kirchhoff matrix kmat.

KirchhoffGraph[{v1,v2,…},kmat] gives the graph with vertices vi and Kirchhoff matrix kmat.
```
