# PolarPlot

```
PolarPlot[r,{θ,θmin,θmax}] generates a polar plot of a curve with radius r as a function of angle θ.

PolarPlot[{r1,r2,…},{θ,θmin,θmax}] makes a polar plot of curves with radius functions r1, r2, ….
```
