# SymbolicDeltaProductArray

```
SymbolicDeltaProductArray[{n1,n2,…},{{j1,1,j1,2,…},{j2,1,j2,2,…},…}] represents an n1×n2×… array with elements ai1,i2,… equal to 1 if all ijp,1ijp,2…, and 0 otherwise.
```
