# Less

`x < y` yields `True` if x is less than y.

`x1 < x2 < x3` yields `True` if the values form a strictly increasing sequence.

## Examples

Comparison:

```wolfram
3 < 5
(* True *)

5 < 3
(* False *)
```

Chained comparison:

```wolfram
1 < 2 < 3
(* True *)
```
