# VertexAdd

```
VertexAdd[g,v] makes a graph by adding the vertex v to the graph g.

VertexAdd[g,{v1,v2,…}] adds a collection of vertices to g.

VertexAdd[{v->w,…},…] uses rules v->w to specify the graph g. 
```
