# GraphDisjointUnion

```
GraphDisjointUnion[g1,g2] gives the graph disjoint union of the graphs g1 and g2.

GraphDisjointUnion[g1,g2,…] gives the disjoint union of g1, g2, ….

GraphDisjointUnion[{v->w,…},…] uses rules v->w to specify the graph g.
```
