# LinearSolveFunction

`LinearSolveFunction[dimensions, data]` represents a function for providing solutions to a matrix equation.

## Examples

```wolfram
lsf = LinearSolve[{{1, 2}, {3, 4}}];
lsf[{5, 6}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LinearSolveFunction.html) for more details.*
