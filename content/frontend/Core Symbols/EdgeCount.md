# EdgeCount

```
EdgeCount[g] gives a count of the number of edges in the graph g.

EdgeCount[g,patt] gives a count of the number of edges that match the pattern patt.

EdgeCount[{v->w,…},…] uses rules v->w to specify the graph g. 
```
