# ArcCos

`ArcCos[z]` gives the arc cosine (inverse cosine) of `z`, returning a value in the range $0$ to $\pi$.

## Examples

Compute the arc cosine of common values:

```wolfram
ArcCos[1/2]
(* Pi/3 *)

ArcCos[0]
(* Pi/2 *)

N[ArcCos[0.5]]
(* 1.0472 *)
```
