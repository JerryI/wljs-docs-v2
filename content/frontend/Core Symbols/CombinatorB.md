# CombinatorB

`CombinatorB` represents the **B** combinator (composition combinator).

## Examples

Apply B combinator:

```wolfram
CombinatorB[f][g][x]
(* f[g[x]] *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CombinatorB.html) for more details.*
