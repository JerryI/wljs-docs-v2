# CircleDot

`CircleDot[x, y, ...]` displays as x⊙y⊙....

## Examples

Display with circle dot:

```wolfram
CircleDot[a, b]
(* a⊙b *)
```

Multiple elements:

```wolfram
CircleDot[x, y, z]
(* x⊙y⊙z *)
```
