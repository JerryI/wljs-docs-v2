# MaxPoints

`MaxPoints` is an option for `NIntegrate` specifying the maximum total number of times to sample the integrand.

## Examples

```wolfram
NIntegrate[Sin[x], {x, 0, Pi}, MaxPoints -> 1000]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MaxPoints.html) for more details.*
