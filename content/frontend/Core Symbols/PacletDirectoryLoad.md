# PacletDirectoryLoad

`PacletDirectoryLoad[dir]` makes paclets in dir visible in the current session.

`PacletDirectoryLoad[{dir1, dir2, ...}]` makes paclets in all the diri visible in the current session.

## Examples

Load paclets from a directory:

```wolfram
PacletDirectoryLoad["/path/to/paclets"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PacletDirectoryLoad.html) for more details.*
