# CanonicalName

`CanonicalName[entity]` gives the canonical name for the entity specified by entity.

`CanonicalName[{entity1, ..., entityn}]` gives the canonical name for entity1 through entityn.

## Examples

Get canonical name:

```wolfram
CanonicalName[Entity["Country", "UnitedStates"]]
(* "UnitedStates" *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CanonicalName.html) for more details.*
