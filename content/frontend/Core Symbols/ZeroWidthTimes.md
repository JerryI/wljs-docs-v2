# ZeroWidthTimes

`ZeroWidthTimes` is an option for selections that specifies whether blank spaces representing multiplication are explicitly shown.

## Examples

```wolfram
Style[x y, ZeroWidthTimes -> True]
```

```wolfram
Cell["x y", ZeroWidthTimes -> False]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ZeroWidthTimes.html) for more details.*
