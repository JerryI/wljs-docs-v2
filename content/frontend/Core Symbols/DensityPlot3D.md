# DensityPlot3D

```
DensityPlot3D[f,{x,xmin,xmax},{y,ymin,ymax},{z,zmin,zmax}] makes a density plot of f as a function of x, y, and z.

DensityPlot3D[f,{x,y,z}∈reg] takes the variables to be in the geometric region reg.
```
