# VerticalTilde

`VerticalTilde[x, y, ...]` displays as x≀y≀….

## Examples

```wolfram
VerticalTilde[a, b]
```

```wolfram
VerticalTilde[x, y, z] // TraditionalForm
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VerticalTilde.html) for more details.*
