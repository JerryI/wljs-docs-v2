# ExternalBundle

```
ExternalBundle[{name1->obj1,name2->obj2,…}] represents a bundle of resources to be externally deployed as named URLs, functions, etc. 

ExternalBundle[{name11->{name1->…,…},…}] represents a nested bundle of resources.
```
