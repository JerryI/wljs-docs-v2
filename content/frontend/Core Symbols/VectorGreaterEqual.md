# VectorGreaterEqual

```
xy or VectorGreaterEqual[{x,y}] yields True for vectors of length n if xi≥yi for all components 1≤i≤n.

xκy or VectorGreaterEqual[{x,y},κ] yields True for x and y if x-y∈κ, where κ is a proper convex cone.
```
