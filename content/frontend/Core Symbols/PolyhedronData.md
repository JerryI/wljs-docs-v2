# PolyhedronData

`PolyhedronData[poly, "property"]` gives the value of the specified property for the polyhedron named poly.

`PolyhedronData[poly]` gives an image of the polyhedron named poly.

## Examples

Display a polyhedron:

```wolfram
PolyhedronData["Dodecahedron"]
```

Get properties:

```wolfram
PolyhedronData["Icosahedron", "Vertices"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PolyhedronData.html) for more details.*
