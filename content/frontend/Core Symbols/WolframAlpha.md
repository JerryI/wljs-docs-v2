# WolframAlpha

`WolframAlpha["query"]` sends query to Wolfram|Alpha and imports the output.

- `WolframAlpha["query", format]` imports the output according to the specified format.

## Examples

Query Wolfram|Alpha:
```wolfram
WolframAlpha["population of France"]
```

Get result as plain text:
```wolfram
WolframAlpha["integrate x^2", "Result"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/WolframAlpha.html) for more details.*
