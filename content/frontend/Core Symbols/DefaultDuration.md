# DefaultDuration

`DefaultDuration` is an option to Animate and related functions that specifies the default total duration of the animation in seconds.

## Examples

Create an animation with a 5-second duration:

```wolfram
Animate[Plot[Sin[x + t], {x, 0, 2 Pi}], {t, 0, 2 Pi}, DefaultDuration -> 5]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DefaultDuration.html) for more details.*
