# ListDensityPlot3D

```
ListDensityPlot3D[farr] generates a smooth density plot from an array of values farr. 

ListDensityPlot3D[{{x1,y1,z1,f1},…,{xn,yn,zn,fn}}] generates a density plot with values fi at the specified points {xi,yi,zi}.
```
