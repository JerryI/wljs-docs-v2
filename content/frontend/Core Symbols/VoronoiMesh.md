# VoronoiMesh

```
VoronoiMesh[{p1,…,pn}] gives a MeshRegion representing the Voronoi mesh from the points p1, p2, ….

VoronoiMesh[{p1,…,pn},{{xmin,xmax},…}] clips the mesh to the bounds [xmin,xmax]×⋯.
```
