# WordSpacings

`WordSpacings` is an option for `WordCloud` that specifies the empty space to be added around each word.

## Examples

```wolfram
WordCloud[{"apple", "banana", "cherry"}, WordSpacings -> 5]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/WordSpacings.html) for more details.*
