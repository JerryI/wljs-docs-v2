# PlaceholderReplace

`PlaceholderReplace` is an option to `Paste` that determines whether to replace a selection placeholder with the selected contents.

## Examples

```wolfram
Paste["text", PlaceholderReplace -> True]
```

```wolfram
Options[Paste, PlaceholderReplace]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PlaceholderReplace.html) for more details.*
