# NotSubsetEqual

`NotSubsetEqual[x, y, ...]` displays as x⊈y⊈….

## Examples

```wolfram
NotSubsetEqual[a, b]
```

```wolfram
NotSubsetEqual[x, y, z] // TraditionalForm
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NotSubsetEqual.html) for more details.*
