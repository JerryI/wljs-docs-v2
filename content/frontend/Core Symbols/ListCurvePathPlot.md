# ListCurvePathPlot

`ListCurvePathPlot[{{x1, y1}, {x2, y2}, ...}]` plots a curve that corresponds to a smooth path through the specified points.

## Examples

Plot a smooth curve through points:

```wolfram
ListCurvePathPlot[{{0, 0}, {1, 1}, {2, 0}, {3, 1}}]
```

Plot points that form a closed curve:

```wolfram
ListCurvePathPlot[CirclePoints[5]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ListCurvePathPlot.html) for more details.*
