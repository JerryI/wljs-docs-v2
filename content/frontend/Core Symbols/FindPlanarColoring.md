# FindPlanarColoring

```
FindPlanarColoring[g] finds a coloring with minimal size for the faces of the planar graph g.

FindPlanarColoring[g,{c1,c2,…}] finds a coloring {c1,c2,…,ck} for the faces in the graph g.
```
