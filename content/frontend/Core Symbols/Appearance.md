# Appearance

`Appearance` is an option for displayed objects such as `Button` and `Slider` that specifies the general type of appearance they should have.

## Examples

Create a button with a specific appearance:

```wolfram
Button["Click Me", Print["Clicked"], Appearance -> "Frameless"]
```

Customize slider appearance:

```wolfram
Slider[0.5, Appearance -> "Labeled"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Appearance.html) for more details.*
