# AudioJoin

```
AudioJoin[audio1,audio2,…] or AudioJoin[{audio1,audio2,…}] concatenates all audioi and returns an audio object.

AudioJoin[{audio1,t1},{audio2,t2},…] inserts ti seconds of silence after each audioi.
```
