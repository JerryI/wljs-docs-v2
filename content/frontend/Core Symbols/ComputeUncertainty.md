# ComputeUncertainty

`ComputeUncertainty` is an option for `ClassifierMeasurements`, `LearnedDistribution` and other functions to specify if numeric results should be returned along with their uncertainty.

## Examples

Compute with uncertainty:

```wolfram
ClassifierMeasurements[classifier, data, "Accuracy", ComputeUncertainty -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ComputeUncertainty.html) for more details.*
