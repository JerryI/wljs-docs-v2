# TernaryPlotCorners

`TernaryPlotCorners` is an option for `TernaryListPlot` that determines how the triangle and axes are positioned.

## Examples

```wolfram
TernaryListPlot[{{0.3, 0.4, 0.3}}, TernaryPlotCorners -> Automatic]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TernaryPlotCorners.html) for more details.*
