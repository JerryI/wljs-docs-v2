# CompilerEnvironmentAppendTo

`CompilerEnvironmentAppendTo[{def1, def2, ...}]` appends declarations to `$CompilerEnvironment`.

`CompilerEnvironmentAppendTo[env, {def1, def2, ...}]` appends declarations to CompilerEnvironmentObject env.

## Examples

Append a declaration to the compiler environment:

```wolfram
CompilerEnvironmentAppendTo[{FunctionDeclaration[myFunc, ...]}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CompilerEnvironmentAppendTo.html) for more details.*
