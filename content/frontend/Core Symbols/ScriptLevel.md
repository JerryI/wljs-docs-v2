# ScriptLevel

`ScriptLevel` is an option for selections that is used in determining the font size of modifiers such as subscripts and superscripts in a nested expression.

## Examples

Set the script level for typesetting:

```wolfram
Style[Subscript[x, Subscript[y, z]], ScriptLevel -> 0]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ScriptLevel.html) for more details.*
