# MinColorDistance

`MinColorDistance` is an option for DominantColors that specifies the minimum distance between returned colors.

## Examples

Get dominant colors with minimum distance:

```wolfram
DominantColors[image, 5, MinColorDistance -> 0.3]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MinColorDistance.html) for more details.*
