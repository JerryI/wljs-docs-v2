# SpanCharacterRounding

`SpanCharacterRounding` is an option for selections that specifies the method used for rounding a spanning character when its size is to be adjusted.

## Examples

Set rounding method for spanning characters:

```wolfram
Style[expr, SpanCharacterRounding -> "Nearest"]
(* styled expression *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SpanCharacterRounding.html) for more details.*
