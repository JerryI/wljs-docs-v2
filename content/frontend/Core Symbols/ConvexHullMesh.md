# ConvexHullMesh

```
ConvexHullMesh[{p1,p2,…}] gives a BoundaryMeshRegion representing the convex hull from the points p1, p2, ….

ConvexHullMesh[mreg] gives the convex hull of the mesh region mreg.
```
