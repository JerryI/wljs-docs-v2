# CircleThrough

```
CircleThrough[{p1,p2,…}] represents a circle passing through the points pi.

CircleThrough[{p1,p2,…},q] represents a circle with center q.

CircleThrough[{p1,p2,…},q,r] represents a circle with radius r.
```
