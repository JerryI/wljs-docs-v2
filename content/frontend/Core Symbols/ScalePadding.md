# ScalePadding

`ScalePadding` is an option for gauge functions that specifies how much space to leave around the scale.

## Examples

Add padding to a gauge:
```wolfram
AngularGauge[75, ScalePadding -> 0.1]
```

No scale padding:
```wolfram
ThermometerGauge[50, ScalePadding -> 0]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ScalePadding.html) for more details.*
