# TransformationClass

`TransformationClass` is an option that specifies the class of geometric transformations to be used.

## Examples

```wolfram
ImageAlign[img1, img2, TransformationClass -> "Rigid"]
```

```wolfram
FindGeometricTransform[pts1, pts2, TransformationClass -> "Affine"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TransformationClass.html) for more details.*
