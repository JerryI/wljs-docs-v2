# UnilateralConvolve

```
UnilateralConvolve[f,g,u,t] gives the unilateral convolution with respect to u of the expressions f and g.

UnilateralConvolve[f,g,{u1,…,un},{t1,…,tn}] gives the multidimensional unilateral convolution.
```
