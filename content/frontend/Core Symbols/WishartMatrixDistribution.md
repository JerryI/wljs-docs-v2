# WishartMatrixDistribution

`WishartMatrixDistribution[ν, Σ]` represents a Wishart matrix distribution with ν degrees of freedom and covariance matrix Σ.

## Examples

```wolfram
dist = WishartMatrixDistribution[5, IdentityMatrix[3]]
```

```wolfram
RandomVariate[dist]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/WishartMatrixDistribution.html) for more details.*
