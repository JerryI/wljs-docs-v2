# TickPositions

`TickPositions` is an option for `AxisObject` that specifies where the tick marks should be positioned.

## Examples

Specify custom tick positions:

```wolfram
AxisObject[{{0, 0}, {1, 0}}, TickPositions -> {0, 0.5, 1}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TickPositions.html) for more details.*
