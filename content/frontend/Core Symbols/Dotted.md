# Dotted

`Dotted` is a graphics directive specifying that lines that follow should be drawn dotted.

## Examples

Draw a dotted line:

```wolfram
Graphics[{Dotted, Line[{{0, 0}, {1, 1}}]}]
(* Graphics with dotted line *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Dotted.html) for more details.*
