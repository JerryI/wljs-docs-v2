# BubbleScale

`BubbleScale` is an option to `BubbleChart` and related functions that specifies how the scale of each bubble should be determined from the value of each data element.

## Examples

Bubble chart with custom scale:

```wolfram
BubbleChart[{{1, 1, 1}, {2, 2, 4}, {3, 3, 9}}, BubbleScale -> "Area"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/BubbleScale.html) for more details.*
