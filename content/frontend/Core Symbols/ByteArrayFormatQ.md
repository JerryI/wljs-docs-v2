# ByteArrayFormatQ

```
ByteArrayFormatQ[ba,"fmt"] gives True if the ByteArray object ba might be imported as format "fmt" and gives False otherwise.

ByteArrayFormatQ[ba,{fmt1,fmt2,…}] gives True if ba might be imported as one of "fmti".
```
