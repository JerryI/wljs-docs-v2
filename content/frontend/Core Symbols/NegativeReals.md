# NegativeReals

`NegativeReals` represents the domain of strictly negative real numbers.

## Examples

Test membership:

```wolfram
Element[-3.14, NegativeReals]
(* True *)
```

Zero is not negative:

```wolfram
Element[0, NegativeReals]
(* False *)
```
