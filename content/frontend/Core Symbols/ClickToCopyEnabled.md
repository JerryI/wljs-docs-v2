# ClickToCopyEnabled

`ClickToCopyEnabled` is an option for `Cell` that specifies whether to show a click-to-copy overlay when hovering over a cell.

## Examples

Enable click-to-copy for a cell:

```wolfram
Cell["text", ClickToCopyEnabled -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ClickToCopyEnabled.html) for more details.*
