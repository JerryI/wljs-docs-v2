# ScaleRanges

`ScaleRanges` is an option for gauge functions that describes how to draw sections of the scale.

## Examples

Set colored scale ranges for a gauge:

```wolfram
AngularGauge[50, ScaleRanges -> {{0, 30, Green}, {30, 70, Yellow}, {70, 100, Red}}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ScaleRanges.html) for more details.*
