# RollPitchYawAngles

```
RollPitchYawAngles[r] gives the roll-pitch-yaw angles {α,β,γ} corresponding to the rotation matrix r.

RollPitchYawAngles[r,{a,b,c}] gives the roll-pitch-yaw angles {α,β,γ} corresponding to rotation order {a,b,c}.
```
