# EdgeCost

`EdgeCost` is an option and annotation for `Graph` and related functions that specifies an edge cost.

## Examples

Create a graph with edge costs:

```wolfram
Graph[{1 -> 2, 2 -> 3}, EdgeCost -> {1 -> 2 -> 5, 2 -> 3 -> 3}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EdgeCost.html) for more details.*
