# DefaultAxesStyle

`DefaultAxesStyle` is a low-level option for graphics functions that specifies the default style to use in displaying axes and axes-like constructs.

## Examples

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, DefaultAxesStyle -> Directive[Red, Thick]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DefaultAxesStyle.html) for more details.*
