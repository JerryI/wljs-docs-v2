# ImageSize

`ImageSize` is an option that specifies the overall size of an image to display for an object.

## Examples

Set fixed width:

```wolfram
Graphics[Circle[], ImageSize -> 200]
```

Set width and height:

```wolfram
Graphics[Circle[], ImageSize -> {200, 100}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ImageSize.html) for more details.*
