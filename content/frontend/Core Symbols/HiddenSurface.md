# HiddenSurface

`HiddenSurface` is an option for `SurfaceGraphics` which specifies whether hidden surfaces are to be eliminated.

## Examples

```wolfram
SurfaceGraphics[Table[Sin[x y], {x, 0, 3, 0.1}, {y, 0, 3, 0.1}], HiddenSurface -> True]
```

```wolfram
Options[SurfaceGraphics, HiddenSurface]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/HiddenSurface.html) for more details.*
