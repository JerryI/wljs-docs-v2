# Rectangle

```
Rectangle[{xmin,ymin},{xmax,ymax}] represents an axis-aligned filled rectangle from {xmin,ymin} to {xmax,ymax}.

Rectangle[{xmin,ymin}] corresponds to a unit square with its bottom-left corner at {xmin,ymin}.
```
