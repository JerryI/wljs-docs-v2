# AudioOutputDevice

`AudioOutputDevice` is an option for `Audio` and related functions that specifies the device to use for playback.

## Examples

Play audio on a specific device:

```wolfram
AudioPlay[audio, AudioOutputDevice -> "Built-in Output"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AudioOutputDevice.html) for more details.*
