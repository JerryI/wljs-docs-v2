# SSSTriangle

`SSSTriangle[a, b, c]` returns a filled triangle with sides of lengths a, b, and c.

## Examples

```wolfram
Graphics[SSSTriangle[3, 4, 5]]
```

```wolfram
SSSTriangle[1, 1, 1]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SSSTriangle.html) for more details.*
