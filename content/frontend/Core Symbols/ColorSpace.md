# ColorSpace

`ColorSpace` is an option for `Image` and related functions that specifies the color space to which color values refer.

## Examples

Get the color space of an image:

```wolfram
ColorSpace[ExampleData[{"TestImage", "Lena"}]]
(* "RGB" *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ColorSpace.html) for more details.*
