# SymmetricKey

`SymmetricKey[assoc]` represents all the information needed for encryption, decryption, and other operations in a symmetric cryptographic system.

## Examples

```wolfram
key = GenerateSymmetricKey[]
```

```wolfram
Encrypt[key, "Secret message"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SymmetricKey.html) for more details.*
