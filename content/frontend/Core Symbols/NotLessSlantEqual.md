# NotLessSlantEqual

`NotLessSlantEqual[x, y, ...]` displays as x⩽̸y….

## Examples

```wolfram
NotLessSlantEqual[a, b]
```

```wolfram
NotLessSlantEqual[x, y, z] // TraditionalForm
```
