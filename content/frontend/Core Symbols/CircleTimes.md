# CircleTimes

`CircleTimes[x]` displays as ⊗x.

`CircleTimes[x,y,…]` displays as x⊗y⊗….

## Examples

Display a single element with circle times:

```wolfram
CircleTimes[a]
(* ⊗a *)
```

Display multiple elements:

```wolfram
CircleTimes[a, b, c]
(* a⊗b⊗c *)
```
