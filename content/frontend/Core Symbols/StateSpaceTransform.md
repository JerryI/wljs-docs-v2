# StateSpaceTransform

```
StateSpaceTransform[sys,{p,q}] transforms the state-space model sys using the matrices p and q. 

StateSpaceTransform[sys,{{x1->p1[z],…},{z1->q1[x],…}}] transforms using the variable transformations {x1->p1[z],…} and {z1->q1[x],…}.
```
