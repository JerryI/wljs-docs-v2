# NotSucceeds

`NotSucceeds[x, y, ...]` displays as x⊁y⊁....

## Examples

Basic usage:

```wolfram
NotSucceeds[a, b]
```

Multiple arguments:

```wolfram
NotSucceeds[x, y, z]
```

In expressions:

```wolfram
NotSucceeds[f[x], g[y]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NotSucceeds.html) for more details.*
