# PerfectNumber

`PerfectNumber[n]` gives the nth perfect number.

## Examples

```wolfram
PerfectNumber[1]
(* 6 *)
```

```wolfram
PerfectNumber[4]
(* 8128 *)
```

```wolfram
Table[PerfectNumber[n], {n, 1, 5}]
(* {6, 28, 496, 8128, 33550336} *)
```
