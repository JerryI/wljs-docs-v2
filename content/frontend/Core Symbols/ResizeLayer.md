# ResizeLayer

```
ResizeLayer[{d}] represents a layer performing one-dimensional resizing of a two-dimensional array.

ResizeLayer[{d1,…,dn}] represents a layer performing n-dimensional resizing of a (n+1)-dimensional array.
```
