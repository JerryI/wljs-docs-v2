# QPochhammer

```
QPochhammer[a,q,n] gives the q-Pochhammer symbol (a;q)n.

QPochhammer[a,q] gives the q-Pochhammer symbol (a;q)∞.

QPochhammer[q] gives the q-Pochhammer symbol (q;q)∞.
```
