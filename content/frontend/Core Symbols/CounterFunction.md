# CounterFunction

`CounterFunction` is an option for counters that specifies the symbols used to display the value of the counter.

## Examples

Use Roman numerals for counter display:

```wolfram
CounterFunction -> (RomanNumeral[#] &)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CounterFunction.html) for more details.*
