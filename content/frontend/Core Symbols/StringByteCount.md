# StringByteCount

`StringByteCount["string"]` gives the total number of bytes used to store the characters in a string.

## Examples

```wolfram
StringByteCount["Hello"]
(* 5 *)
```

```wolfram
StringByteCount["日本語"]
(* 9 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/StringByteCount.html) for more details.*
