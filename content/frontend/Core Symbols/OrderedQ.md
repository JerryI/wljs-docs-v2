# OrderedQ

```
OrderedQ[h[e1,e2,…]] gives True if the ei are in canonical order, and False otherwise.

OrderedQ[h[e1,e2,…],p] uses the ordering function p to determine whether each pair of elements ei, ei+1 is in order. 
```
