# CoprimeQ

```
CoprimeQ[n1,n2] yields True if n1 and n2 are relatively prime, and yields False otherwise. 

CoprimeQ[n1,n2,…] yields True if all pairs of the ni are relatively prime, and yields False otherwise. 
```
