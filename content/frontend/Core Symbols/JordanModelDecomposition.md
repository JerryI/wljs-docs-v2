# JordanModelDecomposition

`JordanModelDecomposition[ssm]` yields the Jordan decomposition of the state-space model ssm.

## Examples

```wolfram
sys = StateSpaceModel[{{1, 1}, {0, 1}}, {{1}, {0}}, {{0, 1}}, {{0}}];
JordanModelDecomposition[sys]
```
