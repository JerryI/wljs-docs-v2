# DoubleVerticalBar

`DoubleVerticalBar[x, y, ...]` displays as x∥y∥....

## Examples

Display double vertical bar:

```wolfram
DoubleVerticalBar[a, b, c]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DoubleVerticalBar.html) for more details.*
