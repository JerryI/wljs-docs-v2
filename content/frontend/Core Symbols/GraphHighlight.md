# GraphHighlight

`GraphHighlight` is an option to `Graph` and related objects that specifies graph elements to highlight.

## Examples

```wolfram
Graph[{1 <-> 2, 2 <-> 3, 3 <-> 1}, GraphHighlight -> {1, 1 <-> 2}]
```

```wolfram
Graph[PetersenGraph[], GraphHighlight -> {1, 2, 3}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GraphHighlight.html) for more details.*
