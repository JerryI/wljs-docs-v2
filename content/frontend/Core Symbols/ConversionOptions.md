# ConversionOptions

`ConversionOptions` is an option to `Import` and `Export` used to pass special options to a particular format.

## Examples

Use conversion options for export:

```wolfram
Export["file.pdf", expr, ConversionOptions -> {"ImageResolution" -> 300}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ConversionOptions.html) for more details.*
