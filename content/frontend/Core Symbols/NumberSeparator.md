# NumberSeparator

`NumberSeparator` is an option for NumberForm and related functions that gives the string to insert at breaks between digits.

## Examples

Format a number with comma separators:

```wolfram
NumberForm[1234567, DigitBlock -> 3, NumberSeparator -> ","]
(* 1,234,567 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NumberSeparator.html) for more details.*
