# NumberPadding

`NumberPadding` is an option for `NumberForm` and related functions which gives strings to use as padding on the left‐ and right‐hand sides of numbers.

## Examples

```wolfram
NumberForm[1.5, {6, 2}, NumberPadding -> {"0", "0"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NumberPadding.html) for more details.*
