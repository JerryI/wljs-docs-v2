# SupersetEqual

`SupersetEqual[x, y, ...]` displays as x⊇y⊇….

## Examples

```wolfram
SupersetEqual[A, B]
```

```wolfram
SupersetEqual[{1, 2, 3}, {1, 2}] // TraditionalForm
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SupersetEqual.html) for more details.*
