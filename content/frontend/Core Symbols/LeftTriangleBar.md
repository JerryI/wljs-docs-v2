# LeftTriangleBar

`LeftTriangleBar[x, y, ...]` displays as x⧏y⧏….

## Examples

```wolfram
LeftTriangleBar[a, b]
```

```wolfram
LeftTriangleBar[x, y, z] // TraditionalForm
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LeftTriangleBar.html) for more details.*
