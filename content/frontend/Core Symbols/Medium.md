# Medium

`Medium` is a style or option setting that specifies that objects should be medium sized.

## Examples

Use medium-sized points:

```wolfram
Graphics[{PointSize[Medium], Point[{0, 0}]}]
```

Apply medium thickness to lines:

```wolfram
Graphics[{Thickness[Medium], Line[{{0, 0}, {1, 1}}]}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Medium.html) for more details.*
