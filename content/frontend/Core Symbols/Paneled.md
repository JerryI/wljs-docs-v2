# Paneled

`Paneled` is an option for Manipulate and related functions that specifies whether to give the output inside a panel.

## Examples

Create a Manipulate without a panel:

```wolfram
Manipulate[x^2, {x, 1, 10}, Paneled -> False]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Paneled.html) for more details.*
