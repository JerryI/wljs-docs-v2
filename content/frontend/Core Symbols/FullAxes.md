# FullAxes

`FullAxes[graphics]` returns the axes options of a graphics object.

## Examples

Get axes options from a plot:

```wolfram
FullAxes[Plot[Sin[x], {x, 0, 2 Pi}]]
```

Get axes from a 3D plot:

```wolfram
FullAxes[Plot3D[x^2 + y^2, {x, -1, 1}, {y, -1, 1}]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/FullAxes.html) for more details.*
