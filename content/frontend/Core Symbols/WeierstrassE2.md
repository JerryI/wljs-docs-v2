# WeierstrassE2

`WeierstrassE2[{g2, g3}]` gives the value e₂ of the Weierstrass elliptic function ℘ at the half-period ω₂(g2, g3).

## Examples

Compute the Weierstrass e2 value:
```wolfram
WeierstrassE2[{1, 0}]
```

Use with specific invariants:
```wolfram
WeierstrassE2[{4, 0}] // N
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/WeierstrassE2.html) for more details.*
