# RFixedPoints

```
RFixedPoints[eqn,a[n],n] gives the fixed points for a recurrence equation.

RFixedPoints[{eqn1,eqn2,…},{a1[n],a2[n],…},n] gives the fixed points for a system of recurrence equations.
```
