# GridGraph

```
GridGraph[{m,n}] gives the grid graph with m×n vertices Gm,n.

GridGraph[{n1,n2,…,nk}] gives the k-dimensional grid graph with n1×n2×⋯×nk vertices Gn1,n2,…,nk.
```
