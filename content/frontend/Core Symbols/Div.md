# Div

```
Div[{f1,…,fn},{x1,…,xn}] gives the divergence ∂f1/∂x1+…+∂fn/∂xn.

Div[{f1,…,fn},{x1,…,xn},chart] gives the divergence in the coordinates chart.
```
