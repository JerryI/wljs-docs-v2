# SurdForm

`SurdForm` is an option to `RadicalBox` and `SqrtBox` that indicates whether the radical represents a `Surd` expression.

## Examples

```wolfram
RadicalBox["8", "3", SurdForm -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SurdForm.html) for more details.*
