# EdgeContract

```
EdgeContract[g,e] contracts the edge e of the graph g.

EdgeContract[g,{e1,e2,…}] contracts a collection of edges e1,e2,….

EdgeContract[{v->w,…},…] uses rules v->w to specify the graph g. 
```
