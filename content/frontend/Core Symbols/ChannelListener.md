# ChannelListener

`ChannelListener[...]` represents a channel listener created by `ChannelListen`.

## Examples

```wolfram
listener = ChannelListen["myChannel", Print]
(* ChannelListener[...] *)
```

```wolfram
RemoveChannelListener[listener]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ChannelListener.html) for more details.*
