# DirectedGraph

```
DirectedGraph[g] gives a directed graph from the undirected graph g.

DirectedGraph[g,conv] gives a directed graph using the conversion conv.

DirectedGraph[{v->w,…},…] uses rules v->w to specify the graph g.
```
