# GaugeMarkers

`GaugeMarkers` is an option for gauge functions that specifies what markers to draw to mark the values.

## Examples

Use custom markers on a gauge:

```wolfram
AngularGauge[75, GaugeMarkers -> "Needle"]
```

Use different marker types:

```wolfram
HorizontalGauge[0.5, GaugeMarkers -> "Bar"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GaugeMarkers.html) for more details.*
