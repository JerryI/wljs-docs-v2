# Scale

```
Scale[g,s] represents graphics primitives g scaled by a factor s. 

Scale[g,s,{x,y,…}] scales with the point {x,y,…} kept fixed. 

Scale[g,{sx,sy,…},…] scales by different factors along different axes. 
```
