# SignPadding

`SignPadding` is an option for `NumberForm` and related functions that specifies whether padding should be inserted after signs.

## Examples

```wolfram
NumberForm[-12.3, {5, 2}, SignPadding -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SignPadding.html) for more details.*
