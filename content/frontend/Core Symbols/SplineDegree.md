# SplineDegree

`SplineDegree` is an option for spline functions and graphics primitives that specifies the degree of polynomial basis to use.

## Examples

```wolfram
BSplineCurve[{{0, 0}, {1, 2}, {2, 0}}, SplineDegree -> 2]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SplineDegree.html) for more details.*
