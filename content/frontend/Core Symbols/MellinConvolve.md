# MellinConvolve

```
MellinConvolve[f,g,x,y] gives the Mellin convolution with respect to x of the expressions f and g.

MellinConvolve[f,g,{x1,x2,…},{y1,y2,…}] gives the multidimensional Mellin convolution.
```
