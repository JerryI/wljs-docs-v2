# N

`N[expr]` gives the numerical value of expr.

`N[expr, n]` attempts to give a result with n-digit precision.

## Examples

Numerical approximation:

```wolfram
N[Pi]
(* 3.14159 *)
```

With specified precision:

```wolfram
N[Pi, 20]
(* 3.1415926535897932385 *)
```

```wolfram
N[Sqrt[2]]
(* 1.41421 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/N.html) for more details.*
