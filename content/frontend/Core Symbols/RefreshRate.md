# RefreshRate

`RefreshRate` is an option to `Animate` and related functions which specifies the refresh rate for frames in animations.

## Examples

```wolfram
Animate[Plot[Sin[x + t], {x, 0, 2 Pi}], {t, 0, 2 Pi}, RefreshRate -> 30]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RefreshRate.html) for more details.*
