# PrincipalValue

`PrincipalValue` is an option for Integrate that specifies whether the Cauchy principal value should be found for a definite integral.

## Examples

Compute the Cauchy principal value of an integral:

```wolfram
Integrate[1/x, {x, -1, 2}, PrincipalValue -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PrincipalValue.html) for more details.*
