# DiscreteAsymptotic

```
DiscreteAsymptotic[expr,n->∞] gives an asymptotic approximation for expr as n tends to infinity over the integers.

DiscreteAsymptotic[expr,{n,∞,m}] gives an asymptotic series approximation for expr to order m.
```
