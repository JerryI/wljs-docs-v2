# ImageFeatureTrack

```
ImageFeatureTrack[{image1,image2,…,imagen}] tracks features from image1 through imagen.

ImageFeatureTrack[{image1,image2,…,imagen},pts] tracks features starting from the initial set of points pts in image1.
```
