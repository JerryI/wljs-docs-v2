# DensityPlot

```
DensityPlot[f,{x,xmin,xmax},{y,ymin,ymax}] makes a density plot of f as a function of x and y. 

DensityPlot[f,{x,y}∈reg] takes the variables {x,y} to be in the geometric region reg. 
```
