# CreateTypeInstance

```
CreateTypeInstance[type,arg1,arg2,…] creates an instance of a type in compiled code.

CreateTypeInstance[productType,<|field1->x1,field2->x2,…|>] creates an instance of a product type and initializes its fields.
```
