# Limit

```
Limit[f,x->x*] gives the limit x->x*f(x). 

Limit[f,{x1->x1*,…,xn->xn*}] gives the nested limit +x1->x1*⋯ +xn->xn*f(x1,…,xn). 

Limit[f,{x1,…,xn}->{x1*,…,xn*}] gives the multivariate limit +{x1,…,xn}->{x1*,…,xn*}f(x1,…,xn).
```
