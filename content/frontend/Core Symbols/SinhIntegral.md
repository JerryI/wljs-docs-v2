# SinhIntegral

`SinhIntegral[z]` gives the hyperbolic sine integral function Shi(z).

## Examples

Evaluate at a numeric value:

```wolfram
SinhIntegral[2.0]
(* 2.50157 *)
```

Plot the function:

```wolfram
Plot[SinhIntegral[x], {x, -5, 5}]
(* Graphics[...] *)
```
