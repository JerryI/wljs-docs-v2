# ShortDownArrow

`ShortDownArrow[x, y, ...]` displays as x↓y↓….

## Examples

```wolfram
ShortDownArrow[a, b]
```

```wolfram
ShortDownArrow[x, y, z] // TraditionalForm
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ShortDownArrow.html) for more details.*
