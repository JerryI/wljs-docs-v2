# ResourceSubmit

`ResourceSubmit[resource]` submits the specified resource object to be reviewed for publication.

- `ResourceSubmit[new, old]` submits the resource new as the updated version of the resource old.

## Examples

```wolfram
ResourceSubmit[ResourceObject[...]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ResourceSubmit.html) for more details.*
