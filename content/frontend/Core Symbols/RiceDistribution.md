# RiceDistribution

`RiceDistribution[α, β]` represents a Rice distribution with shape parameters α and β.

- `RiceDistribution[m, α, β]` represents a Norton–Rice distribution with parameters m, α, and β.

## Examples

```wolfram
dist = RiceDistribution[1, 2];
Mean[dist]
```

```wolfram
RandomVariate[RiceDistribution[0.5, 1], 5]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RiceDistribution.html) for more details.*
