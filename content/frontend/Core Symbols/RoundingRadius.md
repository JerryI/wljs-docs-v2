# RoundingRadius

`RoundingRadius` is an option for `Rectangle`, `Framed` and related functions that specifies the radius of the circle to use in rendering rounded corners.

## Examples

```wolfram
Graphics[Rectangle[{0, 0}, {2, 1}, RoundingRadius -> 0.2]]
```

```wolfram
Framed["Hello", RoundingRadius -> 10]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RoundingRadius.html) for more details.*
