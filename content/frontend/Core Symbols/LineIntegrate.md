# LineIntegrate

```
LineIntegrate[f,{x,y,…}∈curve] computes the scalar line integral of the function f[x,y,…] over the curve.

LineIntegrate[{p,q,…},{x,y,…}∈curve] computes the vector line integral of the vector function {p[x,y,…],q[x,y,…],…}.
```
