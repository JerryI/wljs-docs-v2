# LessEqualThan

`LessEqualThan[y]` is an operator form that yields x≤y when applied to an expression x.

## Examples

Use as an operator:

```wolfram
LessEqualThan[5][3]
(* True *)
```

Filter a list:

```wolfram
Select[{1, 5, 8, 3, 10}, LessEqualThan[5]]
(* {1, 5, 3} *)
```
