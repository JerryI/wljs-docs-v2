# Forward

`Forward` is a symbol that represents the forward direction for purposes of motion and animation.

## Examples

Use Forward in an animation:

```wolfram
Animate[Graphics[{Disk[{t, 0}]}], {t, 0, 5, AnimationDirection -> Forward}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Forward.html) for more details.*
