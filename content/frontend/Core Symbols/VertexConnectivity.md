# VertexConnectivity

```
VertexConnectivity[g] gives the vertex connectivity of the graph g.

VertexConnectivity[g,s,t] gives the s-t vertex connectivity of the graph g.

VertexConnectivity[{v->w,…},…] uses rules v->w to specify the graph g.
```
