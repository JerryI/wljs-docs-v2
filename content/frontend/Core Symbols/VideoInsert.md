# VideoInsert

```
VideoInsert[video,t->new] inserts the video new at time t.

VideoInsert[video,{t1,t2,…}->new] inserts the same video at multiple positions.

VideoInsert[video,{t1->new1,…}] inserts multiple videos at different positions.
```
