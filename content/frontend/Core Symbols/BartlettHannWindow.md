# BartlettHannWindow

`BartlettHannWindow[x]` represents a Bartlett–Hann window function of x.

## Examples

Plot the Bartlett-Hann window:

```wolfram
Plot[BartlettHannWindow[x], {x, -1/2, 1/2}]
```

Evaluate at a specific point:

```wolfram
BartlettHannWindow[0]
(* 1 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/BartlettHannWindow.html) for more details.*
