# ResourceVersion

`ResourceVersion` is an option for `ResourceObject`, `ResourceFunction` and related functions for specifying the version of a resource.

## Examples

```wolfram
ResourceFunction["FibonacciQ", ResourceVersion -> "1.0.0"]
```

```wolfram
ResourceObject["MyResource", ResourceVersion -> "2.0"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ResourceVersion.html) for more details.*
