# NumberMultiplier

`NumberMultiplier` is an option for `NumberForm` and related functions which gives the string to use as a multiplication sign in scientific notation.

## Examples

```wolfram
NumberForm[1.23*10^6, NumberMultiplier -> "×"]
```

```wolfram
ScientificForm[123456.789, NumberMultiplier -> " * "]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NumberMultiplier.html) for more details.*
