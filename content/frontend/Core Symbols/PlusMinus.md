# PlusMinus

`PlusMinus[x]` displays as ±x.

- `PlusMinus[x, y, ...]` displays as x±y±....

## Examples

Display plus-minus notation:
```wolfram
PlusMinus[5]
```

Multiple arguments:
```wolfram
PlusMinus[a, b, c]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PlusMinus.html) for more details.*
