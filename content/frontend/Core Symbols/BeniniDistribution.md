# BeniniDistribution

`BeniniDistribution[α,β,σ]` represents a Benini distribution with shape parameters α and β and scale parameter σ.

## Examples

```wolfram
BeniniDistribution[1, 2, 1]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/BeniniDistribution.html) for more details.*
