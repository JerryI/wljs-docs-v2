# VertexCoordinateRules

`VertexCoordinateRules` is an option for `GraphPlot` and related functions which specifies rules for determining the coordinates at which vertices should be placed.

## Examples

```wolfram
GraphPlot[{1 -> 2, 2 -> 3}, VertexCoordinateRules -> {1 -> {0, 0}, 2 -> {1, 1}, 3 -> {2, 0}}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VertexCoordinateRules.html) for more details.*
