# ResamplingAlgorithmData

`ResamplingAlgorithmData[rs,"prop"]` gives the specified property "prop" for the resampling rs.

## Examples

Get properties from a resampling algorithm:

```wolfram
rs = ResamplingAlgorithmData["Bootstrap"];
ResamplingAlgorithmData[rs, "SampleSize"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ResamplingAlgorithmData.html) for more details.*
