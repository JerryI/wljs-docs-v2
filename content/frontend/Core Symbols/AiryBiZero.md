# AiryBiZero

`AiryBiZero[k]` represents the kth zero of the Airy function Bi(x).

`AiryBiZero[k, x0]` represents the kth zero less than x0.

## Examples

Get the first zero of AiryBi:

```wolfram
N[AiryBiZero[1]]
(* -1.17371 *)
```
