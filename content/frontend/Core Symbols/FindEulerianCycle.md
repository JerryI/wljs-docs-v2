# FindEulerianCycle

```
FindEulerianCycle[g] finds an Eulerian cycle in the graph g.

FindEulerianCycle[g,k] finds at most k Eulerian cycles.

FindEulerianCycle[{v->w,…},…] uses rules v->w to specify the graph g.
```
