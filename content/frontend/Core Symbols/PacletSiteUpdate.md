# PacletSiteUpdate

`PacletSiteUpdate[site]` acquires and caches current information about the available paclets on the given paclet site.

## Examples

```wolfram
PacletSiteUpdate["https://pacletserver.wolfram.com"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PacletSiteUpdate.html) for more details.*
