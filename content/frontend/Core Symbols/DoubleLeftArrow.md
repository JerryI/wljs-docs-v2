# DoubleLeftArrow

`DoubleLeftArrow[x, y, ...]` displays as x⇐y⇐….

## Examples

Display a double left arrow:

```wolfram
DoubleLeftArrow[a, b, c]
(* a ⇐ b ⇐ c *)
```
