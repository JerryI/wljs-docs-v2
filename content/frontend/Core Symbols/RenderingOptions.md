# RenderingOptions

`RenderingOptions` is an option for `Style`, `Cell` and related constructs that specifies options related to 3D rendering.

## Examples

```wolfram
Style[Graphics3D[Sphere[]], RenderingOptions -> {"3DRenderingMethod" -> "HardwareDepthBuffer"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RenderingOptions.html) for more details.*
