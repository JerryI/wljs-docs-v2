# DefineResourceFunction

`DefineResourceFunction[f]` defines a resource function that can be applied to arguments to give the same result as `f[...]`.

`DefineResourceFunction[f, name]` uses name as the name of the resource function.

## Examples

Define a resource function:

```wolfram
DefineResourceFunction[Mean, "MyMean"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DefineResourceFunction.html) for more details.*
