# ForwardBackward

`ForwardBackward` is a symbol that represents alternate forward and backward motion or animation.

## Examples

Use ForwardBackward animation direction:

```wolfram
Animate[Graphics[{Disk[{t, 0}]}], {t, 0, 5, AnimationDirection -> ForwardBackward}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ForwardBackward.html) for more details.*
