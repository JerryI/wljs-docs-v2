# MoleculeDraw

`MoleculeDraw[]` displays a window with interactive tools for drawing a Molecule, and returns the result.

`MoleculeDraw[mol]` displays a window that initially contains the Molecule mol.

## Examples

Open an empty molecule drawing window:

```wolfram
MoleculeDraw[]
```

Edit an existing molecule:

```wolfram
MoleculeDraw[Molecule["caffeine"]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MoleculeDraw.html) for more details.*
