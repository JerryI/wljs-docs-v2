# PercentForm

`PercentForm[expr]` prints with numbers in expr given as percentages.

`PercentForm[expr,n]` prints with approximate real numbers in expr given as percentages to n-digit precision.

## Examples

Display a number as a percentage:

```wolfram
PercentForm[0.25]
(* 25.% *)

PercentForm[1/3, 3]
(* 33.3% *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PercentForm.html) for more details.*
