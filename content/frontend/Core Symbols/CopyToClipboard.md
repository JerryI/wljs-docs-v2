# CopyToClipboard

`CopyToClipboard[expr]` replaces the contents of the clipboard with expr.

## Examples

Copy text to the clipboard:

```wolfram
CopyToClipboard["Hello, World!"]
```

Copy a computed result:

```wolfram
CopyToClipboard[N[Pi, 50]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CopyToClipboard.html) for more details.*
