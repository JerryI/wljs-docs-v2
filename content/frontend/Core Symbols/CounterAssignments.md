# CounterAssignments

`CounterAssignments` is an option for selections that sets the value of a specified counter.

## Examples

```wolfram
Cell["Section 5", "Section", CounterAssignments -> {"Section" -> 5}]
(* Cell with counter set to 5 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CounterAssignments.html) for more details.*
