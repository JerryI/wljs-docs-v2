# PlotDivision

`PlotDivision` is an option for `Plot` that specifies the maximum amount of subdivision to be used.

## Examples

```wolfram
Plot[Sin[1/x], {x, 0.01, 1}, PlotDivision -> 50]
```

```wolfram
Plot[Tan[x], {x, -Pi, Pi}, PlotDivision -> 100]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PlotDivision.html) for more details.*
