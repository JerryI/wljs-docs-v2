# DisplayFunction

`DisplayFunction` is an option for graphics and sound functions that specifies a function to apply to graphics and sound objects before returning them.

## Examples

Use Identity to return the graphics object:

```wolfram
Plot[Sin[x], {x, 0, 2Pi}, DisplayFunction -> Identity]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DisplayFunction.html) for more details.*
