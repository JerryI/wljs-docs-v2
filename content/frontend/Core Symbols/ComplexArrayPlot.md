# ComplexArrayPlot

`ComplexArrayPlot[array]` generates a plot in which complex values zij in an array are shown in a discrete array of squares with Arg[zij] indicated by color and Abs[zij] by shading.

## Examples

Plot a complex array:

```wolfram
ComplexArrayPlot[Table[x + I y, {x, -2, 2}, {y, -2, 2}]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ComplexArrayPlot.html) for more details.*
