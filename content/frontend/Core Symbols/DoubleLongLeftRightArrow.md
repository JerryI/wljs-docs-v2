# DoubleLongLeftRightArrow

`DoubleLongLeftRightArrow[x, y, ...]` displays as x⟺y⟺....

## Examples

Display double long left-right arrow:

```wolfram
DoubleLongLeftRightArrow[a, b, c]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DoubleLongLeftRightArrow.html) for more details.*
