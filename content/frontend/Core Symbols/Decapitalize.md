# Decapitalize

`Decapitalize[string]` yields a string in which the first character has been made lowercase.

## Examples

Lowercase the first character:

```wolfram
Decapitalize["Hello World"]
(* "hello World" *)
```

With all-caps input:

```wolfram
Decapitalize["HELLO"]
(* "hELLO" *)
```
