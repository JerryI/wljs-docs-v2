# VectorLessEqual

```
xy or VectorLessEqual[{x,y}] yields True for vectors of length n if xi≤yi for all components 1≤i≤n.

xκy or VectorLessEqual[{x,y},κ] yields True for x and y if y-x∈κ, where κ is a proper convex cone.
```
