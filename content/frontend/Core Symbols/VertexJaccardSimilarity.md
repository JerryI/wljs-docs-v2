# VertexJaccardSimilarity

```
VertexJaccardSimilarity[g,u,v] gives the Jaccard similarity between vertices u and v of the graph g.

VertexJaccardSimilarity[{v->w,…},…] uses rules v->w to specify the graph g. 
```
