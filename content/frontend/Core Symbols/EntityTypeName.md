# EntityTypeName

`EntityTypeName[entity]` gives the name of the entity type of entity.

`EntityTypeName[{entity1, ..., entityn}]` gives the name of the entity type for entity1 through entityn.

## Examples

Get entity type name:

```wolfram
EntityTypeName[Entity["Country", "France"]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EntityTypeName.html) for more details.*
