# WignerD

```
WignerD[{j,m1,m2},ψ,θ,ϕ] gives the Wigner D-function Dm1,m2j(ψ,θ,ϕ).

WignerD[{j,m1,m2},θ,ϕ] gives the Wigner D-function Dm1,m2j(0,θ,ϕ).

WignerD[{j,m1,m2},θ] gives the Wigner D-function Dm1,m2j(0,θ,0).
```
