# ConnectLibraryCallbackFunction

`ConnectLibraryCallbackFunction[mname, cf]` connects a CompiledFunction cf with the library callback manager with name mname.

## Examples

Connect a library callback function:

```wolfram
ConnectLibraryCallbackFunction["myManager", compiledFunc]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ConnectLibraryCallbackFunction.html) for more details.*
