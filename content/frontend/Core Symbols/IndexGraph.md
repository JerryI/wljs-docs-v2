# IndexGraph

```
IndexGraph[g] replaces the vertices of the graph g by its vertex indices.

IndexGraph[g,r] replaces the vertices with integers r,  r+1, ….

IndexGraph[{v->w,…},…] uses rules v->w to specify the graph g. 
```
