# LaplacianPDETerm

`LaplacianPDETerm[vars]` represents a Laplacian term ∇²u with model variables vars.

`LaplacianPDETerm[vars, pars]` uses model parameters pars.

## Examples

```wolfram
LaplacianPDETerm[{u[x, y], {x, y}}]
(* LaplacianPDETerm[{u[x, y], {x, y}}] *)
```
