# BarSpacing

`BarSpacing` is an option to `BarChart` and related functions that controls the spacing between bars and groups of bars.

## Examples

Set bar spacing:

```wolfram
BarChart[{1, 2, 3, 4}, BarSpacing -> 0.5]
```

No spacing:

```wolfram
BarChart[{1, 2, 3, 4}, BarSpacing -> 0]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/BarSpacing.html) for more details.*
