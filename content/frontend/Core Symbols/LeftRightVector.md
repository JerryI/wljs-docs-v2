# LeftRightVector

`LeftRightVector[x, y, ...]` displays as x⥎y⥎….

## Examples

```wolfram
LeftRightVector[a, b]
```

```wolfram
LeftRightVector[x, y, z] // TraditionalForm
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LeftRightVector.html) for more details.*
