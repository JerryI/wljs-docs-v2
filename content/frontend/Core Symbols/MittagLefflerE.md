# MittagLefflerE

`MittagLefflerE[α, z]` gives the Mittag–Leffler function $E_α(z)$.

- `MittagLefflerE[α, β, z]` gives the generalized Mittag–Leffler function $E_{α,β}(z)$.

## Examples

```wolfram
MittagLefflerE[1, 1]
```

```wolfram
MittagLefflerE[0.5, 1.0, 0.5] // N
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MittagLefflerE.html) for more details.*
