# MissingStyle

`MissingStyle` is an option for `GeoRegionValuePlot` that specifies how locations with missing data should be displayed.

## Examples

Display missing regions in gray:
```wolfram
GeoRegionValuePlot[data, MissingStyle -> Gray]
```

Hide missing regions:
```wolfram
GeoRegionValuePlot[data, MissingStyle -> None]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MissingStyle.html) for more details.*
