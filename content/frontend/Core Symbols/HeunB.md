# HeunB

`HeunB[q, α, γ, δ, ϵ, z]` gives the bi-confluent Heun function.

## Examples

```wolfram
HeunB[1, 2, 3, 4, 5, 0.5]
```

```wolfram
Plot[HeunB[1, 1, 1, 1, 1, x], {x, -2, 2}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/HeunB.html) for more details.*
