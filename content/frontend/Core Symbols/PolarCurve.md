# PolarCurve

`PolarCurve[r, {θ, θmin, θmax}]` gives a polar curve with radius r as a function of angle θ.

## Examples

Create a polar curve:
```wolfram
PolarCurve[1 + Cos[θ], {θ, 0, 2 Pi}]
```

Spiral curve:
```wolfram
PolarCurve[θ, {θ, 0, 4 Pi}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PolarCurve.html) for more details.*
