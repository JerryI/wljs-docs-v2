# PetersenGraph

`PetersenGraph[n, k]` gives the generalized Petersen graph P(n, k).

## Examples

Classic Petersen graph:

```wolfram
PetersenGraph[5, 2]
```

Different parameters:

```wolfram
PetersenGraph[7, 3]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PetersenGraph.html) for more details.*
