# LightYellow

`LightYellow` represents a light yellow color in graphics or style specifications.

## Examples

```wolfram
Graphics[{LightYellow, Disk[]}]
```

```wolfram
Style["Hello", Background -> LightYellow]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LightYellow.html) for more details.*
