# ImageLabels

`ImageLabels` is an option for image highlighting that specifies what labels to use for each highlighted feature.

## Examples

```wolfram
HighlightImage[img, objs, ImageLabels -> {"A", "B", "C"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ImageLabels.html) for more details.*
