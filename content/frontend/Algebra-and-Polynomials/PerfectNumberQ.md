---
title: PerfectNumberQ
---

`PerfectNumberQ[n]` returns `True` if n is a perfect number, and `False` otherwise.

## Examples

Test for perfect number:

```wolfram
PerfectNumberQ[6]
(* True *)
```

Non-perfect number:

```wolfram
PerfectNumberQ[10]
(* False *)
```
