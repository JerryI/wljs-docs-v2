title: Integer
---

`Integer` is the head used for integers.

## Examples

Check if a value is an integer:

```wolfram
Head[42]
(* Integer *)
```

Test for integer type:

```wolfram
IntegerQ[42]
(* True *)
```

```wolfram
IntegerQ[3.14]
(* False *)
```
