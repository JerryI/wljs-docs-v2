`McLaughlinGroupMcL[]` represents the sporadic simple McLaughlin group McL.

## Examples

Create the McLaughlin group:

```wolfram
McLaughlinGroupMcL[]
```

Get the group order:

```wolfram
GroupOrder[McLaughlinGroupMcL[]]
(* 898128000 *)
```

Check properties:

```wolfram
FiniteGroupData["McLaughlinGroup", "SimpleGroupQ"]
(* True *)
```
