---
title: CompositeQ
---

`CompositeQ[n]` yields True if n is a composite number, and yields False otherwise.

## Examples

Check if a number is composite:

```wolfram
CompositeQ[15]
(* True *)

CompositeQ[7]
(* False *)
```
