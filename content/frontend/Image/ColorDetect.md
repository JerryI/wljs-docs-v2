---
title: ColorDetect
---

`ColorDetect[image, cspec]` returns a mask image representing regions in image with colors within the specified color region.

## Examples

Detect red regions in an image:

```wolfram
ColorDetect[img, Red]
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ColorDetect.html) for more details.
