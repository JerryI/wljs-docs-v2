---
title: LinearGradientImage
---
```wolfram
LinearGradientImage[{__RGBColor}]
```

```wolfram
LinearGradientImage[{pos1, pos2} -> col]
```

```wolfram
LinearGradientImage[..., size]
```

generates a static [Image](../Image/Image) filled with gradient using the provided data.

For example
```wolfram
LinearGradientImage[{Blue, Yellow, Red}]
```
