---
title: GeoModel
---

`GeoModel` is an option for `GeoGraphics` that specifies the reference body or model for it for the purposes of geodetic computations and map drawing.

## Examples

```wolfram
GeoGraphics[{}, GeoModel -> "Moon"]
```

```wolfram
GeoGraphics[{}, GeoModel -> "Mars"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GeoModel.html) for more details.*
