---
title: GeoZoomLevel
---

`GeoZoomLevel` is an option for specifying the resolution at which to render a map.

## Examples

```wolfram
GeoGraphics[{}, GeoZoomLevel -> 5]
```

```wolfram
GeoGraphics[Entity["Country", "France"], GeoZoomLevel -> 8]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GeoZoomLevel.html) for more details.*
