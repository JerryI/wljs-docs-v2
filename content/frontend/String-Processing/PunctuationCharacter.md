---
title: PunctuationCharacter
---

`PunctuationCharacter` represents a punctuation character in `StringExpression`.

## Examples

```wolfram
StringMatchQ["!", PunctuationCharacter]
```

```wolfram
StringCases["Hello, World!", PunctuationCharacter]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PunctuationCharacter.html) for more details.*
