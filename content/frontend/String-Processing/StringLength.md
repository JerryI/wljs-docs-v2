---
title: StringLength
---

`StringLength["string"]` gives the number of characters in a string.

## Examples

Length of a string:

```wolfram
StringLength["Hello World"]
(* 11 *)
```

Empty string:

```wolfram
StringLength[""]
(* 0 *)
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/StringLength.html) for more details.
