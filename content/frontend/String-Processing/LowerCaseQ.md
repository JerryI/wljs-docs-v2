---
title: LowerCaseQ
---

`LowerCaseQ[string]` yields `True` if all the characters in the string are lowercase letters, and yields `False` otherwise.

## Examples

```wolfram
LowerCaseQ["hello"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LowerCaseQ.html) for more details.*
