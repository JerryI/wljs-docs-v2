---
title: DictionaryWordQ
---

`DictionaryWordQ["word"]` tests whether "word" is a recognized dictionary word.

## Examples

Check if a word is in the dictionary:

```wolfram
DictionaryWordQ["hello"]
(* True *)
```

Check a non-word:

```wolfram
DictionaryWordQ["asdfgh"]
(* False *)
```
