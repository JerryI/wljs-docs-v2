---
title: Synonyms
---

`Synonyms["word"]` returns the synonyms associated with the specified word.

## Examples

Find synonyms of a word:

```wolfram
Synonyms["happy"]
(* {"joyful", "content", "pleased", ...} *)
```

Synonyms for a verb:

```wolfram
Synonyms["run"]
(* {"sprint", "dash", "jog", ...} *)
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Synonyms.html) for more details.
