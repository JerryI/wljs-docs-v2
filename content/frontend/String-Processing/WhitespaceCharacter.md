---
title: WhitespaceCharacter
---

`WhitespaceCharacter` represents a single whitespace character in `StringExpression`.

## Examples

```wolfram
StringMatchQ[" ", WhitespaceCharacter]
(* True *)
```

```wolfram
StringSplit["hello world", WhitespaceCharacter..]
(* {"hello", "world"} *)
```
