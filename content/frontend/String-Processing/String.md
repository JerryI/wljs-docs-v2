---
title: String
---

`String` is the head of a character string "text".

## Examples

Check if an expression is a string:

```wolfram
Head["hello"]
(* String *)
```

Test with pattern:

```wolfram
MatchQ["hello", _String]
(* True *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/String.html) for more details.*
