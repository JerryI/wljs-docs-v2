---
title: StringReverse
---

`StringReverse["string"]` reverses the order of characters in the string.

## Examples

Reverse a string:

```wolfram
StringReverse["Hello"]
(* "olleH" *)
```

Check for palindrome:

```wolfram
StringReverse["racecar"] === "racecar"
(* True *)
```
