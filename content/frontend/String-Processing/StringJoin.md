---
title: StringJoin
---

`StringJoin["s1", "s2", ...]` or `"s1" <> "s2" <> ...` yields a string consisting of the concatenation of the strings.

## Examples

Join strings:

```wolfram
StringJoin["Hello", " ", "World"]
(* "Hello World" *)
```

Using the `<>` operator:

```wolfram
"Hello" <> " " <> "World"
(* "Hello World" *)
```
