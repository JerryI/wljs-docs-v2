---
title: WordList
---

`WordList[]` gives a list of common words.

- `WordList[type]` gives a list of words of the specified type.

## Examples

```wolfram
WordList[]
```

```wolfram
WordList["CommonWords"]
```

```wolfram
WordList["KnownWords"]
```

*See the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/WordList.html) for more details.*
