---
title: LetterQ
---

`LetterQ[string]` yields `True` if all the characters in the string are letters, and `False` otherwise.

## Examples

Check if all characters are letters:

```wolfram
LetterQ["Hello"]
(* True *)
```

String with numbers:

```wolfram
LetterQ["Hello123"]
(* False *)
```
