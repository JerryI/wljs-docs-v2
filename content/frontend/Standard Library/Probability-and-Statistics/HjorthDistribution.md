---
title: HjorthDistribution
---

`HjorthDistribution[m, s, f]` represents the Hjorth distribution with location parameter m, scale parameter s, and shape parameter f.

## Examples

Plot the PDF of a Hjorth distribution:

```wolfram
Plot[PDF[HjorthDistribution[0, 1, 2], x], {x, 0, 5}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/HjorthDistribution.html) for more details.*
