# SurvivalModelFit

`SurvivalModelFit[{e1, e2, ...}]` creates a survival model for event times ei.

## Examples

```wolfram
model = SurvivalModelFit[{1, 2, 3, 5, 7, 10}]
```

```wolfram
model["SurvivalFunction"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SurvivalModelFit.html) for more details.*
