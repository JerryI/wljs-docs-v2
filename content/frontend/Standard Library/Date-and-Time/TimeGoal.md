---
title: TimeGoal
---

`TimeGoal` is an option for various functions that specifies how long to spend doing a particular operation.

## Examples

```wolfram
NMinimize[x^4 - 3 x^2 + x, x, TimeGoal -> 5]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TimeGoal.html) for more details.*
