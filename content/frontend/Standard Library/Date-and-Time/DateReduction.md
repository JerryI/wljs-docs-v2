# DateReduction

`DateReduction` is an option for `DateHistogram` that specifies the length for cyclic periods of time.

## Examples

```wolfram
DateHistogram[DateRange["Jan 1, 2020", "Dec 31, 2025"], DateReduction -> "Month"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DateReduction.html) for more details.*
