---
title: ColorOutput
---

`ColorOutput` is an option for graphics functions that specifies the type of color output to produce.

## Examples

Specify grayscale output:

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, ColorOutput -> GrayLevel]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ColorOutput.html) for more details.*
