---
title: Proportional
---

`Proportional[x, y, ...]` displays as x∝y∝....

## Examples

Basic usage:

```wolfram
Proportional[a, b]
```

Multiple arguments:

```wolfram
Proportional[x, y, z]
```

In expressions:

```wolfram
Proportional[F, m]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Proportional.html) for more details.*
