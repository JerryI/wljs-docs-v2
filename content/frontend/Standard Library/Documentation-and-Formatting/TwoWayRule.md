# TwoWayRule

`x <-> y` or `TwoWayRule[x, y]` represents a two-way rule expressing exchange or correspondence of x and y.

## Examples

```wolfram
Graph[{1 <-> 2, 2 <-> 3, 3 <-> 1}]
```

```wolfram
TwoWayRule["A", "B"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TwoWayRule.html) for more details.*
