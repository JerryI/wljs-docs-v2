# OutputForm

`OutputForm[expr]` prints a 2D representation using only keyboard characters.

## Examples

Show output form:

```wolfram
OutputForm[a/b]
(* a/b *)
```

```wolfram
OutputForm[Sqrt[x]]
(* Sqrt[x] *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/OutputForm.html) for more details.*
