# LeftArrow

`LeftArrow[x, y, ...]` displays as x←y←....

## Examples

Display left arrow notation:
```wolfram
LeftArrow[a, b, c]
```

Use in expressions:
```wolfram
LeftArrow[x, y]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LeftArrow.html) for more details.*
