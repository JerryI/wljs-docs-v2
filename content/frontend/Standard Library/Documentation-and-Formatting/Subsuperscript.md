---
title: Subsuperscript
---

`Subsuperscript[x, y, z]` is an object that formats as x with subscript y and superscript z.

## Examples

Basic subscript and superscript:

```wolfram
Subsuperscript[a, i, 2]
```

In expressions:

```wolfram
Subsuperscript[x, n, m] + Subsuperscript[y, k, j]
```

With symbols:

```wolfram
Subsuperscript[\[Gamma], \[Mu], \[Nu]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Subsuperscript.html) for more details.*
