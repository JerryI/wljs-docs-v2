---
title: PromptForm
---

`PromptForm[prompt, expr]` prints as an output prompt and expression.

## Examples

```wolfram
PromptForm["In[1]:= ", x + y]
```

```wolfram
PromptForm["Out[1]= ", 42]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PromptForm.html) for more details.*
