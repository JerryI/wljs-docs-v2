# Colon

`Colon[x, y, ...]` displays as x∶y∶....

## Examples

Display with colon notation:

```wolfram
Colon[a, b]
(* a∶b *)
```

Multiple elements:

```wolfram
Colon[x, y, z]
(* x∶y∶z *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Colon.html) for more details.*
