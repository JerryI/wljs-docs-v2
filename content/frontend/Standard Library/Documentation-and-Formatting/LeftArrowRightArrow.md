---
title: LeftArrowRightArrow
---

`LeftArrowRightArrow[x, y, …]` displays as x ⇆ y ⇆ ….

## Examples

```wolfram
LeftArrowRightArrow[a, b]
```

```wolfram
LeftArrowRightArrow[x, y, z]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LeftArrowRightArrow.html) for more details.*
