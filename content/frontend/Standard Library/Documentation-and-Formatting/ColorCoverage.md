# ColorCoverage

`ColorCoverage` is an option for `DominantColors` that specifies the minimum image coverage that each color cluster should have.

## Examples

Get dominant colors with minimum coverage:

```wolfram
DominantColors[img, ColorCoverage -> 0.1]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ColorCoverage.html) for more details.*
