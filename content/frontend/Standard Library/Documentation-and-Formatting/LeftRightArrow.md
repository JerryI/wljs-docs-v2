# LeftRightArrow

`LeftRightArrow[x, y, ...]` displays as x↔y↔….

This is a symbolic representation that displays as a bidirectional arrow, commonly used to indicate equivalence or bidirectional relationships.

## Examples

```wolfram
LeftRightArrow[a, b]
```

```wolfram
LeftRightArrow[x, y, z]
```

```wolfram
x \[LeftRightArrow] y
```

*See the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LeftRightArrow.html) for more details.*
