# SubsetQ

`SubsetQ[list1, list2]` yields True if list2 is a subset of list1, and False otherwise.

## Examples

Test for subset:

```wolfram
SubsetQ[{1, 2, 3, 4, 5}, {2, 3}]
(* True *)
```

Not a subset:

```wolfram
SubsetQ[{1, 2, 3}, {3, 4}]
(* False *)
```
