# LongForm

`LongForm` is an option for `Information`. With `LongForm -> True`, the full information of a symbol is printed. With `LongForm -> False` the usage of a symbol is printed.

## Examples

```wolfram
Information[Sin, LongForm -> False]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LongForm.html) for more details.*
