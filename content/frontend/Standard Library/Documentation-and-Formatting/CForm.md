---
title: CForm
---

`CForm[expr]` prints expr in C language syntax.

## Examples

Convert to C code:

```wolfram
CForm[x^2 + y^2]
(* Power(x,2) + Power(y,2) *)
```

```wolfram
CForm[Sin[x] + Cos[y]]
(* Cos(y) + Sin(x) *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CForm.html) for more details.*
