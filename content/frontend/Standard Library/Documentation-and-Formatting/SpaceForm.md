# SpaceForm

`SpaceForm[n]` prints as n spaces.

## Examples

Print 5 spaces:

```wolfram
SpaceForm[5]
```

In a string output:

```wolfram
Print["Hello", SpaceForm[3], "World"]
```

Creating fixed-width formatting:

```wolfram
Row[{"Item:", SpaceForm[10], "Value"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SpaceForm.html) for more details.*
