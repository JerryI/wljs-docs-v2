---
title: Invisible
---

`Invisible[expr]` displays as space that is the same size as the formatted version of expr.

## Examples

```wolfram
Row[{"A", Invisible["B"], "C"}]
```

```wolfram
Invisible[x^2 + y^2]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Invisible.html) for more details.*
