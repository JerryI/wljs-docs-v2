---
title: ShortUpArrow
---

`ShortUpArrow[x,y,…]` displays as x↑y↑….

## Examples

Display a short up arrow relation:

```wolfram
ShortUpArrow[a, b, c]
(* a↑b↑c *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ShortUpArrow.html) for more details.*
