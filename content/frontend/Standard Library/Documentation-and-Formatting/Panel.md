# Panel

`Panel[expr]` displays as a panel containing expr.

`Panel[expr, title]` gives the panel the specified title.

`Panel[expr, title, pos]` places title at a position specified by pos.

## Examples

Simple panel:

```wolfram
Panel["Content"]
```

With title:

```wolfram
Panel["Content", "My Panel"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Panel.html) for more details.*
