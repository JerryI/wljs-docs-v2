# Proportion

`Proportion[x, y, ...]` displays as x∷y∷....

## Examples

Display a simple proportion:

```wolfram
Proportion[1, 2, 3]
(* 1∷2∷3 *)
```

Create a ratio relationship:

```wolfram
Proportion[a, b] == Proportion[c, d]
```
