# Italic

`Italic` represents an italic font slant.

## Examples

Style text as italic:

```wolfram
Style["Italic text", Italic]
```

Combine with other styles:

```wolfram
Style["Bold Italic", Bold, Italic]
```

Use in formatting functions:

```wolfram
Style["emphasis", FontSlant -> Italic]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Italic.html) for more details.*
