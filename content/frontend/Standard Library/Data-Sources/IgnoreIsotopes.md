---
title: IgnoreIsotopes
---

`IgnoreIsotopes` is an option for `MoleculeMatchQ` that determines whether isotopes should be ignored for pattern matching.

## Examples

```wolfram
MoleculeMatchQ[mol1, mol2, IgnoreIsotopes -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/IgnoreIsotopes.html) for more details.*
