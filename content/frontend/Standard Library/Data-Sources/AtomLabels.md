---
title: AtomLabels
---

`AtomLabels` is an option for `MoleculePlot` and `MoleculePlot3D` that specifies what labels and label positions should be used for atoms.

## Examples

```wolfram
MoleculePlot[Molecule["Caffeine"], AtomLabels -> "AtomIndex"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AtomLabels.html) for more details.*
