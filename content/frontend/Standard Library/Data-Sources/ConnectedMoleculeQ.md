---
title: ConnectedMoleculeQ
---

`ConnectedMoleculeQ[mol]` returns True if the atoms in mol are connected by bonds, and False otherwise.

## Examples

```wolfram
ConnectedMoleculeQ[Molecule["Water"]]
(* True *)
```

```wolfram
ConnectedMoleculeQ[Molecule["Ethanol"]]
(* True *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ConnectedMoleculeQ.html) for more details.*
