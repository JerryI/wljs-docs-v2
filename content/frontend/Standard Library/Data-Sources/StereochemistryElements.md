---
title: StereochemistryElements
---

`StereochemistryElements` is an option for Molecule that specifies the local stereochemical arrangement of atoms in a molecule.

## Examples

Get stereochemistry elements from a molecule:

```wolfram
Molecule["L-Alanine", "StereochemistryElements"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/StereochemistryElements.html) for more details.*
