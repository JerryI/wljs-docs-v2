---
title: BridgeData
---

`BridgeData[entity, property]` gives the value of the specified property for the bridge entity.

`BridgeData[{entity1, entity2, ...}, property]` gives a list of property values for the specified bridge entities.

## Examples

Get bridge information:

```wolfram
BridgeData[Entity["Bridge", "GoldenGateBridge"], "Length"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/BridgeData.html) for more details.*
