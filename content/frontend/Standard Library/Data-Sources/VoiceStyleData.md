# VoiceStyleData

`VoiceStyleData[]` gives the list of available voices for speech synthesis.

- `VoiceStyleData[voice]` returns all properties for the specified voice.
- `VoiceStyleData[voice, prop]` returns the specified property prop for voice.

## Examples

```wolfram
VoiceStyleData[]
```

```wolfram
VoiceStyleData["Samantha", "Language"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VoiceStyleData.html) for more details.*
