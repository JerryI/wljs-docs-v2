---
title: FiniteGroupData
---

`FiniteGroupData[name, "property"]` gives the value of the specified property for the finite group specified by name.

`FiniteGroupData["class"]` gives a list of finite groups in the specified class.

## Examples

```wolfram
FiniteGroupData["Symmetric", 4]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/FiniteGroupData.html) for more details.*
