---
title: Atom
---

`Atom["sym"]` represents an atom with atomic symbol "sym".

`Atom["sym", name -> value, ...]` represents an atom with atomic symbol "sym" and specified properties.

## Examples

Create an atom:

```wolfram
Atom["C"]
```

Atom with properties:

```wolfram
Atom["O", "FormalCharge" -> -1]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Atom.html) for more details.*
