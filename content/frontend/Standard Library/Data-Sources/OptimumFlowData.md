# OptimumFlowData

`OptimumFlowData[…]` represents flow data such as generated by `FindMaximumFlow`, `FindMinimumCostFlow`, etc.

## Examples

```wolfram
g = Graph[{1 -> 2, 2 -> 3}, EdgeCapacity -> {1, 2}];
FindMaximumFlow[g, 1, 3]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/OptimumFlowData.html) for more details.*
