---
title: ValenceFilling
---

`ValenceFilling` is an option for Molecule that specifies whether to fill open valences with hydrogen atoms.

## Examples

Create a molecule with valence filling:

```wolfram
Molecule["C", ValenceFilling -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ValenceFilling.html) for more details.*
