---
title: ColorProfileData
---

`ColorProfileData[<>, "Description" -> "desc", "DeviceColorSpace" -> "device", "IndependentColorSpace" -> "ics"]` represents an ICC color profile that can convert between the independent color space "ics" and the device-dependent color space "device".

## Examples

Get color profile from an image:

```wolfram
ColorProfileData[img]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ColorProfileData.html) for more details.*
