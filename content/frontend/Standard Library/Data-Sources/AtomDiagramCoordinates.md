---
title: AtomDiagramCoordinates
---

`AtomDiagramCoordinates` is an option for `Molecule` and related functions that specifies the two-dimensional coordinates of the atoms.

## Examples

Set 2D diagram coordinates:

```wolfram
Molecule[{"C", "C"}, {Bond[{1, 2}]}, 
  AtomDiagramCoordinates -> {{0, 0}, {1, 0}}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AtomDiagramCoordinates.html) for more details.*
