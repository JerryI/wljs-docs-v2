# IsotopeData

`IsotopeData[{Z, A}, "property"]` gives the value of the specified property for the isotope with atomic number `Z` and mass number `A`.

- `IsotopeData["name", "property"]` gives the value of the property for the named isotope.

## Examples

```wolfram
IsotopeData[{6, 12}, "AtomicMass"]
```

```wolfram
IsotopeData["Uranium235", "HalfLife"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/IsotopeData.html) for more details.*
