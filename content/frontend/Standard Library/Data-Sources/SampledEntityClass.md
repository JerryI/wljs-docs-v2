---
title: SampledEntityClass
---

`SampledEntityClass[class, n]` represents an entity class containing n entities from class.

- `SampledEntityClass[class, {m, n}]` represents an entity class containing entities m through n of class.

## Examples

```wolfram
SampledEntityClass["Country", 5]
```

```wolfram
EntityList[SampledEntityClass["Element", {1, 10}]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SampledEntityClass.html) for more details.*
