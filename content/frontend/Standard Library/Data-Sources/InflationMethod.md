---
title: InflationMethod
---

`InflationMethod` is an option for `InflationAdjust` that specifies what time series data is to be used for adjustment in time.

## Examples

```wolfram
InflationAdjust[Quantity[100, "USDollars"], {1990, 2020}, InflationMethod -> "CPI"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/InflationMethod.html) for more details.*
