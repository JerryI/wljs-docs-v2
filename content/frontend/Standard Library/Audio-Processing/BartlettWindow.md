# BartlettWindow

`BartlettWindow[x]` represents a Bartlett window function of x.

## Examples

Plot the Bartlett window:

```wolfram
Plot[BartlettWindow[x], {x, -1/2, 1/2}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/BartlettWindow.html) for more details.*
