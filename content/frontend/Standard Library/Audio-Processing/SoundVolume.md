# SoundVolume

`SoundVolume` is an option to `Sound` and `SoundNote` and related functions that specifies the relative volume of the sound produced.

## Examples

```wolfram
Sound[SoundNote["C"], SoundVolume -> 0.5]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SoundVolume.html) for more details.*
