---
title: ConnesWindow
---

`ConnesWindow[x]` represents a Connes window function of x.

`ConnesWindow[x,α]` uses the parameter α.

## Examples

```wolfram
ConnesWindow[0.5]
(* 0.5625 *)
```

```wolfram
Plot[ConnesWindow[x], {x, -1, 1}]
(* Plots the Connes window function *)
```
