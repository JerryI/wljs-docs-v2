# AudioPlay

`AudioPlay[audio]` returns a new AudioStream object from audio and starts the playback.

`AudioPlay[astream]` starts playing an AudioStream object astream.

## Examples

Play audio:

```wolfram
audio = ExampleData[{"Audio", "Bird"}];
AudioPlay[audio]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AudioPlay.html) for more details.*
