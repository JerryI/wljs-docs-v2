---
title: AudioStream
---

`AudioStream[source]` creates a new AudioStream object from source.

`AudioStream[id]` is an object that represents a unique audio stream.

## Examples

```wolfram
stream = AudioStream[ExampleData[{"Audio", "Drums"}]]
(* AudioStream[...] *)
```
