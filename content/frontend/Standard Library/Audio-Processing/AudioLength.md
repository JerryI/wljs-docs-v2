# AudioLength

`AudioLength[audio]` returns the number of samples in the Audio object audio.

## Examples

Get the number of samples:

```wolfram
audio = ExampleData[{"Audio", "Bird"}];
AudioLength[audio]
(* 132300 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AudioLength.html) for more details.*
