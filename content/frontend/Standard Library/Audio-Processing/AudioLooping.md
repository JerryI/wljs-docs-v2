---
title: AudioLooping
---

`AudioLooping` is an option for AudioStream and related functions to specify the playback looping.

## Examples

Create an audio stream with looping enabled:

```wolfram
AudioStream[audio, AudioLooping -> True]
```

Disable looping:

```wolfram
AudioStream[audio, AudioLooping -> False]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AudioLooping.html) for more details.*
