---
title: AudioType
---

`AudioType[audio]` returns the data type used to represent samples in the Audio object audio.

## Examples

Get the sample data type:

```wolfram
audio = ExampleData[{"Audio", "Bird"}];
AudioType[audio]
(* "Real64" *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AudioType.html) for more details.*
