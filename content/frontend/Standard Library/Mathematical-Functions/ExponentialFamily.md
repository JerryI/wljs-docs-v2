# ExponentialFamily

`ExponentialFamily` is an option for `GeneralizedLinearModelFit` that specifies the exponential family for the model.

## Examples

Specify exponential family:

```wolfram
GeneralizedLinearModelFit[data, x, x, ExponentialFamily -> "Binomial"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ExponentialFamily.html) for more details.*
