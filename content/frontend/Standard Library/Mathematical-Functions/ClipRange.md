---
title: ClipRange
---

`ClipRange` is an option to `Raster3D` that specifies a rectangular region that is cut away from the resulting view.

## Examples

Set clip range for Raster3D:

```wolfram
Raster3D[data, ClipRange -> {{0, 0.5}, {0, 1}, {0, 1}}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ClipRange.html) for more details.*
