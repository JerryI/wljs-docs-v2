# ChebyshevT

`ChebyshevT[n, x]` gives the Chebyshev polynomial of the first kind T_n(x).

## Examples

Chebyshev T polynomials:

```wolfram
ChebyshevT[0, x]
(* 1 *)

ChebyshevT[2, x]
(* -1 + 2*x^2 *)

ChebyshevT[4, x]
(* 1 - 8*x^2 + 8*x^4 *)
```

Numerical value:

```wolfram
ChebyshevT[3, 0.5]
(* -1. *)
```
