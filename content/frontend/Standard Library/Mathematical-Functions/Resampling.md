---
title: Resampling
---

`Resampling` is an option that specifies the method to be used for resampling images or arrays.

## Examples

```wolfram
ImageResize[img, 200, Resampling -> "Gaussian"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Resampling.html) for more details.*
