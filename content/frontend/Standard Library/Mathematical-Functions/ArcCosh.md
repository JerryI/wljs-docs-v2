# ArcCosh

`ArcCosh[z]` gives the inverse hyperbolic cosine cosh⁻¹(z) of the complex number z.

## Examples

Evaluate the inverse hyperbolic cosine:

```wolfram
ArcCosh[2]
(* Log[2 + Sqrt[3]] *)
```

Numerical value:

```wolfram
N[ArcCosh[2]]
(* 1.31696 *)
```
