# MaxTrainingRounds

`MaxTrainingRounds` is an option for `NetTrain` and related functions that specifies the maximum number of rounds of training to do.

## Examples

```wolfram
NetTrain[net, data, MaxTrainingRounds -> 100]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MaxTrainingRounds.html) for more details.*
