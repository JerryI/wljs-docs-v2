# ScorerHiPrime

`ScorerHiPrime[z]` gives the derivative of the Scorer function Hi′(z).

## Examples

Evaluate the derivative at a point:

```wolfram
ScorerHiPrime[1.0]
(* 0.326643 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ScorerHiPrime.html) for more details.*
