# CantorStaircase

`CantorStaircase[x]` gives the Cantor staircase function FC(x).

## Examples

Plot the Cantor staircase:

```wolfram
Plot[CantorStaircase[x], {x, 0, 1}]
```

Evaluate at specific points:

```wolfram
CantorStaircase[1/3]
(* 1/2 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CantorStaircase.html) for more details.*
