---
title: ReconstructionMesh
---

`ReconstructionMesh[{pt1, pt2, …}]` reconstructs a mesh from a set of points pt1, pt2, ….

## Examples

```wolfram
pts = RandomReal[1, {50, 3}];
ReconstructionMesh[pts]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ReconstructionMesh.html) for more details.*
