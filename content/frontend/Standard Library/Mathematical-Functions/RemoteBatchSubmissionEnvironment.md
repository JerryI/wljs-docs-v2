---
title: RemoteBatchSubmissionEnvironment
---

`RemoteBatchSubmissionEnvironment["provider",assoc]` represents a remote batch job submission environment for provider with properties assoc.

`RemoteBatchSubmissionEnvironment["provider"]` represents a submission environment for provider with default optional properties.

## Examples

Create a remote batch submission environment:

```wolfram
RemoteBatchSubmissionEnvironment["AWS"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RemoteBatchSubmissionEnvironment.html) for more details.*
