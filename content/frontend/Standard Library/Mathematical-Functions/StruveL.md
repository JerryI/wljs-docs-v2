# StruveL

`StruveL[n, z]` gives the modified Struve function Ln(z).

## Examples

Evaluate the modified Struve function:

```wolfram
StruveL[0, 1.5]
(* 0.802738 *)
```

Plot the function:

```wolfram
Plot[StruveL[1, x], {x, 0, 10}]
```
