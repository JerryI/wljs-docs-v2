# HeunDPrime

`HeunDPrime[q, α, γ, δ, ϵ, z]` gives the z-derivative of the `HeunD` function.

## Examples

Evaluate the derivative of HeunD:

```wolfram
HeunDPrime[1, 2, 3, 4, 5, 0.5]
```

Symbolic derivative:

```wolfram
HeunDPrime[q, a, g, d, e, z]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/HeunDPrime.html) for more details.*
