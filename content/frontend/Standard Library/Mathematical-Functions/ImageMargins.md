# ImageMargins

`ImageMargins` is an option that specifies the absolute margins to leave around the image displayed for an object.

## Examples

Set equal margins on all sides:

```wolfram
Graphics[Circle[], ImageMargins -> 20]
```

Set different margins for each side:

```wolfram
Graphics[Circle[], ImageMargins -> {{10, 20}, {5, 15}}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ImageMargins.html) for more details.*
