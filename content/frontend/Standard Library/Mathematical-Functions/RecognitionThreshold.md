# RecognitionThreshold

`RecognitionThreshold` is an option for `ImageInstanceQ` and related functions that specifies the minimum estimated probability at which recognition is considered acceptable.

## Examples

```wolfram
ImageInstanceQ[img, "Cat", RecognitionThreshold -> 0.8]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RecognitionThreshold.html) for more details.*
