# LogIntegral

`LogIntegral[z]` gives the logarithmic integral function li(z).

## Examples

Compute log integral:

```wolfram
LogIntegral[10.0]
(* 6.16554 *)
```

Plot:

```wolfram
Plot[LogIntegral[x], {x, 2, 100}]
```
