---
title: MathieuCharacteristicExponent
---

`MathieuCharacteristicExponent[a, q]` gives the characteristic exponent `r` for Mathieu functions with characteristic value `a` and parameter `q`.

## Examples

```wolfram
MathieuCharacteristicExponent[1, 0.5]
```

```wolfram
Plot[MathieuCharacteristicExponent[a, 1], {a, 0, 10}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MathieuCharacteristicExponent.html) for more details.*
