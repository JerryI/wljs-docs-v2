# MathieuC

`MathieuC[a, q, z]` gives the even Mathieu function with characteristic value a and parameter q.

## Examples

```wolfram
MathieuC[1, 0.5, 0.3]
```

```wolfram
Plot[MathieuC[1, 0.5, z], {z, 0, 2 Pi}]
```
