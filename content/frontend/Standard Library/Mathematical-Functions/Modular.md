---
title: Modular
---

`Modular` is a setting for the option `Mode` in `Solve` and related functions, which specifies that equations need be satisfied only modulo an integer.

## Examples

```wolfram
Solve[x^2 == 1, x, Modulus -> 8]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Modular.html) for more details.*
