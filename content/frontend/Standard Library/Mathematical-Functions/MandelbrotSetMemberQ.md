# MandelbrotSetMemberQ

`MandelbrotSetMemberQ[z]` returns True if z is in the Mandelbrot set, and False otherwise.

## Examples

Check if a point is in the Mandelbrot set:

```wolfram
MandelbrotSetMemberQ[0]
(* True *)
```

```wolfram
MandelbrotSetMemberQ[2 + 2 I]
(* False *)
```
