---
title: MaxMixtureKernels
---

`MaxMixtureKernels` is an option for `SmoothKernelDistribution` and related functions that specifies the maximum number and location of kernel functions to use in the estimation.

## Examples

Limit the number of kernels in a smooth kernel distribution:

```wolfram
SmoothKernelDistribution[data, MaxMixtureKernels -> 10]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MaxMixtureKernels.html) for more details.*
