# MangoldtLambda

`MangoldtLambda[n]` gives the von Mangoldt function Λ(n).

## Examples

The von Mangoldt function for a prime power:

```wolfram
MangoldtLambda[8]
(* Log[2] *)
```

For a non-prime-power:

```wolfram
MangoldtLambda[6]
(* 0 *)
```
