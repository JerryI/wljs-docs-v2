# RealSign

`RealSign[x]` gives -1, 0, or 1 depending on whether x is negative, zero, or positive.

## Examples

Get sign:

```wolfram
RealSign[-5]
(* -1 *)
```

```wolfram
RealSign[0]
(* 0 *)
```

```wolfram
RealSign[3.14]
(* 1 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RealSign.html) for more details.*
