---
title: SingleLetterItalics
---

`SingleLetterItalics` is an option for `Cell` that specifies whether single‐letter names should be displayed in italics.

## Examples

Create a cell with single-letter italics enabled:

```wolfram
Cell["x + y", SingleLetterItalics -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SingleLetterItalics.html) for more details.*
