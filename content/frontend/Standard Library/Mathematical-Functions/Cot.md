# Cot

`Cot[z]` gives the cotangent of z.

## Examples

Cotangent of common angles:

```wolfram
Cot[Pi/4]
(* 1 *)

Cot[Pi/6]
(* Sqrt[3] *)
```

Numerical evaluation:

```wolfram
Cot[1.0]
(* 0.642093 *)
```
