# AbsArg

`AbsArg[z]` gives the list `{Abs[z], Arg[z]}` of the number z.

## Example

Get the magnitude and phase of a complex number:

```wolfram
AbsArg[1 + I]
(* {Sqrt[2], Pi/4} *)
```
