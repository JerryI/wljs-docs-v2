# RenderAll

`RenderAll` is an option for Graphics3D that specifies whether or not PostScript should be generated for all polygons.

## Examples

Use RenderAll with Graphics3D:

```wolfram
Graphics3D[Sphere[], RenderAll -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RenderAll.html) for more details.*
