# RemoveVideoStream

`RemoveVideoStream[]` deletes all `VideoStream` objects.

- `RemoveVideoStream[stream]` deletes the `VideoStream` object stream.

## Examples

```wolfram
RemoveVideoStream[]
```

```wolfram
stream = VideoRecord[];
RemoveVideoStream[stream]
```
