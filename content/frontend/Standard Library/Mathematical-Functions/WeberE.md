# WeberE

`WeberE[ν, z]` gives the Weber function Eν(z).

- `WeberE[ν, μ, z]` gives the associated Weber function Eνμ(z).

## Examples

Weber function at a point:

```wolfram
WeberE[1, 2.5]
```

Plot the Weber function:

```wolfram
Plot[WeberE[0, x], {x, 0, 10}]
```

Associated Weber function:

```wolfram
WeberE[1, 2, 3.0]
```
