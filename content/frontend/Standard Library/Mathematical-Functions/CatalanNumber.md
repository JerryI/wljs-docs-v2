---
title: CatalanNumber
---

`CatalanNumber[n]` gives the nth Catalan number Cn.

## Examples

```wolfram
CatalanNumber[5]
(* 42 *)
```

```wolfram
Table[CatalanNumber[n], {n, 0, 10}]
(* {1, 1, 2, 5, 14, 42, 132, 429, 1430, 4862, 16796} *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CatalanNumber.html) for more details.*
