---
title: Erfi
---

`Erfi[z]` gives the imaginary error function erf(iz)/i.

## Examples

Evaluate the imaginary error function:

```wolfram
Erfi[1.0]
(* 1.65043 *)
```

Plot the function:

```wolfram
Plot[Erfi[x], {x, -2, 2}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Erfi.html) for more details.*
