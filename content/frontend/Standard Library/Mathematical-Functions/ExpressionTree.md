# ExpressionTree

`ExpressionTree[expr]` gives a `Tree` object from the structure of the expression expr.

`ExpressionTree[expr, struct]` gives a `Tree` object from the expression expr with data and subtrees as specified by struct.

## Examples

Create a tree from an expression:

```wolfram
ExpressionTree[a + b*c]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ExpressionTree.html) for more details.*
