# MaxWordGap

`MaxWordGap` is an option for `SearchAdjustment` that specifies the number of words that can occur between the terms of a phrase.

## Examples

```wolfram
SearchAdjustment["term1 term2", MaxWordGap -> 3]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MaxWordGap.html) for more details.*
