# FoxHReduce

`FoxHReduce[expr, x]` attempts to reduce expr to a single FoxH object as a function of x.

## Examples

Reduce an expression to Fox H form:

```wolfram
FoxHReduce[Exp[-x], x]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/FoxHReduce.html) for more details.*
