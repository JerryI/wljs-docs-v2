# KroneckerSymbol

`KroneckerSymbol[n, m]` gives the Kronecker symbol (n/m).

## Examples

Compute the Kronecker symbol:

```wolfram
KroneckerSymbol[2, 5]
(* -1 *)
```

Another example:

```wolfram
KroneckerSymbol[3, 7]
(* -1 *)
```
