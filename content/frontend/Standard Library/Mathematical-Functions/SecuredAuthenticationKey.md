# SecuredAuthenticationKey

`SecuredAuthenticationKey[assoc]` represents a secured authentication key with credentials and details specified by the association assoc.

## Examples

```wolfram
SecuredAuthenticationKey[<|"ConsumerKey" -> "key", "ConsumerSecret" -> "secret"|>]
```

```wolfram
SecuredAuthenticationKey[<|"BearerToken" -> "token"|>]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SecuredAuthenticationKey.html) for more details.*
