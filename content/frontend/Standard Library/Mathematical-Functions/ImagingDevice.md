# ImagingDevice

`ImagingDevice` is an option to specify what device to use for capturing images.

## Examples

```wolfram
CurrentImage[ImagingDevice -> "FaceTime HD Camera"]
```

```wolfram
ImageCapture[ImagingDevice -> Automatic]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ImagingDevice.html) for more details.*
