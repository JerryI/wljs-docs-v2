---
title: HurwitzZeta
---

`HurwitzZeta[s, a]` gives the Hurwitz zeta function ζ(s, a).

## Examples

Compute Hurwitz zeta:

```wolfram
HurwitzZeta[2, 1]
(* Pi^2/6 - same as Zeta[2] *)
```

Numerical evaluation:

```wolfram
HurwitzZeta[3, 0.5] // N
(* 8.66905 *)
```
