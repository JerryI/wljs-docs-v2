---
title: SubtractFrom
---

`x -= dx` subtracts dx from x and returns the new value of x.

## Examples

Subtract and update:

```wolfram
x = 10;
x -= 3
(* 7 *)
x
(* 7 *)
```

Decrement in a loop:

```wolfram
count = 5;
While[count > 0, Print[count]; count -= 1]
```
