---
title: MinkowskiQuestionMark
---

`MinkowskiQuestionMark[x]` gives Minkowski's question mark function ?(x).

## Examples

Evaluate the Minkowski question mark function:

```wolfram
MinkowskiQuestionMark[1/3]
(* 3/8 *)
```

```wolfram
MinkowskiQuestionMark[GoldenRatio - 1]
(* 2/3 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MinkowskiQuestionMark.html) for more details.*
