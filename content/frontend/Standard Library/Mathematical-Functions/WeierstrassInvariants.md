# WeierstrassInvariants

`WeierstrassInvariants[{ω1, ω3}]` gives the invariants {g2, g3} for Weierstrass elliptic functions corresponding to the half‐periods {ω1, ω3}.

## Examples

```wolfram
WeierstrassInvariants[{1, I}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/WeierstrassInvariants.html) for more details.*
