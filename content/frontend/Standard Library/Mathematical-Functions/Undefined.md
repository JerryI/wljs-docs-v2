# Undefined

`Undefined` is a symbol that represents a quantity with no defined value.

## Examples

Indeterminate form:

```wolfram
0/0
(* Indeterminate *)
```

Result of Undefined operations:

```wolfram
Undefined + 1
(* Undefined *)
```

Limit with undefined behavior:

```wolfram
Limit[Sin[x]/x, x -> Infinity]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Undefined.html) for more details.*
