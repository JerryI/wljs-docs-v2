# EllipticNomeQ

`EllipticNomeQ[m]` gives the nome q corresponding to the parameter m in an elliptic function.

## Examples

Compute the elliptic nome:

```wolfram
EllipticNomeQ[0.5]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EllipticNomeQ.html) for more details.*
