---
title: VideoStop
---

`VideoStop[]` stops the playback of all `VideoStream` objects.

- `VideoStop[vstream]` stops the playback of the `VideoStream` object vstream.

## Examples

```wolfram
VideoStop[]
```

```wolfram
stream = VideoPlay[Video["test.mp4"]];
VideoStop[stream]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VideoStop.html) for more details.*
