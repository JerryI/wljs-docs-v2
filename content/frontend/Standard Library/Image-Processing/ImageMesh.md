# ImageMesh

`ImageMesh[image]` returns the foreground region in image as a `BoundaryMeshRegion` object.

## Examples

```wolfram
ImageMesh[Binarize[ExampleData[{"TestImage", "Lena"}]]]
(* BoundaryMeshRegion[...] *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ImageMesh.html) for more details.*
