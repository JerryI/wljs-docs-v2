# VideoSummaryPlot

`VideoSummaryPlot[video]` plots a summary of video and audio tracks of video.

- `VideoSummaryPlot[video, layout]` lays out the video frames according to the provided layout.

## Examples

```wolfram
VideoSummaryPlot[Video["ExampleData/Caminandes.mp4"]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VideoSummaryPlot.html) for more details.*
