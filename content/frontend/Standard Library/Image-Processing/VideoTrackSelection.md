---
title: VideoTrackSelection
---

`VideoTrackSelection` is an option that specifies the video tracks of interest.

## Examples

Select specific video tracks:

```wolfram
VideoExtractFrames[video, All, VideoTrackSelection -> 1]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VideoTrackSelection.html) for more details.*
