# VideoTimeStretch

`VideoTimeStretch[video,spec]` applies time stretching to video using the specified spec.

## Examples

Slow down a video by 2x:

```wolfram
VideoTimeStretch[video, 2]
```

Speed up a video:

```wolfram
VideoTimeStretch[video, 0.5]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VideoTimeStretch.html) for more details.*
