---
title: ShowAutoSpellCheck
---

`ShowAutoSpellCheck` is an option for `Cell` that specifies whether to highlight misspelled words.

## Examples

```wolfram
Cell["Hello Wrold", ShowAutoSpellCheck -> True]
```

```wolfram
Cell["text", ShowAutoSpellCheck -> False]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ShowAutoSpellCheck.html) for more details.*
