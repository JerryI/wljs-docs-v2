---
title: Gray
---

`Gray` represents the color gray in graphics or style specifications.

## Examples

Use in graphics:

```wolfram
Graphics[{Gray, Disk[]}]
```

In text styling:

```wolfram
Style["Muted text", Gray]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Gray.html) for more details.*
