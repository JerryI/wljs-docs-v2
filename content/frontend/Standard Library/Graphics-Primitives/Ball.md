---
title: Ball
---

`Ball[p, r]` represents a ball (filled sphere) of radius r centered at point p.

## Examples

3D ball:

```wolfram
Graphics3D[Ball[{0, 0, 0}, 1]]
```

Multiple balls:

```wolfram
Graphics3D[{Red, Ball[{0, 0, 0}, 0.5], Blue, Ball[{1, 0, 0}, 0.3]}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Ball.html) for more details.*
