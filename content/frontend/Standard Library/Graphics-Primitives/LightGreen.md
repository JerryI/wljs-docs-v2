---
title: LightGreen
---

`LightGreen` represents a light green color in graphics or style specifications.

## Examples

Use in graphics:

```wolfram
Graphics[{LightGreen, Disk[]}]
```

With text styling:

```wolfram
Style["Hello", LightGreen, Bold]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LightGreen.html) for more details.*
