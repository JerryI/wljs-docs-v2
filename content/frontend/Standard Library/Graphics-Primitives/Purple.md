---
title: Purple
---

`Purple` represents the color purple in graphics or style specifications.

## Examples

Use in graphics:

```wolfram
Graphics[{Purple, Disk[]}]
```

In plots:

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, PlotStyle -> Purple]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Purple.html) for more details.*
