# TextGrid

`TextGrid[{{expr11, expr12, ...}, {expr21, expr22, ...}, ...}]` formats expressions as a two-dimensional text grid.

## Examples

Create a simple text grid:

```wolfram
TextGrid[{{"Name", "Age"}, {"Alice", 25}, {"Bob", 30}}]
```

With frame:

```wolfram
TextGrid[{{1, 2, 3}, {4, 5, 6}}, Frame -> All]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TextGrid.html) for more details.*
