# Orange

`Orange` represents the color orange in graphics or style specifications.

## Examples

Use in graphics:

```wolfram
Graphics[{Orange, Disk[]}]
```

In plots:

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, PlotStyle -> Orange]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Orange.html) for more details.*
