---
title: LineIndent
---

`LineIndent` is an option for `Style` and `Cell` that specifies how many ems of indentation to add at the beginnings of lines for each level of nesting in an expression.

## Examples

Set line indent:

```wolfram
Style[expr, LineIndent -> 2]
```

In a Cell:

```wolfram
Cell["text", LineIndent -> 1]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LineIndent.html) for more details.*
