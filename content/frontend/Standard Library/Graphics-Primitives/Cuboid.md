---
title: Cuboid
---

`Cuboid[pmin, pmax]` represents an axis-aligned filled box with lower corner pmin and upper corner pmax.

## Examples

3D box:

```wolfram
Graphics3D[Cuboid[{0, 0, 0}, {1, 2, 3}]]
```

Unit cube:

```wolfram
Graphics3D[{Blue, Opacity[0.5], Cuboid[]}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Cuboid.html) for more details.*
