# LightBlue

`LightBlue` represents a light blue color in graphics or style specifications.

## Examples

Use LightBlue in graphics:
```wolfram
Graphics[{LightBlue, Disk[]}]
```

Style text with LightBlue:
```wolfram
Style["Hello", Background -> LightBlue]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LightBlue.html) for more details.*
