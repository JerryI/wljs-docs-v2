---
title: ViewCenter
---

`ViewCenter` is an option for `Graphics3D` and related functions which gives the scaled coordinates of the point which should appear at the center of the final image.

## Examples

```wolfram
Graphics3D[Sphere[], ViewCenter -> {0.5, 0.5, 0.5}]
```

```wolfram
Graphics3D[Cuboid[], ViewCenter -> {1, 0.5, 0.5}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ViewCenter.html) for more details.*
