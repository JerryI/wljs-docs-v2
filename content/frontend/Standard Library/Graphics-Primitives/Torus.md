---
title: Torus
---

`Torus[{x, y, z}, {rinner, router}]` represents a torus centered at the point with given radii.

## Examples

3D torus:

```wolfram
Graphics3D[Torus[{0, 0, 0}, {0.3, 1}]]
```

Default torus:

```wolfram
Graphics3D[{Orange, Torus[]}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Torus.html) for more details.*
