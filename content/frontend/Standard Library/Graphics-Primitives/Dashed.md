---
title: Dashed
---

`Dashed` is a graphics directive specifying that lines that follow should be drawn dashed.

## Examples

Draw a dashed line:

```wolfram
Graphics[{Dashed, Line[{{0, 0}, {1, 1}}]}]
```

Combine with color:

```wolfram
Graphics[{Red, Dashed, Line[{{0, 0}, {1, 0}}]}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Dashed.html) for more details.*
