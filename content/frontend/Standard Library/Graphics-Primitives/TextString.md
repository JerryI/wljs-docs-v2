# TextString

`TextString[expr]` gives a human-readable string representation of expr.

## Examples

Convert expression to string:

```wolfram
TextString[1/2]
(* "1/2" *)
```

Convert date:

```wolfram
TextString[Today]
(* "Tue 28 Jan 2025" *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TextString.html) for more details.*
