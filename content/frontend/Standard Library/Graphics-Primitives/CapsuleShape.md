---
title: CapsuleShape
---

`CapsuleShape[{{x1, y1, z1}, {x2, y2, z2}}, r]` represents the filled capsule between points {xi, yi, zi} and radius r.

## Examples

Create a capsule:

```wolfram
Graphics3D[CapsuleShape[{{0, 0, 0}, {1, 1, 1}}, 0.2]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CapsuleShape.html) for more details.*
