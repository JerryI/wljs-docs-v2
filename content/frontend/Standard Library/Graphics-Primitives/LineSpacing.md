# LineSpacing

`LineSpacing` is an option for `Style` and `Cell` that specifies the spacing between successive lines of text.

## Examples

```wolfram
Style["Line 1\nLine 2\nLine 3", LineSpacing -> {1, 5}]
```

```wolfram
Style["Line 1\nLine 2", LineSpacing -> {2, 0}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LineSpacing.html) for more details.*
