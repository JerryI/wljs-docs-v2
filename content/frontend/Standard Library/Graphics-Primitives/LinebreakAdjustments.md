---
title: LinebreakAdjustments
---

`LinebreakAdjustments` is an option for selections that sets parameters used for calculating where automatic line breaks should be inserted.

## Examples

```wolfram
Style[expr, LinebreakAdjustments -> {1., 1., 1., 1., 1.}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LinebreakAdjustments.html) for more details.*
