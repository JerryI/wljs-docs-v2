---
title: Pink
---

`Pink` represents the color pink in graphics or style specifications.

## Examples

Use in graphics:

```wolfram
Graphics[{Pink, Disk[]}]
```

In plots:

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, PlotStyle -> Pink]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Pink.html) for more details.*
