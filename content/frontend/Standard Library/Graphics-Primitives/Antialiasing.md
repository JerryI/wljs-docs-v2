# Antialiasing

`Antialiasing` is an option that specifies whether antialiasing should be done.

## Examples

Enable antialiasing in graphics:

```wolfram
Graphics[Circle[], Antialiasing -> True]
```

Disable antialiasing for crisp edges:

```wolfram
Graphics[Rectangle[], Antialiasing -> False]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Antialiasing.html) for more details.*
