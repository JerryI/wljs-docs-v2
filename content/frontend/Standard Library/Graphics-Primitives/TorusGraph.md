# TorusGraph

`TorusGraph[{n1, n2, ..., nk}]` gives the k-dimensional torus graph with n1×n2×...×nk vertices.

## Examples

```wolfram
TorusGraph[{4, 4}]
```

```wolfram
TorusGraph[{3, 3, 3}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TorusGraph.html) for more details.*
