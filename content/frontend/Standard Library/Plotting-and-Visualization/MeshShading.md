---
title: MeshShading
---

`MeshShading` is an option for plotting functions that gives lists of colors to use for regions between mesh divisions.

## Examples

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, Mesh -> 5, MeshShading -> {Red, Blue}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MeshShading.html) for more details.*
