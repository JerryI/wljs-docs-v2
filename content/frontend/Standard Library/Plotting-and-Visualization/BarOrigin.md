# BarOrigin

`BarOrigin` is an option to `BarChart` and related functions that specifies the origin placement for bars.

## Examples

Change bar origin:

```wolfram
BarChart[{1, 2, 3, 4}, BarOrigin -> Left]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/BarOrigin.html) for more details.*
