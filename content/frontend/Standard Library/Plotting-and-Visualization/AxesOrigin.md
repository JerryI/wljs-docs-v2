# AxesOrigin

`AxesOrigin` is an option for graphics functions that specifies where any axes drawn should cross.

## Examples

Set the axes origin:

```wolfram
Plot[x^2, {x, -2, 2}, AxesOrigin -> {0, 0}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AxesOrigin.html) for more details.*
