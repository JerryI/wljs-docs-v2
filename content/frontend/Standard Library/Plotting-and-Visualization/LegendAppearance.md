# LegendAppearance

`LegendAppearance` is an option for charting functions that specifies the appearance of any legends that are generated.

## Examples

```wolfram
BarChart[{1, 2, 3}, ChartLegend -> Automatic, LegendAppearance -> "Row"]
```

```wolfram
PieChart[{1, 2, 3}, ChartLegend -> {"A", "B", "C"}, LegendAppearance -> "Column"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LegendAppearance.html) for more details.*
