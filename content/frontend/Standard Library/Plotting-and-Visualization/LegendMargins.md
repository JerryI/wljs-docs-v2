# LegendMargins

`LegendMargins` is an option for legends that specifies the margins to leave around the legend.

## Examples

```wolfram
SwatchLegend[{Red, Blue}, {"A", "B"}, LegendMargins -> 20]
```

```wolfram
LineLegend[{Red, Blue}, {"X", "Y"}, LegendMargins -> {{10, 10}, {5, 5}}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LegendMargins.html) for more details.*
