# AspectRatio

`AspectRatio` is an option for `Graphics` and related functions that specifies the ratio of height to width for a plot.

## Examples

Set a specific aspect ratio:

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, AspectRatio -> 1]
```

Automatic aspect ratio:

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, AspectRatio -> Automatic]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AspectRatio.html) for more details.*
