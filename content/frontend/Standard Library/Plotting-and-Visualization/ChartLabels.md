---
title: ChartLabels
---

`ChartLabels` is an option for charting functions that specifies what labels should be used for chart elements.

## Examples

Add labels to a bar chart:

```wolfram
BarChart[{1, 2, 3}, ChartLabels -> {"A", "B", "C"}]
```

Add labels to a pie chart:

```wolfram
PieChart[{25, 35, 40}, ChartLabels -> Automatic]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ChartLabels.html) for more details.*
