# MeshCellMeasure

`MeshCellMeasure` is an annotation of `MeshRegion` and `BoundaryMeshRegion` objects that gives the measures of mesh cells.

## Examples

```wolfram
mr = MeshRegion[{{0, 0}, {1, 0}, {1, 1}}, Triangle[{1, 2, 3}]];
mr["MeshCellMeasure"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MeshCellMeasure.html) for more details.*
