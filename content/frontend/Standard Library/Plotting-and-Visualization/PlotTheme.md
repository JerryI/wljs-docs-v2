---
title: PlotTheme
---

`PlotTheme` is an option for plotting and related functions that specifies an overall theme for visualization elements and styles.

## Examples

Use a theme:

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, PlotTheme -> "Detailed"]
```

Different themes:

```wolfram
Plot[Cos[x], {x, 0, 2 Pi}, PlotTheme -> "Scientific"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PlotTheme.html) for more details.*
