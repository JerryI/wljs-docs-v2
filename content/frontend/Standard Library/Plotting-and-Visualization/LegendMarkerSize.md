# LegendMarkerSize

`LegendMarkerSize` is an option for legends such as `PointLegend` that specifies the size of marker regions for each element.

## Examples

Create a legend with custom marker size:

```wolfram
PointLegend[{Red, Blue}, {"A", "B"}, LegendMarkerSize -> 20]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LegendMarkerSize.html) for more details.*
