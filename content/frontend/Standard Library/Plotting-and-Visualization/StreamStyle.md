# StreamStyle

`StreamStyle` is an option to `StreamPlot`, `StreamDensityPlot`, and related functions that determines the style to use for drawing streamlines.

## Examples

```wolfram
StreamPlot[{-y, x}, {x, -2, 2}, {y, -2, 2}, StreamStyle -> Red]
```

```wolfram
StreamPlot[{-y, x}, {x, -2, 2}, {y, -2, 2}, StreamStyle -> Arrowheads[0.05]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/StreamStyle.html) for more details.*
