---
title: ChartLegends
---

`ChartLegends` is an option for charting functions that specifies what legends should be used for chart elements.

## Examples

Add legends to a pie chart:

```wolfram
PieChart[{1, 2, 3}, ChartLegends -> {"A", "B", "C"}]
```

Use automatic legends in a bar chart:

```wolfram
BarChart[{1, 2, 3}, ChartLegends -> Automatic]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ChartLegends.html) for more details.*
