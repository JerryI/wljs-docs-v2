---
title: Framed
---

`Framed[expr]` displays a framed version of expr.

## Examples

Frame an expression:

```wolfram
Framed["Hello World"]
```

With styling options:

```wolfram
Framed["Styled", Background -> LightBlue, FrameStyle -> Red]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Framed.html) for more details.*
