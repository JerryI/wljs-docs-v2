# BoundaryStyle

`BoundaryStyle` is an option for plotting functions that specifies the style in which boundaries of regions should be drawn.

## Examples

Style plot boundaries:

```wolfram
RegionPlot[x^2 + y^2 < 1, {x, -1.5, 1.5}, {y, -1.5, 1.5}, 
  BoundaryStyle -> {Thick, Red}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/BoundaryStyle.html) for more details.*
