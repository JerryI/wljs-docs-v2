# AxesStyle

`AxesStyle` is an option for graphics functions that specifies how axes should be rendered.

## Examples

Style the axes:

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, AxesStyle -> {Red, Thick}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AxesStyle.html) for more details.*
