# FrameStyle

`FrameStyle` is an option for `Graphics`, `Grid`, and other constructs that specifies the style in which to draw frames.

## Examples

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, Frame -> True, FrameStyle -> Red]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/FrameStyle.html) for more details.*
