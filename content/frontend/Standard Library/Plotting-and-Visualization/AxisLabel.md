# AxisLabel

`AxisLabel` is an option for `AxisObject` that specifies a label for the axis.

## Examples

Create an axis with a label:

```wolfram
AxisObject[{{0, 0}, {1, 0}}, AxisLabel -> "x"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AxisLabel.html) for more details.*
