---
title: ChartLayout
---

`ChartLayout` is an option to charting functions that specifies the overall layout to use.

## Examples

Stacked bar chart layout:

```wolfram
BarChart[{{1, 2, 3}, {2, 3, 1}}, ChartLayout -> "Stacked"]
```

Percentile layout:

```wolfram
BarChart[{{1, 2, 3}, {2, 3, 1}}, ChartLayout -> "Percentile"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ChartLayout.html) for more details.*
