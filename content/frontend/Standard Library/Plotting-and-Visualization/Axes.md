---
title: Axes
---

`Axes` is an option for graphics functions that specifies whether axes should be drawn.

## Examples

Show axes in a plot:

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, Axes -> True]
```

Hide axes:

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, Axes -> False]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Axes.html) for more details.*
