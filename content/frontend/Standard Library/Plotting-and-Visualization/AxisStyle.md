---
title: AxisStyle
---

`AxisStyle` is an option for `AxisObject` that specifies how to style the path of an axis.

## Examples

Style an axis:

```wolfram
Graphics[AxisObject[{{0, 0}, {1, 0}}, AxisStyle -> {Red, Thick}]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AxisStyle.html) for more details.*
