# NorlundB

`NorlundB[n, a]` gives Nørlund polynomials Bₙ(a) of degree *n* in *a*.

- `NorlundB[n, a, x]` gives generalized Bernoulli polynomials Bₙ⁽ᵃ⁾(x).

## Examples

```wolfram
NorlundB[3, a]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NorlundB.html) for more details.*
