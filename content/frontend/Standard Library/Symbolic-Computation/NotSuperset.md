# NotSuperset

`NotSuperset[x, y, ...]` displays as x⊅y⊅....

## Examples

Basic usage:

```wolfram
NotSuperset[a, b]
```

Multiple arguments:

```wolfram
NotSuperset[x, y, z]
```

In expressions:

```wolfram
NotSuperset[A, B]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NotSuperset.html) for more details.*
