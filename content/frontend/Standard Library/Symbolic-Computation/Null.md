---
title: "Null"
---

`Null` is a symbol used to indicate the absence of an expression or a result. When it appears as a complete output expression, no output is printed.

## Examples

Suppress output:

```wolfram
x = 5; (* returns Null, nothing printed *)
```

Explicit Null:

```wolfram
{1, Null, 2, Null, 3}
(* {1, Null, 2, Null, 3} *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Null.html) for more details.*
