# GreaterEqual

`x >= y` yields `True` if x is greater than or equal to y.

## Examples

Comparison:

```wolfram
5 >= 3
(* True *)

5 >= 5
(* True *)

4 >= 5
(* False *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GreaterEqual.html) for more details.*
