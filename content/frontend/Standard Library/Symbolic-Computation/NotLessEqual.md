# NotLessEqual

`NotLessEqual[x,y,…]` displays as x≰y≰….

## Examples

Display the not-less-or-equal relation:

```wolfram
NotLessEqual[a, b, c]
(* a ≰ b ≰ c *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NotLessEqual.html) for more details.*
