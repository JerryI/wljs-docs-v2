---
title: Rationals
---

`Rationals` represents the domain of rational numbers, as in x ∈ Rationals.

## Examples

Test membership:

```wolfram
Element[3/4, Rationals]
(* True *)
```

Pi is not rational:

```wolfram
Element[Pi, Rationals]
(* False *)
```
