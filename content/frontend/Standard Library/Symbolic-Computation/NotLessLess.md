---
title: NotLessLess
---

`NotLessLess[x, y, ...]` displays as x ≪̸ y ≪̸ ....

## Examples

```wolfram
NotLessLess[a, b, c]
```

```wolfram
a \[NotLessLess] b
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NotLessLess.html) for more details.*
