# HeaderSize

`HeaderSize` is an option for Dataset that specifies the widths and heights of headers.

## Examples

Set header size in a dataset:

```wolfram
Dataset[{<|"a" -> 1, "b" -> 2|>}, HeaderSize -> {Automatic, 2}]
```

Specify width and height:

```wolfram
Dataset[data, HeaderSize -> {100, 30}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/HeaderSize.html) for more details.*
