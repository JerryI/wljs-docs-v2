---
title: LessSlantEqual
---

`LessSlantEqual[x, y, ...]` displays as x⩽y⩽....

## Examples

```wolfram
LessSlantEqual[a, b, c]
(* a ⩽ b ⩽ c *)
```

```wolfram
LessSlantEqual[1, 2, 3]
(* True *)
```
