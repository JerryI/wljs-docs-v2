# Not

`!expr` is the logical NOT function. It gives `False` if expr is `True`, and `True` if it is `False`.

## Examples

Logical NOT:

```wolfram
!True
(* False *)

!False
(* True *)
```

With conditions:

```wolfram
x = 5;
!(x > 10)
(* True *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Not.html) for more details.*
