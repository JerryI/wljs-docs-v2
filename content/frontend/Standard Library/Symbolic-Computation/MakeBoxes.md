---
title: MakeBoxes
---

`MakeBoxes[expr, form]` is the low‐level function used in Wolfram System sessions to convert expressions into boxes.

- `MakeBoxes[expr]` is the function to convert expr to `StandardForm` boxes.

## Examples

```wolfram
MakeBoxes[x^2 + y, StandardForm]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MakeBoxes.html) for more details.*
