# NotSquareSubset

`NotSquareSubset[x, y, ...]` displays as x⊄y⊄....

## Examples

Basic usage:

```wolfram
NotSquareSubset[a, b]
```

Multiple arguments:

```wolfram
NotSquareSubset[x, y, z]
```

In expressions:

```wolfram
NotSquareSubset[A, B]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NotSquareSubset.html) for more details.*
