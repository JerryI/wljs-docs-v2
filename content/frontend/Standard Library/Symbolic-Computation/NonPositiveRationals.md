# NonPositiveRationals

`NonPositiveRationals` represents the domain of non-positive rational numbers, as in x ∈ NonPositiveRationals.

## Examples

Test membership:

```wolfram
Element[-1/2, NonPositiveRationals]
(* True *)
```

Zero is included:

```wolfram
Element[0, NonPositiveRationals]
(* True *)
```
