---
title: LessLess
---

`LessLess[x, y, ...]` displays as x≪y≪....

## Examples

Display the much-less-than relation:

```wolfram
LessLess[1, 1000000]
```

Multiple arguments:

```wolfram
LessLess[a, b, c]
```

In mathematical expressions:

```wolfram
Row[{"If ", LessLess[epsilon, 1], " then..."}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LessLess.html) for more details.*
