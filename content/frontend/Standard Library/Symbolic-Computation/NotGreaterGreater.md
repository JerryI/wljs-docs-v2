# NotGreaterGreater

`NotGreaterGreater[x, y, ...]` displays as x ≫̸ y ≫̸ ....

## Examples

Create a not-greater-greater relation:

```wolfram
NotGreaterGreater[a, b, c]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NotGreaterGreater.html) for more details.*
