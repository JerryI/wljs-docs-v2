---
title: NotLessTilde
---

`NotLessTilde[x, y, ...]` displays as x≴y≴....

## Examples

Display the not-less-tilde relation:

```wolfram
NotLessTilde[a, b]
```

Multiple arguments:

```wolfram
NotLessTilde[x, y, z]
```

In mathematical expressions:

```wolfram
Row[{x, " ", NotLessTilde[a, b], " ", y}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NotLessTilde.html) for more details.*
