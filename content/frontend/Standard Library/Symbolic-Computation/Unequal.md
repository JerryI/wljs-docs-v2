---
title: Unequal
---

`lhs != rhs` returns `True` if lhs and rhs are not identical.

## Examples

Numeric comparison:

```wolfram
3 != 4
(* True *)

5 != 5
(* False *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Unequal.html) for more details.*
