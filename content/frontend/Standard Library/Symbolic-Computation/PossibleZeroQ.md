# PossibleZeroQ

`PossibleZeroQ[expr]` gives `True` if basic symbolic and numerical methods suggest that expr has value zero, and gives `False` otherwise.

## Examples

```wolfram
PossibleZeroQ[Sin[Pi]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PossibleZeroQ.html) for more details.*
