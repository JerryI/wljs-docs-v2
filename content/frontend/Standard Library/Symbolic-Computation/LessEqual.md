# LessEqual

`x <= y` yields `True` if x is less than or equal to y.

## Examples

Comparison:

```wolfram
3 <= 5
(* True *)

5 <= 5
(* True *)

6 <= 5
(* False *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LessEqual.html) for more details.*
