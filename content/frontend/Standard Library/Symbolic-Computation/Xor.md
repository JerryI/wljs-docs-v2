---
title: Xor
---

`Xor[e1, e2, ...]` is the logical XOR (exclusive OR) function. It gives `True` if an odd number of the ei are `True`.

## Examples

Basic XOR:

```wolfram
Xor[True, False]
(* True *)

Xor[True, True]
(* False *)

Xor[False, False]
(* False *)
```

Multiple arguments:

```wolfram
Xor[True, True, True]
(* True *)
```
