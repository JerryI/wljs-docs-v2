# NotGreaterLess

`NotGreaterLess[x, y, ...]` displays as x≹y≹....

## Examples

```wolfram
NotGreaterLess[a, b]
(* a ≹ b *)
```

```wolfram
NotGreaterLess[1, 2, 3]
(* 1 ≹ 2 ≹ 3 *)
```
