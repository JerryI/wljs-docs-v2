# BooleanStrings

`BooleanStrings` is an option to `TextString` and related functions that determines what strings correspond to the Wolfram Language symbols `True` and `False`.

## Examples

```wolfram
ImportString["yes,no", "CSV", BooleanStrings -> {"yes", "no"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/BooleanStrings.html) for more details.*
