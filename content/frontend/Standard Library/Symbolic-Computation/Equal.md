# Equal

`lhs == rhs` returns `True` if lhs and rhs are identical.

## Examples

Numeric comparison:

```wolfram
5 == 5
(* True *)

3 == 4
(* False *)
```

Symbolic:

```wolfram
x == x
(* True *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Equal.html) for more details.*
