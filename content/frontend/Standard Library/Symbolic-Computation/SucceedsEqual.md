---
title: SucceedsEqual
---

`SucceedsEqual[x, y, …]` displays as x⪰y⪰….

## Examples

Display the succeeds or equal relation:

```wolfram
SucceedsEqual[a, b, c]
(* a ⪰ b ⪰ c *)
```

Use in symbolic expressions:

```wolfram
SucceedsEqual[x, y]
(* x ⪰ y *)
```
