# HeaderStyle

`HeaderStyle` is an option for `Dataset` that specifies the style to use for headers.

## Examples

```wolfram
Dataset[{<|"a" -> 1, "b" -> 2|>}, HeaderStyle -> {Bold, Red}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/HeaderStyle.html) for more details.*
