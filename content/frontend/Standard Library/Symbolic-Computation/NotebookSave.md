---
title: NotebookSave
---

`NotebookSave[nb]` or `NotebookSave[nb, path]` saves notebook nb to a file given by path or using the existing temporal path.

## Examples

```wolfram
NotebookSave[EvaluationNotebook[]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NotebookSave.html) for more details.*
