---
title: LinkReadHeld
---

`LinkReadHeld[link]` reads an expression via WSTP from link and returns it wrapped in Hold.

## Examples

Read an expression from a link without evaluating it:

```wolfram
LinkReadHeld[link]
(* Hold[expr] *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LinkReadHeld.html) for more details.*
