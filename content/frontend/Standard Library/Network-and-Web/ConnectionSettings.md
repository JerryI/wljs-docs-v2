---
title: ConnectionSettings
---

`ConnectionSettings` is an option for `URLRead` and related functions to specify advanced connection settings.

## Examples

Set connection timeout:

```wolfram
URLRead["http://example.com", ConnectionSettings -> {"Timeout" -> 10}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ConnectionSettings.html) for more details.*
