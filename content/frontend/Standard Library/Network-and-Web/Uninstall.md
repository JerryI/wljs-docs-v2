# Uninstall

`Uninstall[link]` terminates an external program started by `Install`, and removes Wolfram Language definitions set up by it.

## Examples

```wolfram
Uninstall["program"]
```

```wolfram
link = Install["myprogram"];
Uninstall[link]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Uninstall.html) for more details.*
