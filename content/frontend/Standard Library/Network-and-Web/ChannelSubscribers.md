---
title: ChannelSubscribers
---

`ChannelSubscribers[channel]` gives a list of users currently subscribed to the specified channel.

`ChannelSubscribers[{channel1,channel2,…}]` gives a list of subscribed users for each of the channels channeli.

## Examples

Get subscribers for a channel:

```wolfram
ChannelSubscribers["channel:user@example.com/mychannel"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ChannelSubscribers.html) for more details.*
