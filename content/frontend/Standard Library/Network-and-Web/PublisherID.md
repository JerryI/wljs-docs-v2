---
title: PublisherID
---

`PublisherID` is an option for `ResourceSubmit` that specifies the ID used to submit a resource for publication in the resource system.

## Examples

```wolfram
ResourceSubmit[resource, PublisherID -> "myPublisherID"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PublisherID.html) for more details.*
