---
title: URLResponseTime
---

`URLResponseTime[url]` gives the total number of seconds to request one byte from the specified URL.

`URLResponseTime[url,prop]` gives the specified timing.

## Examples

```wolfram
URLResponseTime["https://www.wolfram.com"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/URLResponseTime.html) for more details.*
