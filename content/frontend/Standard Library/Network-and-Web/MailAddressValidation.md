---
title: MailAddressValidation
---

`MailAddressValidation` is an option for `SendMail` that specifies whether and how to validate email addresses.

## Examples

```wolfram
SendMail[<|"To" -> "user@example.com"|>, MailAddressValidation -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MailAddressValidation.html) for more details.*
