# VectorPoints

`VectorPoints` is an option to `VectorPlot`, `ListVectorPlot`, and related functions that determines where to draw arrows.

## Examples

```wolfram
VectorPlot[{y, -x}, {x, -2, 2}, {y, -2, 2}, VectorPoints -> 10]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VectorPoints.html) for more details.*
