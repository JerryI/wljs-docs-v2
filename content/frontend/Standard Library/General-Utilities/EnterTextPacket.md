---
title: EnterTextPacket
---

`EnterTextPacket[string]` is a WSTP packet that requests the parsing and evaluation of string as an expression.

## Examples

This is a low-level WSTP packet:

```wolfram
EnterTextPacket["1 + 1"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EnterTextPacket.html) for more details.*
