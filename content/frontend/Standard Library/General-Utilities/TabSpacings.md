# TabSpacings

`TabSpacings` is an option for character selections that specifies the number of spaces in ems that the cursor advances when the Tab key is pressed.

## Examples

```wolfram
Style["text\twith\ttabs", TabSpacings -> 4]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TabSpacings.html) for more details.*
