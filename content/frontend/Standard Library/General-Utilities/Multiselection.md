# Multiselection

`Multiselection` is an option to `ListPicker` that specifies whether multiple values may be selected.

## Examples

```wolfram
ListPicker[{1}, {1, 2, 3}, Multiselection -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Multiselection.html) for more details.*
