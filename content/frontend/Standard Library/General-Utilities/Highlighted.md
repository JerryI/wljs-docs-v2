---
title: Highlighted
---

`Highlighted[expr]` displays a highlighted version of expr.

`Highlighted[expr, effect]` uses the effect effect to highlight plot elements representing expr.

## Examples

Highlight text:

```wolfram
Highlighted["Important text"]
(* Highlighted["Important text"] *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Highlighted.html) for more details.*
