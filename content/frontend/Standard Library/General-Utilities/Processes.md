---
title: Processes
---

`Processes[]` returns a list of currently running external processes, started in this Wolfram Language session.

## Examples

List running processes:
```wolfram
Processes[]
```

Check active processes:
```wolfram
Length[Processes[]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Processes.html) for more details.*
