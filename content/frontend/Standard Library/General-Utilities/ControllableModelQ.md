---
title: ControllableModelQ
---

`ControllableModelQ[sys]` yields True if the state-space model sys is controllable, and False otherwise.

`ControllableModelQ[{sys, sub}]` yields True if the subsystem sub is controllable.

## Examples

Check if a system is controllable:

```wolfram
ControllableModelQ[stateSpaceModel]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ControllableModelQ.html) for more details.*
