---
title: Placeholder
---

`Placeholder[name]` represents a placeholder labeled with name that indicates a place to type.

- `Placeholder[]` gives the empty placeholder.

## Examples

```wolfram
Placeholder["x"]
```

```wolfram
Placeholder[]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Placeholder.html) for more details.*
