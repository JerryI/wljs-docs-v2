---
title: PreprocessingRules
---

`PreprocessingRules` is an option that specifies how the input should be preprocessed.

## Examples

```wolfram
Import["file.txt", "PreprocessingRules" -> {"a" -> "b"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PreprocessingRules.html) for more details.*
