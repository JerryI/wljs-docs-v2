---
title: UpdatePacletSites
---

`UpdatePacletSites` is an option to `PacletInstall` and `PacletInstallSubmit` that specifies whether to first update the local cache of information about available paclets.

## Examples

```wolfram
PacletInstall["MyPaclet", UpdatePacletSites -> True]
```

```wolfram
PacletInstall["Wolfram/Chatbook", UpdatePacletSites -> False]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/UpdatePacletSites.html) for more details.*
