# RightUpVector

`RightUpVector[x, y, ...]` displays as x↾y↾....

## Examples

Display right up vector notation:
```wolfram
RightUpVector[a, b, c]
```

Use in expressions:
```wolfram
RightUpVector[x, y]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RightUpVector.html) for more details.*
