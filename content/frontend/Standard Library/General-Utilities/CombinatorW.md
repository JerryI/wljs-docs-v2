# CombinatorW

`CombinatorW` represents the **W** combinator (duplication combinator).

## Examples

Apply W combinator:

```wolfram
CombinatorW[f][x]
(* f[x][x] *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CombinatorW.html) for more details.*
