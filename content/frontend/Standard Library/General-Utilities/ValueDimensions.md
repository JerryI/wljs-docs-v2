# ValueDimensions

`ValueDimensions` is an option to `TemporalData`, `TimeSeries`, and `EventSeries` that specifies the dimension of the value space.

## Examples

```wolfram
TimeSeries[{{1, 2}, {3, 4}}, ValueDimensions -> 2]
```

```wolfram
EventSeries[data, ValueDimensions -> 1]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ValueDimensions.html) for more details.*
