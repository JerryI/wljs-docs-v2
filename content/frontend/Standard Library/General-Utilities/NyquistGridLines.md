# NyquistGridLines

`NyquistGridLines` is an option to `NyquistPlot` that specifies contours of constant magnitude and phase of a closed-loop system.

## Examples

```wolfram
NyquistPlot[TransferFunctionModel[1/(s + 1), s], NyquistGridLines -> Automatic]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NyquistGridLines.html) for more details.*
