# LicenseEntitlementObject

`LicenseEntitlementObject[…]` represents an on-demand license entitlement.

- `LicenseEntitlementObject[id]` gives the entitlement object representing the entitlement specified by id.

## Examples

```wolfram
LicenseEntitlementObject["my-entitlement-id"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LicenseEntitlementObject.html) for more details.*
