# Vectors

`Vectors[d]` represents the domain of vectors of dimension d.

`Vectors[d, dom]` represents the domain of vectors of dimension d, with components in the domain dom.

## Examples

```wolfram
Vectors[3]
(* Vectors[3] *)
```

```wolfram
Vectors[3, Reals]
(* Vectors[3, Reals] *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Vectors.html) for more details.*
