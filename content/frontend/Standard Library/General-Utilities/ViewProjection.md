---
title: ViewProjection
---

`ViewProjection` is an option for three-dimensional graphics that specifies the projection to use for the graphic.

## Examples

Orthographic projection:

```wolfram
Graphics3D[Cuboid[], ViewProjection -> "Orthographic"]
```

Perspective projection (default):

```wolfram
Graphics3D[Cuboid[], ViewProjection -> "Perspective"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ViewProjection.html) for more details.*
