# SamplingPeriod

`SamplingPeriod` is an option to `StateSpaceModel` etc. that specifies the sampling period.

## Examples

Create a discrete-time state-space model:

```wolfram
StateSpaceModel[{{0.5}}, {{1}}, {{1}}, {{0}}, SamplingPeriod -> 0.1]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SamplingPeriod.html) for more details.*
