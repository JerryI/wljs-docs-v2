# EclipseType

`EclipseType` is an option for `SolarEclipse` and `LunarEclipse` that specifies the type of eclipse being queried for.

## Examples

Find total solar eclipses:

```wolfram
SolarEclipse[{2020, 2030}, EclipseType -> "Total"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EclipseType.html) for more details.*
