# SymmetricDifference

`SymmetricDifference[list1, list2, ...]` gives the symmetric difference of the lists listi.

## Examples

Find elements in one list but not both:
```wolfram
SymmetricDifference[{1, 2, 3, 4}, {3, 4, 5, 6}]
```

With multiple lists:
```wolfram
SymmetricDifference[{a, b, c}, {b, c, d}, {c, d, e}]
```
