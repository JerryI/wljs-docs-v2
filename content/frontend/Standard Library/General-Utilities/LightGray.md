---
title: LightGray
---

`LightGray` represents a light gray color in graphics or style specifications.

## Examples

Use in graphics:

```wolfram
Graphics[{LightGray, Disk[]}]
```

Style text:

```wolfram
Style["Light gray text", LightGray]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LightGray.html) for more details.*
