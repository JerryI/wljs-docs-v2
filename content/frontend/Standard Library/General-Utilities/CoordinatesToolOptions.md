---
title: CoordinatesToolOptions
---

`CoordinatesToolOptions` is an option for `Graphics` that gives values of options associated with the Get Coordinates tool.

## Examples

Set coordinates tool options:

```wolfram
Graphics[{Circle[]}, CoordinatesToolOptions -> {"DisplayFunction" -> (ToString[#] &)}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CoordinatesToolOptions.html) for more details.*
