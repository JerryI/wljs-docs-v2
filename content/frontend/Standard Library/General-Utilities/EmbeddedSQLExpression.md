---
title: EmbeddedSQLExpression
---

`EmbeddedSQLExpression[string]` represents an SQL expression to be evaluated verbatim within an `EntityFunction` object.

`EmbeddedSQLExpression[template, args]` represents an SQL expression string template with arguments provided by args.

## Examples

Create an embedded SQL expression:

```wolfram
EmbeddedSQLExpression["COUNT(*)"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EmbeddedSQLExpression.html) for more details.*
