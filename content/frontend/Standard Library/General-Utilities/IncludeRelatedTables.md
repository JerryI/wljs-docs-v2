# IncludeRelatedTables

`IncludeRelatedTables` is an option for RelationalDatabase that specifies whether to include tables specified in foreign keys.

## Examples

```wolfram
RelationalDatabase[db, IncludeRelatedTables -> True]
(* Includes related tables from foreign keys *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/IncludeRelatedTables.html) for more details.*
