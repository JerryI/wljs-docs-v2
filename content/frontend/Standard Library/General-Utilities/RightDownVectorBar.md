---
title: RightDownVectorBar
---

`RightDownVectorBar[x, y, ...]` displays as x⥕y⥕....

## Examples

Basic usage:

```wolfram
RightDownVectorBar[a, b]
```

Multiple arguments:

```wolfram
RightDownVectorBar[x, y, z]
```

In mathematical expressions:

```wolfram
RightDownVectorBar[f[x], g[y]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RightDownVectorBar.html) for more details.*
