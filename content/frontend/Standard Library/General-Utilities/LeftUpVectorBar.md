# LeftUpVectorBar

`LeftUpVectorBar[x, y, …]` displays as x ⥘ y ⥘ ….

## Examples

```wolfram
LeftUpVectorBar[a, b]
```

```wolfram
LeftUpVectorBar[x, y, z]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LeftUpVectorBar.html) for more details.*
