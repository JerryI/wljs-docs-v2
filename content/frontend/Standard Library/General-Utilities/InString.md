---
title: InString
---

`InString[n]` is a global object that is assigned to be the text of the nth input line.

## Examples

```wolfram
1 + 1
InString[1]
(* "1 + 1" *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/InString.html) for more details.*
