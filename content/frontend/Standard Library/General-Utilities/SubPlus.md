---
title: SubPlus
---

`SubPlus[expr]` displays as expr+.

## Examples

Display an expression with subscript plus:

```wolfram
SubPlus[x]
(* x+ *)
```

Use in a formula:

```wolfram
SubPlus[a] + SubMinus[b]
(* a+ + b- *)
```
