---
title: PodWidth
---

`PodWidth` is an option for `WolframAlpha` that determines the width parameters of the content returned by the Wolfram|Alpha API.

## Examples

```wolfram
WolframAlpha["2+2", PodWidth -> 500]
```

```wolfram
WolframAlpha["weather", PodWidth -> 800]
```

```wolfram
Options[WolframAlpha, PodWidth]
```

*See the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PodWidth.html) for more details.*
