---
title: GaugeFrameStyle
---

`GaugeFrameStyle` is an option for gauge functions that specifies the style in which the frame is to be drawn.

## Examples

Create a gauge with a styled frame:

```wolfram
AngularGauge[0.5, GaugeFrameStyle -> Directive[Thick, Blue]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GaugeFrameStyle.html) for more details.*
