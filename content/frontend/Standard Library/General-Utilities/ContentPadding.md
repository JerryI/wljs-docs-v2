---
title: ContentPadding
---

`ContentPadding` is an option for objects that can be displayed with frames that specifies whether the vertical margins should shrink wrap tightly around the contents.

## Examples

Control content padding:

```wolfram
Framed["text", ContentPadding -> False]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ContentPadding.html) for more details.*
