---
title: TildeEqual
---

`TildeEqual[x, y, ...]` displays as x≃y≃….

## Examples

Create an approximate equality expression:

```wolfram
TildeEqual[a, b, c]
(* a ≃ b ≃ c *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TildeEqual.html) for more details.*
