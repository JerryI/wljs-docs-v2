# PackingMethod

`PackingMethod` is an option for `GraphPlot` and related functions that specifies how disconnected components should be packed together in the layout produced.

## Examples

Pack disconnected components using a different method:

```wolfram
GraphPlot[{1 -> 2, 3 -> 4}, PackingMethod -> "ClosestPacking"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PackingMethod.html) for more details.*
