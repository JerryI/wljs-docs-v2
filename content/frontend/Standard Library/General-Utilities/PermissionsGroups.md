# PermissionsGroups

`PermissionsGroups[]` gives a list of permissions groups belonging to the current user.

This function is used for cloud permissions management.

## Examples

```wolfram
PermissionsGroups[]
```

```wolfram
(* List all groups the current user belongs to *)
Column[PermissionsGroups[]]
```

```wolfram
Length[PermissionsGroups[]]
```
