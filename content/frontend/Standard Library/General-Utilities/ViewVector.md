---
title: ViewVector
---

`ViewVector` is an option for `Graphics3D` and related functions which specifies the position and direction of a simulated camera used to view three-dimensional objects.

## Examples

```wolfram
Graphics3D[Sphere[], ViewVector -> {{3, 0, 0}, {0, 0, 0}}]
```

```wolfram
Graphics3D[Cuboid[], ViewVector -> {{2, 2, 2}, {0, 0, 0}}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ViewVector.html) for more details.*
