---
title: Magnification
---

`Magnification` is an option for Style and Cell that specifies what magnification to use for display.

## Examples

Display text at double magnification:

```wolfram
Style["Large Text", Magnification -> 2]
```

Use smaller magnification:

```wolfram
Style["Small Text", Magnification -> 0.5]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Magnification.html) for more details.*
