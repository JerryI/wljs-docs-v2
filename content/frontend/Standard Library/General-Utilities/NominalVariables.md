---
title: NominalVariables
---

`NominalVariables` is an option for statistical functions such as `LinearModelFit` that specifies which variables should be treated as having discrete values specified by names.

## Examples

```wolfram
LinearModelFit[data, {1, x, y}, {x, y}, NominalVariables -> y]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NominalVariables.html) for more details.*
