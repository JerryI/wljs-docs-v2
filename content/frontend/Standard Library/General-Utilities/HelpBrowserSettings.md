# HelpBrowserSettings

`HelpBrowserSettings` is a global option that specifies settings for the legacy Help Browser.

## Examples

```wolfram
Options[$FrontEnd, HelpBrowserSettings]
```

```wolfram
SetOptions[$FrontEnd, HelpBrowserSettings -> {"SearchPageState" -> "Bookmarks"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/HelpBrowserSettings.html) for more details.*
