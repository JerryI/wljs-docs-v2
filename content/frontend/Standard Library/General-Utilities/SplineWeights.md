---
title: SplineWeights
---

`SplineWeights` is an option for B-spline functions and graphics primitives that specifies weights of control points.

## Examples

```wolfram
BSplineCurve[pts, SplineWeights -> {1, 2, 1, 1}]
(* B-spline curve with specified weights *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SplineWeights.html) for more details.*
