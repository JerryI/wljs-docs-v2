# LayerSizeFunction

`LayerSizeFunction` is an option for TreePlot that gives a function to specify the relative height to allow for each layer.

## Examples

Customize layer sizes in a tree plot:

```wolfram
TreePlot[{1 -> 2, 1 -> 3, 2 -> 4}, LayerSizeFunction -> (1 &)]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LayerSizeFunction.html) for more details.*
