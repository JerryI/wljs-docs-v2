# In

`In[n]` is a global object assigned to have a delayed value of the nth input line.

## Examples

Access previous input:

```wolfram
1 + 1
In[1]
(* 1 + 1 *)
```

Re-evaluate previous input:

```wolfram
In[1] // Evaluate
(* 2 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/In.html) for more details.*
