# ProcessParameterAssumptions

`ProcessParameterAssumptions[proc]` gives a logical expression for assumptions on parameters in the random process proc.

## Examples

```wolfram
ProcessParameterAssumptions[WienerProcess[μ, σ]]
```

```wolfram
ProcessParameterAssumptions[ARProcess[{a}, v]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ProcessParameterAssumptions.html) for more details.*
