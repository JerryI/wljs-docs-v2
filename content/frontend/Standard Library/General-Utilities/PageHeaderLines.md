---
title: PageHeaderLines
---

`PageHeaderLines` is an option for notebooks that specifies whether a horizontal line is inserted at the top of each page when the notebook is printed.

## Examples

```wolfram
SetOptions[EvaluationNotebook[], PageHeaderLines -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PageHeaderLines.html) for more details.*
