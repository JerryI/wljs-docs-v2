# EmbeddedService

`EmbeddedService[service]` is an object that formats as a web frame containing content from the specified external service.

## Examples

Embed a YouTube video:

```wolfram
EmbeddedService["YouTube"]["VideoID" -> "dQw4w9WgXcQ"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EmbeddedService.html) for more details.*
