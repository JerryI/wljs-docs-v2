# TickLabelOrientation

`TickLabelOrientation` is an option for AxisObject that specifies how the tick labels should be oriented relative to the axis.

## Examples

Set tick labels to be horizontal:

```wolfram
AxisObject[{0, 1}, TickLabelOrientation -> Horizontal]
```

Set tick labels to be vertical:

```wolfram
AxisObject[{0, 1}, TickLabelOrientation -> Vertical]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TickLabelOrientation.html) for more details.*
