---
title: GaugeFrameSize
---

`GaugeFrameSize` is an option for gauge functions that controls the size of the frame around the gauge.

## Examples

Create a gauge with larger frame:

```wolfram
AngularGauge[75, GaugeFrameSize -> Large]
```

Use a specific frame size:

```wolfram
HorizontalGauge[0.5, GaugeFrameSize -> 0.1]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GaugeFrameSize.html) for more details.*
