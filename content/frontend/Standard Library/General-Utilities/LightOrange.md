---
title: LightOrange
---

`LightOrange` represents a light orange color in graphics or style specifications.

## Examples

Use as a color:

```wolfram
Graphics[{LightOrange, Disk[]}]
```

In plots:

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, PlotStyle -> LightOrange]
```

With text styling:

```wolfram
Style["Hello", LightOrange, Bold]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LightOrange.html) for more details.*
