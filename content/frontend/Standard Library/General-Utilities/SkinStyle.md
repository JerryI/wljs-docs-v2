# SkinStyle

`SkinStyle` is an option of `AnatomyPlot3D` that specifies what style to use for automatically included skin subparts.

## Examples

```wolfram
AnatomyPlot3D[Entity["AnatomicalStructure", "Heart"], SkinStyle -> Opacity[0.3]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SkinStyle.html) for more details.*
