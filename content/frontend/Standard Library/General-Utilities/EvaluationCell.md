---
title: EvaluationCell
---

`EvaluationCell[]` returns a `CellObject` corresponding to the cell in which this function is being evaluated.

## Examples

Get the current evaluation cell:

```wolfram
EvaluationCell[]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EvaluationCell.html) for more details.*
