---
title: PageHeaders
---

`PageHeaders` is an option for notebooks that specifies what should be inserted as the header of each page of a notebook when it is printed.

## Examples

Set page headers for a notebook:

```wolfram
SetOptions[EvaluationNotebook[], PageHeaders -> {{"Left", "Center", "Right"}, {"Left", "Center", "Right"}}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PageHeaders.html) for more details.*
