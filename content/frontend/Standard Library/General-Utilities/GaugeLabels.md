---
title: GaugeLabels
---

`GaugeLabels` is an option for gauge functions that specifies labels to be placed on the gauge.

## Examples

Add labels to a gauge:

```wolfram
AngularGauge[75, GaugeLabels -> {"Min", "Max"}]
```

Display the current value as a label:

```wolfram
AngularGauge[75, GaugeLabels -> Automatic]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GaugeLabels.html) for more details.*
