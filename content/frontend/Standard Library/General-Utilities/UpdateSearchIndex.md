# UpdateSearchIndex

`UpdateSearchIndex[obj]` updates the given search index object.

`UpdateSearchIndex["name"]` updates the search index with the specified name in the SearchIndices[] list.

## Examples

Update a search index by name:

```wolfram
UpdateSearchIndex["MyIndex"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/UpdateSearchIndex.html) for more details.*
