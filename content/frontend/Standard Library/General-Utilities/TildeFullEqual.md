---
title: TildeFullEqual
---

`TildeFullEqual[x,y,…]` displays as x≅y≅….

## Examples

Display values with approximate equality:

```wolfram
TildeFullEqual[a, b, c]
(* a ≅ b ≅ c *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TildeFullEqual.html) for more details.*
