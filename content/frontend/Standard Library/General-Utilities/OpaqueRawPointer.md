---
title: OpaqueRawPointer
---

`OpaqueRawPointer[addr]` represents an untyped pointer to the memory address addr.

## Examples

```wolfram
OpaqueRawPointer[16^^DEADBEEF]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/OpaqueRawPointer.html) for more details.*
