# MultigraphQ

`MultigraphQ[g]` yields `True` if the graph g is a multigraph and `False` otherwise.

## Examples

```wolfram
MultigraphQ[Graph[{1 -> 2, 1 -> 2}]]
```

```wolfram
MultigraphQ[CompleteGraph[5]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MultigraphQ.html) for more details.*
