---
title: LinkFunction
---

`LinkFunction` is an option for `GeneralizedLinearModelFit` that specifies the link function for the generalized linear model.

## Examples

```wolfram
GeneralizedLinearModelFit[data, x, x, LinkFunction -> "Log"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LinkFunction.html) for more details.*
