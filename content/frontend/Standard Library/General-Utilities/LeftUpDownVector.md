# LeftUpDownVector

`LeftUpDownVector[x,y,…]` displays as x⥑y⥑….

## Examples

Display using LeftUpDownVector:

```wolfram
LeftUpDownVector[a, b, c]
(* a⥑b⥑c *)
```
