---
title: TickLengths
---

`TickLengths` is an option for `AxisObject` that specifies the lengths of the tick marks.

## Examples

Set tick lengths:
```wolfram
AxisObject[Line[{{0, 0}, {1, 0}}], TickLengths -> {0.1, 0.05}]
```

Custom tick lengths:
```wolfram
AxisObject[axis, TickLengths -> 0.2]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TickLengths.html) for more details.*
