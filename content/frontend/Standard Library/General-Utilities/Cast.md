# Cast

`Cast[val, type]` converts val to the type type, for use in compiled code.

`Cast[val, type, method]` uses the specified casting method.

## Examples

Cast an integer to a real in compiled code:

```wolfram
Cast[3, "Real64"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Cast.html) for more details.*
