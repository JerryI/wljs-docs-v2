# Enabled

`Enabled` is an option for objects such as `Slider` that specifies whether the objects should be enabled for interactive manipulation.

## Examples

Create a disabled slider:

```wolfram
Slider[0.5, Enabled -> False]
```

Create a disabled button:

```wolfram
Button["Click", Print["Clicked"], Enabled -> False]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Enabled.html) for more details.*
