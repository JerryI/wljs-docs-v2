---
title: PolarAxes
---

`PolarAxes` is an option for sector charts and polar plots that specifies whether polar axes should be drawn.

## Examples

```wolfram
PolarPlot[Sin[3 t], {t, 0, Pi}, PolarAxes -> True]
```

```wolfram
SectorChart[{{1, 2}, {3, 4}}, PolarAxes -> Automatic]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PolarAxes.html) for more details.*
