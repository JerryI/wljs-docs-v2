# GeneratedDocumentBinding

`GeneratedDocumentBinding` is an option for supplying parameters to a DocumentGenerator during manual evaluation.

## Examples

Bind parameters to a document generator:

```wolfram
DocumentGenerator[template, GeneratedDocumentBinding -> <|"name" -> "John"|>]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GeneratedDocumentBinding.html) for more details.*
