# Generic

`Generic` is a setting for the Mode option of Solve and related functions.

## Examples

Solve with Generic mode:

```wolfram
Solve[a x + b == 0, x, Mode -> Generic]
(* {{x -> -b/a}} *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Generic.html) for more details.*
