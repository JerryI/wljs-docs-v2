---
title: Iconize
---

`Iconize[expr]` gives an iconized form that can be used to stand in for expr in notebook input.

`Iconize[expr, "name"]` displays with the specified name in the icon.

## Examples

```wolfram
Iconize[Range[100], "data"]
(* displays an icon labeled "data" *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Iconize.html) for more details.*
