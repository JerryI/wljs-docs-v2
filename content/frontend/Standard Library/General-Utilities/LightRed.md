# LightRed

`LightRed` represents a light red color in graphics or style specifications.

## Examples

Use in graphics:

```wolfram
Graphics[{LightRed, Disk[]}]
```

In plots:

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, PlotStyle -> LightRed]
```

As background:

```wolfram
Style["Text", Background -> LightRed]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LightRed.html) for more details.*
