---
title: Skip
---

`Skip[stream,type]` skips one object of the specified type in an input stream.

`Skip[stream,type,n]` skips n objects of the specified type.

## Examples

```wolfram
str = OpenRead["file.txt"];
Skip[str, String]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Skip.html) for more details.*
