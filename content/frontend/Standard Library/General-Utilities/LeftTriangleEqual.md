# LeftTriangleEqual

`LeftTriangleEqual[x,y,…]` displays as x⊴y⊴….

## Examples

Display a left triangle equal relation:

```wolfram
LeftTriangleEqual[a, b, c]
(* a⊴b⊴c *)
```
