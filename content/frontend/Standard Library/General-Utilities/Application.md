---
title: Application
---

`f @ g` or `Application[f, g]` represents the formal application of f to g.

## Examples

Use Application notation:

```wolfram
f @ x
(* f[x] *)
```

Chain applications:

```wolfram
Sin @ Cos @ x
(* Sin[Cos[x]] *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Application.html) for more details.*
