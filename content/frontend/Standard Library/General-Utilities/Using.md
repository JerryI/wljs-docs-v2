---
title: Using
---

`Using` is an option to `Roots` that specifies any subsidiary equations that are to be used.

## Examples

Solve with subsidiary equations:

```wolfram
Roots[x^2 + a*x + b == 0, x, Using -> {a == 2, b == 1}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Using.html) for more details.*
