---
title: PageTheme
---

`PageTheme` is an option for `FormObject`, `GalleryView`, and related functions that specifies an overall theme for a webpage and its elements.

## Examples

Create a form with a theme:
```wolfram
FormObject[{"name" -> "String"}, PageTheme -> "Blue"]
```

Gallery with page theme:
```wolfram
GalleryView[images, PageTheme -> "Light"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PageTheme.html) for more details.*
