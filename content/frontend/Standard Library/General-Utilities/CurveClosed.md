---
title: CurveClosed
---

`CurveClosed` is an option for `JoinedCurve` that specifies whether individual curve components should be closed curves.

## Examples

Create a closed curve:

```wolfram
JoinedCurve[{{0, 0}, {1, 1}, {2, 0}}, CurveClosed -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CurveClosed.html) for more details.*
