---
title: GeneratedAssetFormat
---

`GeneratedAssetFormat` is an option for functions like VideoGenerator that specifies the format of the resulting asset.

## Examples

Generate a video in MP4 format:

```wolfram
VideoGenerator[f, 10, GeneratedAssetFormat -> "MP4"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GeneratedAssetFormat.html) for more details.*
