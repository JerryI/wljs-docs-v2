# Scrollbars

`Scrollbars` is an option for `Pane` that specifies whether scrollbars should be displayed.

## Examples

```wolfram
Pane[Range[100], {200, 100}, Scrollbars -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Scrollbars.html) for more details.*
