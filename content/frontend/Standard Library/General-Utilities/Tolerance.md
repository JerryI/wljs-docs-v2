# Tolerance

`Tolerance` is an option for various numerical functions which specifies the tolerance that should be allowed in computing results.

## Examples

Use Tolerance in SameQ comparisons:

```wolfram
SameQ[1.0, 1.0000001, Tolerance -> 0.001]
(* True *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Tolerance.html) for more details.*
