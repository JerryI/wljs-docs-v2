---
title: ErlangC
---

`ErlangC[c, a]` computes the Erlang C probability for nonzero waiting time in an M/M/c queue.

## Examples

Compute Erlang C probability:

```wolfram
ErlangC[10, 8]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ErlangC.html) for more details.*
