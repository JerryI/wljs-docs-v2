# AnchoredSearch

`AnchoredSearch` is an option for `Find` and `FindList` that specifies whether the text searched for must be at the beginning of a record.

## Examples

Search only at the beginning of lines:

```wolfram
FindList["file.txt", "pattern", AnchoredSearch -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AnchoredSearch.html) for more details.*
