---
title: ScriptSizeMultipliers
---

`ScriptSizeMultipliers` is an option for `Style` that specifies how much smaller to render each successive level of subscripts, etc.

## Examples

```wolfram
Style[Subscript[x, Subscript[y, z]], ScriptSizeMultipliers -> 0.7]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ScriptSizeMultipliers.html) for more details.*
