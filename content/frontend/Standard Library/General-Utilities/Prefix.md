---
title: Prefix
---

`Prefix[f[expr]]` prints with `f[expr]` given in default prefix form: `f @ expr`.

- `Prefix[f[expr], h]` prints as `h @ expr`.

## Examples

```wolfram
Prefix[f[x]]
```

```wolfram
f @ x
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Prefix.html) for more details.*
