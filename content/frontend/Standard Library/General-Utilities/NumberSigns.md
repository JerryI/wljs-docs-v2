# NumberSigns

`NumberSigns` is an option for `NumberForm` and related functions which gives strings to use as signs for negative and positive numbers.

## Examples

```wolfram
NumberForm[-123.45, NumberSigns -> {"(", ")"}]
```

```wolfram
NumberForm[{-5, 5}, NumberSigns -> {"-", "+"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NumberSigns.html) for more details.*
