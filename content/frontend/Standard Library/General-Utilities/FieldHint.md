---
title: FieldHint
---

`FieldHint` is an option for InputField that specifies contents to display when the input field is empty.

## Examples

```wolfram
(* Create an input field with a hint *)
InputField["", String, FieldHint -> "Enter your name"]

(* With styled hint *)
InputField["", Number, FieldHint -> "Enter a value"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/FieldHint.html) for more details.*
