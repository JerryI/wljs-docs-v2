---
title: Large
---

`Large` is a style or option setting that specifies that objects should be large.

## Examples

Apply large styling to text:

```wolfram
Style["Large Text", Large]
```

Set font size:

```wolfram
Style["Hello", FontSize -> Large]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Large.html) for more details.*
