---
title: ExclusionsStyle
---

`ExclusionsStyle` is an option to plotting functions that specifies how to render subregions excluded according to `Exclusions`.

## Examples

Style exclusion regions:

```wolfram
Plot[Tan[x], {x, 0, 2Pi}, ExclusionsStyle -> Dashed]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ExclusionsStyle.html) for more details.*
