# GeneratedQuantityMagnitudes

`GeneratedQuantityMagnitudes` is an option that specifies how quantities generated to represent the quantity multiplier results in NondimensionalizationTransform should be named.

## Examples

Use custom magnitude names:

```wolfram
NondimensionalizationTransform[expr, GeneratedQuantityMagnitudes -> {"L", "T", "M"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GeneratedQuantityMagnitudes.html) for more details.*
