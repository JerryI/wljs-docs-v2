---
title: SquareSuperset
---

`SquareSuperset[x, y, ...]` displays as x⊐y⊐....

## Examples

Display square superset notation:
```wolfram
SquareSuperset[a, b, c]
```

Use in expressions:
```wolfram
SquareSuperset[set1, set2]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SquareSuperset.html) for more details.*
