---
title: LinkObject
---

`LinkObject["name",n1,n2]` is an object that represents an active WSTP connection for functions such as LinkRead and LinkWrite.

## Examples

Get all active links:

```wolfram
Links[]
(* {LinkObject[...], ...} *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LinkObject.html) for more details.*
