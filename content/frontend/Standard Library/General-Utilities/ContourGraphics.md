# ContourGraphics

`ContourGraphics[array]` is a representation of a contour plot.

## Examples

Create contour graphics:

```wolfram
ContourGraphics[Table[Sin[x] Cos[y], {x, 0, 3, 0.1}, {y, 0, 3, 0.1}]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ContourGraphics.html) for more details.*
