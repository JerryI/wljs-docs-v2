# LightPurple

`LightPurple` represents a light purple color in graphics or style specifications.

This is a named color constant for use in graphics and styling.

## Examples

```wolfram
Graphics[{LightPurple, Disk[]}]
```

```wolfram
Style["Hello", LightPurple, Bold]
```

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, PlotStyle -> LightPurple]
```

*See the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LightPurple.html) for more details.*
