# SubtitleEncoding

`SubtitleEncoding` is an option for `Export` and other functions that specifies the subtitle encoding to use when creating a video file.

## Examples

```wolfram
Export["video.mp4", video, SubtitleEncoding -> "UTF-8"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SubtitleEncoding.html) for more details.*
