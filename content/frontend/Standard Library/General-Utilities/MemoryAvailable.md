# MemoryAvailable

`MemoryAvailable[]` gives the estimated number of bytes readily available for storing additional data in the current Wolfram Language kernel session.

## Examples

Check available memory:
```wolfram
MemoryAvailable[]
```

Display in megabytes:
```wolfram
MemoryAvailable[] / 10^6
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MemoryAvailable.html) for more details.*
