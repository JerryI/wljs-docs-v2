---
title: EquatedTo
---

`EquatedTo` is an option for `Roots`, which specifies an expression to use in place of the variable in the solution.

## Examples

Use EquatedTo option:

```wolfram
Roots[x^2 - 4 == 0, x, EquatedTo -> y]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EquatedTo.html) for more details.*
