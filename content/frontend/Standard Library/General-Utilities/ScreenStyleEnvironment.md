---
title: ScreenStyleEnvironment
---

`ScreenStyleEnvironment` is an option for notebooks that specifies the style environment to be used in displaying a notebook on the screen.

## Examples

```wolfram
SetOptions[EvaluationNotebook[], ScreenStyleEnvironment -> "Presentation"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ScreenStyleEnvironment.html) for more details.*
