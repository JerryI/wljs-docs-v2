# AlternateImage

`AlternateImage` is an option to CDFInformation that specifies an image that should be used if the plugin is not available.

## Examples

```wolfram
Options[CDFInformation, AlternateImage]
```

```wolfram
CDFInformation[expr, AlternateImage -> myImage]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AlternateImage.html) for more details.*
