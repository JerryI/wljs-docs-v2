---
title: GaugeFaceStyle
---

`GaugeFaceStyle` is an option for gauge functions that specifies the style in which the face is to be drawn.

## Examples

Create a gauge with a colored face:

```wolfram
AngularGauge[75, GaugeFaceStyle -> LightBlue]
```

Use a custom face style:

```wolfram
HorizontalGauge[0.5, GaugeFaceStyle -> Directive[LightGray, EdgeForm[Black]]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GaugeFaceStyle.html) for more details.*
