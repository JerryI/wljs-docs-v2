---
title: EscapeRadius
---

`EscapeRadius` is an option to `MandelbrotSetPlot` that specifies the criterion to use to decide that a point is not in the Mandelbrot set.

## Examples

Set escape radius for Mandelbrot plot:

```wolfram
MandelbrotSetPlot[EscapeRadius -> 100]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EscapeRadius.html) for more details.*
