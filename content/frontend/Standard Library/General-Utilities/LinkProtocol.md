# LinkProtocol

`LinkProtocol` is an option to `LinkLaunch`, `Install`, and related functions that specifies the underlying data transport protocol to use for a new WSTP link.

## Examples

```wolfram
Options[LinkLaunch, LinkProtocol]
(* {LinkProtocol :> $LinkProtocol} *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LinkProtocol.html) for more details.*
