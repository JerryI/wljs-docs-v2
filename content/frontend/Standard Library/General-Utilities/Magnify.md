# Magnify

`Magnify[expr, r]` represents an object to be displayed with magnification r.

- `Magnify[expr]` displays with expr magnified by a fixed factor.

## Examples

```wolfram
Magnify[Graphics[Circle[]], 2]
```

```wolfram
Magnify["Hello", 3]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Magnify.html) for more details.*
