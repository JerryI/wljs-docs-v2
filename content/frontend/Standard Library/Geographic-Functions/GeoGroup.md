# GeoGroup

`GeoGroup[geoobjects]` represents a list of geographic objects to be treated as a single object for certain operations.

## Examples

Create a group of geo positions:

```wolfram
GeoGroup[{GeoPosition[{40.7, -74.0}], GeoPosition[{34.0, -118.2}]}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GeoGroup.html) for more details.*
