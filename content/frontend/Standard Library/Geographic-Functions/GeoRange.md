# GeoRange

`GeoRange` is an option for geographic functions that specifies the range of latitude and longitude to include.

## Examples

```wolfram
GeoGraphics[{}, GeoRange -> {{30, 60}, {-10, 20}}]
```

```wolfram
GeoGraphics[Entity["Country", "France"], GeoRange -> "World"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GeoRange.html) for more details.*
