# GeoVariant

`GeoVariant[obj, qual]` represents a geographic object `obj` with qualifier `qual`.

## Examples

```wolfram
GeoVariant[Entity["Country", "France"], "MainlandArea"]
```

```wolfram
GeoGraphics[GeoVariant[Entity["Country", "UnitedStates"], "Continental"]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GeoVariant.html) for more details.*
