---
title: GeoProjectionData
---

`GeoProjectionData["projection", "property"]` gives the value of the specified property for the specified cartographic projection.

- `GeoProjectionData["projection"]` gives the complete options for the default form of the specified projection.

## Examples

```wolfram
GeoProjectionData["Mercator"]
```

```wolfram
GeoProjectionData["LambertConformalConic", "ProjectionCenter"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GeoProjectionData.html) for more details.*
