---
title: GeoBackground
---

`GeoBackground` is an option that specifies the background style of a `GeoGraphics` object.

## Examples

```wolfram
GeoGraphics[{}, GeoBackground -> "Satellite"]
```

```wolfram
GeoGraphics[{}, GeoBackground -> "StreetMap"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GeoBackground.html) for more details.*
