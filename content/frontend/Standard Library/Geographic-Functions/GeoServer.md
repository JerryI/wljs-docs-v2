---
title: GeoServer
---

`GeoServer` is an option for `GeoGraphics`, `GeoStyling` and `GeoImage` that specifies the URL address of a geo server and connection parameters to download map tiles and geo elevation data.

## Examples

```wolfram
GeoGraphics[{}, GeoServer -> "OpenStreetMap"]
```

```wolfram
Options[GeoGraphics, GeoServer]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GeoServer.html) for more details.*
