# GeoGridRangePadding

`GeoGridRangePadding` is an option for geographic functions that specifies how much to extend the projected coordinate ranges determined by `GeoGridRange`.

## Examples

```wolfram
GeoGraphics[{}, GeoGridRangePadding -> 0.1]
```

```wolfram
GeoGraphics[Entity["Country", "France"], GeoGridRangePadding -> Scaled[0.2]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GeoGridRangePadding.html) for more details.*
