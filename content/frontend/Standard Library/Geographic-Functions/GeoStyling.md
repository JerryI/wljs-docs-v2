---
title: GeoStyling
---

`GeoStyling[mapstyle]` displays faces of polygons and other filled geo objects using mapstyle.

`GeoStyling[mapstyle,directive]` uses mapstyle with the given graphics directive applied.

## Examples

```wolfram
GeoGraphics[{GeoStyling["StreetMap"], GeoDisk[]}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GeoStyling.html) for more details.*
