---
title: GeoArraySize
---

`GeoArraySize` is an option for geographic data functions that determines the dimensions of the array generated.

## Examples

```wolfram
GeoElevationData[Entity["Country", "Switzerland"], GeoArraySize -> {100, 100}]
```

```wolfram
Options[GeoElevationData, GeoArraySize]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GeoArraySize.html) for more details.*
