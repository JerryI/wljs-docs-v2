# GeoGridLines

`GeoGridLines` is an option for `GeoGraphics` that specifies what parallels and meridians to show.

## Examples

```wolfram
GeoGraphics[{}, GeoGridLines -> Automatic]
```

```wolfram
GeoGraphics[{}, GeoGridLines -> {{-90, -60, -30, 0, 30, 60, 90}, Automatic}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GeoGridLines.html) for more details.*
