# Decimal

`Decimal` is a setting for the `ColumnAlignments` option of `GridBox` which states that numbers should align along the decimal place.

## Examples

Align numbers by decimal point:

```wolfram
Grid[{{1.5}, {12.34}, {0.7}}, Alignment -> Decimal]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Decimal.html) for more details.*
