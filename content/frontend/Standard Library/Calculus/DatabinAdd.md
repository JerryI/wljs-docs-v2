---
title: DatabinAdd
---

`DatabinAdd[bin,data]` adds the specified data to a databin.

## Examples

Add data to a databin:

```wolfram
DatabinAdd[bin, {1, 2, 3}]
```

Add an association:

```wolfram
DatabinAdd[bin, <|"x" -> 1, "y" -> 2|>]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DatabinAdd.html) for more details.*
