---
title: DatabinSubmit
---

`DatabinSubmit[bin, data]` submits the specified data to be added to the databin bin asynchronously.

## Examples

Submit data to a databin:

```wolfram
DatabinSubmit[bin, {"temperature" -> 25}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DatabinSubmit.html) for more details.*
