# DefaultFrameTicksStyle

`DefaultFrameTicksStyle` is a low-level option for 2D graphics functions that specifies the default style to use in rendering frame ticks.

## Examples

Set default frame ticks style:

```wolfram
Plot[Sin[x], {x, 0, 2Pi}, Frame -> True, DefaultFrameTicksStyle -> Directive[Red, 12]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DefaultFrameTicksStyle.html) for more details.*
