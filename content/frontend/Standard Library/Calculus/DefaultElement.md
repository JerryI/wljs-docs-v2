# DefaultElement

`DefaultElement` is an option for `Grid` and related constructs which specifies what to insert when a new element is interactively created.

## Examples

```wolfram
Grid[{{1, 2}, {3, 4}}, DefaultElement -> ""]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DefaultElement.html) for more details.*
