---
title: DataRange
---

`DataRange` is an option for functions such as `ListPlot` and `ListDensityPlot` that specifies what range of actual coordinates the data should be assumed to occupy.

## Examples

```wolfram
ListPlot[{1, 4, 9, 16}, DataRange -> {0, 3}]
(* plots with x values from 0 to 3 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DataRange.html) for more details.*
