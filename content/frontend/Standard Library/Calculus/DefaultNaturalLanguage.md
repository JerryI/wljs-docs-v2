---
title: DefaultNaturalLanguage
---

`DefaultNaturalLanguage` is an option for character selections that specifies the language used when checking the spelling of a word in a human natural language selection.

## Examples

Set the default natural language for spell checking:

```wolfram
DefaultNaturalLanguage -> "English"
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DefaultNaturalLanguage.html) for more details.*
