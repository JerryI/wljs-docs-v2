---
title: DefaultFrameStyle
---

`DefaultFrameStyle` is a low-level option for graphics and related constructs that specifies the default style to use in displaying their frames.

## Examples

Set default frame style:

```wolfram
Plot[Sin[x], {x, 0, 2Pi}, Frame -> True, DefaultFrameStyle -> Thick]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DefaultFrameStyle.html) for more details.*
