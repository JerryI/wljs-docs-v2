---
title: DeliveryFunction
---

`DeliveryFunction` is an option that specifies how material such as documents generated by `DocumentGenerator` should be delivered.

## Examples

Set delivery function for document generation:

```wolfram
DocumentGenerator[template, DeliveryFunction -> "Email"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DeliveryFunction.html) for more details.*
