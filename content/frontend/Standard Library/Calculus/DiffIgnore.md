# DiffIgnore

`DiffIgnore` is an option to Diff and related functions that specifies what elements to ignore when computing diffs.

## Examples

Ignore whitespace when computing diffs:

```wolfram
Diff[str1, str2, DiffIgnore -> "Whitespace"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DiffIgnore.html) for more details.*
