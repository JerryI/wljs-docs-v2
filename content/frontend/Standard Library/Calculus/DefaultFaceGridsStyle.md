---
title: DefaultFaceGridsStyle
---

`DefaultFaceGridsStyle` is a low-level option for 3D graphics functions that specifies the default style to use in rendering face grids.

## Examples

Set default face grids style:

```wolfram
Graphics3D[Sphere[], DefaultFaceGridsStyle -> Gray]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DefaultFaceGridsStyle.html) for more details.*
