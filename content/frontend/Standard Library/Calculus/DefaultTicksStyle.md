# DefaultTicksStyle

`DefaultTicksStyle` is a low-level option for graphics functions that specifies the default style to use in rendering ticks.

## Examples

Set the default ticks style in a plot:

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, DefaultTicksStyle -> Directive[Red, 12]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DefaultTicksStyle.html) for more details.*
