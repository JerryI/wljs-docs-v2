---
title: DigitBlock
---

`DigitBlock` is an option for `NumberForm` and related functions that specifies the maximum length of blocks of digits between breaks.

## Examples

Format number with digit blocks:

```wolfram
NumberForm[1234567890, DigitBlock -> 3]
(* 1,234,567,890 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DigitBlock.html) for more details.*
