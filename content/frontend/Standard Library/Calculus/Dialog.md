# Dialog

`Dialog[]` initiates a dialog.

`Dialog[expr]` initiates a dialog with expr as the current value of %.

## Examples

Start a dialog with a value:

```wolfram
Dialog[42]
(* Opens dialog with % set to 42 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Dialog.html) for more details.*
