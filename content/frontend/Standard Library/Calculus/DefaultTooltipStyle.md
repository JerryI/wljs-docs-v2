---
title: DefaultTooltipStyle
---

`DefaultTooltipStyle` is a low-level option for tooltips that specifies the default style to use in displaying their elements.

## Examples

```wolfram
SetOptions[$FrontEnd, DefaultTooltipStyle -> {FontSize -> 14, Background -> LightYellow}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DefaultTooltipStyle.html) for more details.*
