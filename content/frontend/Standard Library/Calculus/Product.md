# Product

`Product[f, {i, imin, imax}]` evaluates the product of f as i ranges from imin to imax.

## Examples

Factorial as a product:

```wolfram
Product[i, {i, 1, 5}]
(* 120 *)
```

Symbolic product:

```wolfram
Product[x + i, {i, 0, 3}]
(* x (1 + x) (2 + x) (3 + x) *)
```
