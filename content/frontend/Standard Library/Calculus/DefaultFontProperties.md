---
title: DefaultFontProperties
---

`DefaultFontProperties` is a global option that allows overriding properties of specified font families.

## Examples

Set default font properties:

```wolfram
Style["Hello", DefaultFontProperties -> {"Weight" -> "Bold"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DefaultFontProperties.html) for more details.*
