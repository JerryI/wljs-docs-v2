---
title: Delimiters
---

`Delimiters` is an option to various functions that specifies what delimiters to use or look for.

## Examples

Use custom delimiters:

```wolfram
StringSplit["a,b;c", Delimiters -> {",", ";"}]
(* {"a", "b", "c"} *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Delimiters.html) for more details.*
