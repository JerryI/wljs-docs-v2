---
title: CSGRegionQ
---

`CSGRegionQ[reg]` yields `True` if the region reg is a valid CSGRegion object and `False` otherwise.

## Examples

Check if a region is a valid CSG region:

```wolfram
CSGRegionQ[CSGRegionUnion[Ball[], Cuboid[]]]
(* True *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CSGRegionQ.html) for more details.*
