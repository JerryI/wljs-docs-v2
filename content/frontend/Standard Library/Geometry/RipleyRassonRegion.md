# RipleyRassonRegion

`RipleyRassonRegion[pdata]` gives an estimated observation based on the point data pdata.

## Examples

```wolfram
points = RandomPoint[Disk[], 50];
RipleyRassonRegion[points]
```

```wolfram
RipleyRassonRegion[RandomReal[1, {100, 2}]]
```
