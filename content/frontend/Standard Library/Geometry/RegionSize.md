---
title: RegionSize
---

`RegionSize` is an option used by `Printout3D` to specify the overall size of an object to print for a region.

## Examples

```wolfram
Printout3D[Sphere[], RegionSize -> Quantity[5, "Centimeters"]]
```

```wolfram
Printout3D[Cuboid[], RegionSize -> {10, 10, 10}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RegionSize.html) for more details.*
