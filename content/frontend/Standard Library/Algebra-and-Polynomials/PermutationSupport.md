# PermutationSupport

`PermutationSupport[perm]` returns the support of the permutation perm.

## Examples

Get the support of a permutation (elements that are moved):

```wolfram
PermutationSupport[Cycles[{{1, 3, 5}}]]
(* {1, 3, 5} *)
```
