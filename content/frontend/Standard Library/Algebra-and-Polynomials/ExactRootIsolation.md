# ExactRootIsolation

`ExactRootIsolation` is an option for `Root`, which specifies whether exact isolating intervals rather than numeric approximations should be used to identify algebraic numbers.

## Examples

Use exact root isolation:

```wolfram
Root[x^5 - x - 1, 1, ExactRootIsolation -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ExactRootIsolation.html) for more details.*
