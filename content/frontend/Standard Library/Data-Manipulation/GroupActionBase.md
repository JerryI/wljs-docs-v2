---
title: GroupActionBase
---

`GroupActionBase` is an option to specify a base for a group.

## Examples

```wolfram
GroupOrbits[SymmetricGroup[4], GroupActionBase -> {1, 2}]
```

```wolfram
GroupStabilizer[AlternatingGroup[5], 1, GroupActionBase -> {1, 2, 3}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GroupActionBase.html) for more details.*
