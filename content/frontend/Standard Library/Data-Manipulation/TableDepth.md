# TableDepth

`TableDepth` is an option for `TableForm` and `MatrixForm` that specifies the maximum number of levels to be printed in tabular or matrix format.

## Examples

```wolfram
TableForm[{{{1, 2}, {3, 4}}, {{5, 6}, {7, 8}}}, TableDepth -> 2]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TableDepth.html) for more details.*
