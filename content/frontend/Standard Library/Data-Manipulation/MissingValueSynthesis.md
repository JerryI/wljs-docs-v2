# MissingValueSynthesis

`MissingValueSynthesis` is an option for functions such as `Classify` that specifies how missing values should be replaced.

## Examples

```wolfram
Classify[trainingData, testData, MissingValueSynthesis -> Automatic]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MissingValueSynthesis.html) for more details.*
