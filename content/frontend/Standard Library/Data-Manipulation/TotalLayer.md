# TotalLayer

`TotalLayer[]` represents a net layer taking a list of input arrays and performing elementwise addition on them.

## Examples

```wolfram
TotalLayer[][{{1, 2, 3}, {4, 5, 6}}]
(* {5, 7, 9} *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TotalLayer.html) for more details.*
