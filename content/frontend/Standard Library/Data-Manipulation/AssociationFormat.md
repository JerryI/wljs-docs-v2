# AssociationFormat

`AssociationFormat` is an option to TextString and related functions that determines how associations are formatted.

## Examples

```wolfram
TextString[<|"a" -> 1, "b" -> 2|>, AssociationFormat -> "JSON"]
(* {"a": 1, "b": 2} *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AssociationFormat.html) for more details.*
