---
title: First
---

`First[expr]` gives the first element in expr.

`First[expr, def]` gives the first element if it exists, or def otherwise.

## Examples

Get the first element:

```wolfram
First[{a, b, c}]
(* a *)
```

With a default value:

```wolfram
First[{}, "empty"]
(* "empty" *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/First.html) for more details.*
