# Joined

`Joined` is an option for `ListPlot` and related functions that specifies whether points in each dataset should be joined into a line, or should be plotted as separate points.

## Examples

```wolfram
ListPlot[{1, 4, 2, 5, 3}, Joined -> True]
```

```wolfram
ListPlot[{1, 4, 2, 5, 3}, Joined -> False]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Joined.html) for more details.*
