---
title: MissingString
---

`MissingString` is an option for `TextString` and related functions that indicates how an expression with head `Missing` should be converted to a string.

## Examples

```wolfram
TextString[{1, Missing["Unknown"], 3}, MissingString -> "N/A"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MissingString.html) for more details.*
