---
title: ArrayPlot3D
---

`ArrayPlot3D[array]` generates a plot in which the values in an array are shown in a discrete array of cubes.

## Examples

```wolfram
ArrayPlot3D[RandomReal[1, {5, 5, 5}]]
(* 3D array visualization *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ArrayPlot3D.html) for more details.*
