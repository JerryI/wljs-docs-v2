---
title: NormalMatrixQ
---

`NormalMatrixQ[m]` gives `True` if m is an explicitly normal matrix, and `False` otherwise.

## Examples

```wolfram
NormalMatrixQ[{{1, 0}, {0, 1}}]
(* True *)
```

```wolfram
NormalMatrixQ[{{1, 2}, {0, 1}}]
(* False *)
```
