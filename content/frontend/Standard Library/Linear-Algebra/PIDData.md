# PIDData

`PIDData[...]` represents PID data generated by `PIDTune` function.

## Examples

Generate PID data:

```wolfram
sys = TransferFunctionModel[1/(s^2 + s + 1), s];
data = PIDTune[sys, "PIDData"]
```

Extract controller:

```wolfram
data["Controller"]
```

Get tuning parameters:

```wolfram
data["Parameters"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PIDData.html) for more details.*
