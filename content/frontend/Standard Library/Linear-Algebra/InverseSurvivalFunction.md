# InverseSurvivalFunction

`InverseSurvivalFunction[dist, q]` gives the inverse of the survival function for the distribution *dist* as a function of the variable *q*.

## Examples

```wolfram
InverseSurvivalFunction[NormalDistribution[], 0.1]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/InverseSurvivalFunction.html) for more details.*
