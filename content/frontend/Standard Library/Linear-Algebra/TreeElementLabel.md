---
title: TreeElementLabel
---

`TreeElementLabel` is an option for `Tree` and related functions that specifies what labels should be used for subtree elements.

## Examples

```wolfram
Tree[a -> {b, c}, TreeElementLabel -> Automatic]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TreeElementLabel.html) for more details.*
