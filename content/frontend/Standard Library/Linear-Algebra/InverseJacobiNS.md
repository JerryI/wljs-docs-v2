# InverseJacobiNS

`InverseJacobiNS[v,m]` gives the inverse Jacobi elliptic function ns⁻¹(v|m).

## Examples

Compute the inverse Jacobi ns function:

```wolfram
InverseJacobiNS[2, 1/2]
(* 0.481212 *)
```
