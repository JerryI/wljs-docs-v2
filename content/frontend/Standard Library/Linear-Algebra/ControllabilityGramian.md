# ControllabilityGramian

`ControllabilityGramian[ssm]` gives the controllability Gramian of the state-space model ssm.

## Examples

```wolfram
ControllabilityGramian[StateSpaceModel[{{0, 1}, {-2, -3}}, {{0}, {1}}, {{1, 0}}, {{0}}]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ControllabilityGramian.html) for more details.*
