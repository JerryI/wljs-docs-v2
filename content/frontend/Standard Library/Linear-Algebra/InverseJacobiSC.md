# InverseJacobiSC

`InverseJacobiSC[v, m]` gives the inverse Jacobi elliptic function sc⁻¹(v|m).

## Examples

```wolfram
InverseJacobiSC[1, 0]
(* Pi/4 *)
```

```wolfram
InverseJacobiSC[2, 1/2] // N
(* 1.08879 *)
```
