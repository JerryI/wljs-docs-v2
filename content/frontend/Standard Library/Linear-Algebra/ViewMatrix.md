# ViewMatrix

`ViewMatrix` is an option for `Graphics3D` and related functions that can be used to specify a pair of explicit homogeneous transformation and projection matrices for 3D coordinates.

## Examples

```wolfram
Graphics3D[Sphere[], ViewMatrix -> Automatic]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ViewMatrix.html) for more details.*
