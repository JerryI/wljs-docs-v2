---
title: Trig
---

`Trig` is an option for various polynomial manipulation functions that specifies whether trigonometric functions should be treated like polynomial elements.

## Examples

```wolfram
Factor[Sin[x]^2 + 2 Sin[x] Cos[x] + Cos[x]^2, Trig -> True]
```

```wolfram
Expand[expr, Trig -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Trig.html) for more details.*
