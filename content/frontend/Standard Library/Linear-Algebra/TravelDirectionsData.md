---
title: TravelDirectionsData
---

`TravelDirectionsData[...]` represents travel directions generated by `TravelDirections`.

## Examples

```wolfram
td = TravelDirections[{"New York", "Boston"}];
td["TotalDistance"]
```

```wolfram
TravelDirectionsData[...]["TravelTime"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TravelDirectionsData.html) for more details.*
