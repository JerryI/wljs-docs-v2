# SquareMatrixQ

`SquareMatrixQ[m]` gives True if m is a square matrix, and False otherwise.

## Examples

```wolfram
SquareMatrixQ[{{1, 2}, {3, 4}}]
(* True *)
```

```wolfram
SquareMatrixQ[{{1, 2, 3}, {4, 5, 6}}]
(* False *)
```
