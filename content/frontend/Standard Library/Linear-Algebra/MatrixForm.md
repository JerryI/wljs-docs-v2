---
title: MatrixForm
---

`MatrixForm[list]` prints with the elements of list arranged in a regular array.

## Examples

Display a matrix:

```wolfram
MatrixForm[{{1, 2, 3}, {4, 5, 6}, {7, 8, 9}}]
```

Display a vector:

```wolfram
MatrixForm[{a, b, c}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MatrixForm.html) for more details.*
