# InnerPolygon

`InnerPolygon[poly]` gives the inner polygon of the polygon poly.

## Examples

Get the inner polygon of a star:

```wolfram
InnerPolygon[Polygon[CirclePoints[5]]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/InnerPolygon.html) for more details.*
