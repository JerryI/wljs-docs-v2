---
title: LoadCompiledComponent
---

`LoadCompiledComponent[comp]` loads a compiled component comp.

`LoadCompiledComponent[comp,target]` loads a compiled component comp from the target location.

## Examples

Load a compiled component:

```wolfram
LoadCompiledComponent["MyComponent"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LoadCompiledComponent.html) for more details.*
