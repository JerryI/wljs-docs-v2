---
title: CreateDatabin
---

`CreateDatabin[]` creates a databin in the Wolfram Data Drop and returns the corresponding Databin object.

`CreateDatabin[options]` creates a databin with the specified options.

## Examples

Create a new databin:

```wolfram
bin = CreateDatabin[]
```

Create a databin with a name:

```wolfram
bin = CreateDatabin["Name" -> "My Data"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CreateDatabin.html) for more details.*
