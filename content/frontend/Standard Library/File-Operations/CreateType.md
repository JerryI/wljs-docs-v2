---
title: CreateType
---

`CreateType[type, parent, init, {fields}]` creates a new type for use in compiled code.

## Examples

Create a simple type:

```wolfram
CreateType["MyType", Null, Automatic, {"field1", "field2"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CreateType.html) for more details.*
