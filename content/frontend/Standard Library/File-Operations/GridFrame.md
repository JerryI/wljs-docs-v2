---
title: GridFrame
---

`GridFrame` is an option for grids that specifies whether a surrounding frame is drawn.

## Examples

```wolfram
Grid[{{1, 2}, {3, 4}}, GridFrame -> True]
```

```wolfram
Grid[{{a, b}, {c, d}}, Frame -> All, GridFrame -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GridFrame.html) for more details.*
