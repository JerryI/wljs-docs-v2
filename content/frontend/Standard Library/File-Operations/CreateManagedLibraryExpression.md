# CreateManagedLibraryExpression

`CreateManagedLibraryExpression[mname, f]` creates a managed library expression by applying f to a positive integer ID associated with a registered manager with name mname.

## Examples

Create a managed library expression:

```wolfram
expr = CreateManagedLibraryExpression["MyManager", myConstructor]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CreateManagedLibraryExpression.html) for more details.*
