---
title: StatusArea
---

`StatusArea[expr, string]` displays string in the status area of the current notebook when the mouse pointer is in the region where expr appears.

## Examples

```wolfram
StatusArea["Hover over me", "This is the status message"]
```

```wolfram
StatusArea[Button["Click"], "A clickable button"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/StatusArea.html) for more details.*
