# GridVideo

`GridVideo[{v1, v2, …}]` creates a video in which each frame is a grid of frames of all `vi` at the corresponding time.

- `GridVideo[{{v11, v12, …}, …}]` uses the array position of each video `vij` to create the video grid.

## Examples

```wolfram
GridVideo[{video1, video2}]
```

```wolfram
GridVideo[{{video1, video2}, {video3, video4}}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GridVideo.html) for more details.*
