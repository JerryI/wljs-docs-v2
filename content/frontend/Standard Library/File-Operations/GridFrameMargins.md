---
title: GridFrameMargins
---

`GridFrameMargins` is an option for grids that specifies the spacing between the content of the grid and the frame surrounding it.

## Examples

```wolfram
Grid[{{1, 2}, {3, 4}}, Frame -> All, GridFrameMargins -> 2]
```

```wolfram
Grid[{{a, b}, {c, d}}, Frame -> All, GridFrameMargins -> {{1, 1}, {2, 2}}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GridFrameMargins.html) for more details.*
