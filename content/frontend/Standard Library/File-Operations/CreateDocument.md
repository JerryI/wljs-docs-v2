---
title: CreateDocument
---

`CreateDocument[{expr1, expr2, ...}]` creates an empty notebook and populates it with the content. Use the option `Visible -> False` to create the content and the notebook offscreen.

## Examples

Create a document with content:

```wolfram
CreateDocument[{"Hello", "World"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CreateDocument.html) for more details.*
