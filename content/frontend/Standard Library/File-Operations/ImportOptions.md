# ImportOptions

`ImportOptions` is an option for Interpreter and related functions that specifies what options should be used in importing data.

## Examples

Specify import options for an interpreter:

```wolfram
Interpreter["CSV", ImportOptions -> {"HeaderLines" -> 1}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ImportOptions.html) for more details.*
