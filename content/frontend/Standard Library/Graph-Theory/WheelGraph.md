# WheelGraph

`WheelGraph[n]` gives the wheel graph with n vertices Wn.

## Examples

Create a wheel graph:

```wolfram
WheelGraph[6]
```

With vertex labels:

```wolfram
WheelGraph[5, VertexLabels -> "Name"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/WheelGraph.html) for more details.*
