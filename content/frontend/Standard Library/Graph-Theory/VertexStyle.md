---
title: VertexStyle
---

`VertexStyle` is an option and annotation for Graph and related functions that specifies what style to use for vertices.

## Examples

Style all vertices red:

```wolfram
Graph[{1 -> 2, 2 -> 3}, VertexStyle -> Red]
```

Style specific vertices:

```wolfram
Graph[{1 -> 2, 2 -> 3}, VertexStyle -> {1 -> Blue, 3 -> Green}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VertexStyle.html) for more details.*
