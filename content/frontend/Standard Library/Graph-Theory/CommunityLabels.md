---
title: CommunityLabels
---

`CommunityLabels` is an option to `CommunityGraphPlot` that controls what labels and placement to use for communities.

## Examples

Add labels to communities:

```wolfram
CommunityGraphPlot[graph, CommunityLabels -> Automatic]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CommunityLabels.html) for more details.*
