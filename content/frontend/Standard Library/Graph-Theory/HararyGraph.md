# HararyGraph

`HararyGraph[k,n]` generates the minimal k-connected graph on n vertices Hk,n.

## Examples

Generate a 3-connected Harary graph on 8 vertices:

```wolfram
HararyGraph[3, 8]
(* Graph[...] *)
```
