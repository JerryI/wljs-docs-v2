---
title: GraphicsSpacing
---

`GraphicsSpacing` is an option for GraphicsArray that specifies the spacing between elements in the array.

## Examples

Set spacing between graphics in an array:

```wolfram
GraphicsArray[{{g1, g2}, {g3, g4}}, GraphicsSpacing -> 0.1]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GraphicsSpacing.html) for more details.*
