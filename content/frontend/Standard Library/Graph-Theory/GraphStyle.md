---
title: GraphStyle
---

`GraphStyle` is an option to `Graph` and related objects that specifies styles to use for the different graph elements.

## Examples

```wolfram
Graph[{1 <-> 2, 2 <-> 3, 3 <-> 1}, GraphStyle -> "DiagramBlue"]
```

```wolfram
Graph[CompleteGraph[5], GraphStyle -> "Artistic"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GraphStyle.html) for more details.*
