# VertexCoordinates

`VertexCoordinates` is an option to `Graph` and related functions that specifies the coordinates to use to place the center of vertices.

## Examples

```wolfram
Graph[{1 -> 2, 2 -> 3, 3 -> 1}, 
  VertexCoordinates -> {{0, 0}, {1, 0}, {0.5, 1}}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VertexCoordinates.html) for more details.*
