# VertexShape

`VertexShape` is an option and property for `Graph` and related functions that specifies the graphics used for vertices.

## Examples

```wolfram
Graph[{1 -> 2, 2 -> 3}, VertexShape -> "Star"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VertexShape.html) for more details.*
