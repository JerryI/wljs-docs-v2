---
title: VertexWeightedGraphQ
---

`VertexWeightedGraphQ[g]` yields `True` if the graph g is a vertex-weighted graph, and `False` otherwise.

## Examples

```wolfram
VertexWeightedGraphQ[Graph[{1 -> 2}, VertexWeight -> {1 -> 5}]]
```

```wolfram
VertexWeightedGraphQ[Graph[{a -> b, b -> c}]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VertexWeightedGraphQ.html) for more details.*
