# VertexCapacity

`VertexCapacity` is an option and annotation for `Graph` and related functions that specifies a vertex capacity.

## Examples

```wolfram
Graph[{1 -> 2, 2 -> 3}, VertexCapacity -> {1 -> 10, 2 -> 5}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VertexCapacity.html) for more details.*
