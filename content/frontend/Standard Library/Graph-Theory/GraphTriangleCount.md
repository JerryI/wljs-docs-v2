# GraphTriangleCount

`GraphTriangleCount[g]` gives the number of triangles in the graph `g`.

## Examples

```wolfram
GraphTriangleCount[CompleteGraph[5]]
```

```wolfram
GraphTriangleCount[RandomGraph[{20, 50}]]
```
