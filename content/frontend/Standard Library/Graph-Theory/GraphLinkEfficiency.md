---
title: GraphLinkEfficiency
---

`GraphLinkEfficiency[g]` gives the link efficiency of the graph `g`.

- `GraphLinkEfficiency[{v -> w, …}]` uses rules `v -> w` to specify the graph `g`.

## Examples

```wolfram
GraphLinkEfficiency[CompleteGraph[10]]
```

```wolfram
GraphLinkEfficiency[GridGraph[{5, 5}]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/GraphLinkEfficiency.html) for more details.*
