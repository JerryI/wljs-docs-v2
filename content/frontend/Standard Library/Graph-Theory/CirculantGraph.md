# CirculantGraph

`CirculantGraph[n, j]` gives the circulant graph with n vertices and jump j.

`CirculantGraph[n, {j1, j2, ...}]` gives the circulant graph with n vertices and jumps j1, j2, ....

## Examples

Create a circulant graph:

```wolfram
CirculantGraph[8, {1, 3}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CirculantGraph.html) for more details.*
