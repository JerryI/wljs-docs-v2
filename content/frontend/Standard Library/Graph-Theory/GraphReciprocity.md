# GraphReciprocity

`GraphReciprocity[g]` gives the reciprocity of a graph g.

`GraphReciprocity[{v->w,…}]` uses rules v->w to specify the graph g.

## Examples

Compute the reciprocity of a directed graph:

```wolfram
GraphReciprocity[Graph[{1 -> 2, 2 -> 1, 2 -> 3}]]
```
