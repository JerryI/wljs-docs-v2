# ClassifierFunction

`ClassifierFunction[...]` represents a function generated by `Classify` that classifies data into classes.

## Examples

Create and use a classifier:

```wolfram
cf = Classify[{1 -> "small", 100 -> "large"}];
cf[50]
(* "large" *)
```

Get probabilities:

```wolfram
cf[25, "Probabilities"]
(* <|"small" -> 0.6, "large" -> 0.4|> *)
```
