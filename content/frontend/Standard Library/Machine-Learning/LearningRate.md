# LearningRate

`LearningRate` is an option for `NetTrain` that specifies the rate at which to adjust neural net weights in order to minimize the training loss.

## Examples

```wolfram
NetTrain[net, trainingData, LearningRate -> 0.001]
(* trains with a learning rate of 0.001 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/LearningRate.html) for more details.*
