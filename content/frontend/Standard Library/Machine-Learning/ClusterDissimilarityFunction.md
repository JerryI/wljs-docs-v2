# ClusterDissimilarityFunction

`ClusterDissimilarityFunction` is an option for `ClusteringTree` and `Dendrogram` that specifies the intercluster dissimilarity.

## Examples

Use single linkage for clustering:

```wolfram
Dendrogram[data, ClusterDissimilarityFunction -> "Single"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ClusterDissimilarityFunction.html) for more details.*
