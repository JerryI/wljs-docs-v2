---
title: NetTrainResultsObject
---

`NetTrainResultsObject[...]` represents an object generated by NetTrain that contains the trained net and other information about the training process.

## Examples

Train and get results object:

```wolfram
data = {1 -> 1, 2 -> 2, 3 -> 3};
result = NetTrain[LinearLayer[], data, All]
```

Extract the trained net:

```wolfram
result["TrainedNet"]
```

Get training history:

```wolfram
result["LossEvolutionPlot"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/NetTrainResultsObject.html) for more details.*
