# AnomalyDetector

`AnomalyDetector` is an option for functions such as `Classify` that specifies an anomaly detector for them to include.

## Examples

Create a classifier with anomaly detection:

```wolfram
Classify[trainingData, AnomalyDetector -> Automatic]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AnomalyDetector.html) for more details.*
