---
title: DoubleUpArrow
---

`DoubleUpArrow[x,y,…]` displays as x⇑y⇑….

## Examples

Display with double up arrows:

```wolfram
DoubleUpArrow[a, b, c]
(* a⇑b⇑c *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DoubleUpArrow.html) for more details.*
