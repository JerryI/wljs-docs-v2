# SymbolicOnesArray

`SymbolicOnesArray[]` represents an array of ones with unspecified dimensions.

- `SymbolicOnesArray[{n1, n2, …}]` represents an n1×n2×… array of ones.

## Examples

```wolfram
SymbolicOnesArray[{3, 3}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SymbolicOnesArray.html) for more details.*
