---
title: SampleRate
---

`SampleRate` is an option that specifies the number of samples per second for sound and signal processing functions.

## Examples

Create an audio object with a specific sample rate:

```wolfram
Audio[{1, 0, -1, 0}, SampleRate -> 44100]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SampleRate.html) for more details.*
