---
title: DoubleLongRightArrow
---

`DoubleLongRightArrow[x, y, ...]` displays as x⟹y⟹....

## Examples

Display double long right arrow:

```wolfram
DoubleLongRightArrow[a, b, c]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DoubleLongRightArrow.html) for more details.*
