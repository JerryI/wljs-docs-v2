# DownRightTeeVector

`DownRightTeeVector[x,y,…]` displays as x⥟y⥟….

## Examples

Create a down-right tee vector notation:

```wolfram
DownRightTeeVector[a, b]
(* a ⥟ b *)
```

Chain multiple elements:

```wolfram
DownRightTeeVector[a, b, c]
(* a ⥟ b ⥟ c *)
```
