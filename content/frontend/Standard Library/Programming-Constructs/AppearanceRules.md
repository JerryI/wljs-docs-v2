# AppearanceRules

`AppearanceRules` is an option for form and page generation functions that specifies the overall appearance of the generated object.

## Examples

```wolfram
FormFunction[{"x" -> "Number"}, #x^2 &, AppearanceRules -> <|"Title" -> "Square Calculator"|>]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AppearanceRules.html) for more details.*
