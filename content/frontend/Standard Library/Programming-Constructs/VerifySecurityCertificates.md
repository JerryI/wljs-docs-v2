---
title: VerifySecurityCertificates
---

`VerifySecurityCertificates` is an option for `URLRead` and related functions that specifies whether to verify security certificates when making an HTTPS connection.

## Examples

```wolfram
URLRead["https://example.com", VerifySecurityCertificates -> False]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VerifySecurityCertificates.html) for more details.*
