# SymbolicZerosArray

`SymbolicZerosArray[]` represents an array of zeros with unspecified dimensions.

- `SymbolicZerosArray[{n1, n2, ...}]` represents an n1×n2×… array of zeros.

## Examples

```wolfram
SymbolicZerosArray[{3, 3}]
```

```wolfram
SymbolicZerosArray[{2, 4}] // Normal
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SymbolicZerosArray.html) for more details.*
