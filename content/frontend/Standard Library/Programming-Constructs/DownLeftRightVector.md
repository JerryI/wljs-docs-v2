# DownLeftRightVector

`DownLeftRightVector[x, y, ...]` displays as x⥐y⥐....

## Examples

Display down left-right vector:

```wolfram
DownLeftRightVector[a, b]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DownLeftRightVector.html) for more details.*
