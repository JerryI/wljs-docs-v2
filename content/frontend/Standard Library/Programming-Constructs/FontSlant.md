---
title: FontSlant
---

`FontSlant` is an option for `Style`, `Cell`, and related constructs that specifies how slanted text characters should be.

## Examples

Italic text:

```wolfram
Style["Italic", FontSlant -> Italic]
```

Plain text:

```wolfram
Style["Plain", FontSlant -> Plain]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/FontSlant.html) for more details.*
