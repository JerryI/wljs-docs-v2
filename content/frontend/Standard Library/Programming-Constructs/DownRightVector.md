---
title: DownRightVector
---

`DownRightVector[x, y, ...]` displays as x⇁y⇁....

## Examples

Display down right vector:

```wolfram
DownRightVector[a, b]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DownRightVector.html) for more details.*
