---
title: PrintingCopies
---

`PrintingCopies` is an option for notebooks that specifies the number of copies of a notebook printed when a print command is given.

## Examples

```wolfram
SetOptions[EvaluationNotebook[], PrintingCopies -> 2]
```

```wolfram
Options[EvaluationNotebook[], PrintingCopies]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PrintingCopies.html) for more details.*
