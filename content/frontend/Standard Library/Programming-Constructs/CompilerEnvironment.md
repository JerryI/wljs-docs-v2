# CompilerEnvironment

`CompilerEnvironment` is an option for `FunctionCompile` and related functions that allows definitions to be included in the compilation.

## Examples

Use compiler environment:

```wolfram
FunctionCompile[fn, CompilerEnvironment -> env]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CompilerEnvironment.html) for more details.*
