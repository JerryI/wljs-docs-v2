# InterpolationOrder

`InterpolationOrder` is an option for Interpolation and plotting functions that specifies the order of interpolation to use.

## Examples

Linear interpolation:

```wolfram
Interpolation[data, InterpolationOrder -> 1]
```

Cubic interpolation:

```wolfram
Interpolation[data, InterpolationOrder -> 3]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/InterpolationOrder.html) for more details.*
