# FontWeight

`FontWeight` is an option for `Style`, `Cell`, and related constructs that specifies how heavy the characters in a font should be.

## Examples

Bold text:

```wolfram
Style["Bold", FontWeight -> Bold]
```

Plain weight:

```wolfram
Style["Plain", FontWeight -> Plain]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/FontWeight.html) for more details.*
