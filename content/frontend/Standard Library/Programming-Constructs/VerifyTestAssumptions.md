---
title: VerifyTestAssumptions
---

`VerifyTestAssumptions` is an option to `LocationTest` and similar functions that controls which assumptions to verify through diagnostic tests.

## Examples

```wolfram
LocationTest[data, VerifyTestAssumptions -> All]
(* performs test with all assumptions verified *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/VerifyTestAssumptions.html) for more details.*
