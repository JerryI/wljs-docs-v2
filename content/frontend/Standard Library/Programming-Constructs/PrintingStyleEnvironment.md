---
title: PrintingStyleEnvironment
---

`PrintingStyleEnvironment` is an option for notebooks that specifies the style environment to be used in printing the notebook on paper.

## Examples

Set the printing style environment:

```wolfram
SetOptions[EvaluationNotebook[], PrintingStyleEnvironment -> "Printout"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PrintingStyleEnvironment.html) for more details.*
