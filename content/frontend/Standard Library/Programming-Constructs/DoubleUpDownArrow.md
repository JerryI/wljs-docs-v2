# DoubleUpDownArrow

`DoubleUpDownArrow[x,y,…]` displays as x⇕y⇕….

## Examples

Display a double up-down arrow between elements:

```wolfram
DoubleUpDownArrow[a, b, c]
(* a⇕b⇕c *)
```
