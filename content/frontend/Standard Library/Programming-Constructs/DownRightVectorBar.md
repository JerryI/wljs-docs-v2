---
title: DownRightVectorBar
---

`DownRightVectorBar[x, y, ...]` displays as x⥗y⥗....

## Examples

Display down right vector bar:

```wolfram
DownRightVectorBar[a, b]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DownRightVectorBar.html) for more details.*
