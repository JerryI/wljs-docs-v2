# PacletDataRebuild

`PacletDataRebuild[]` rescans all the installed paclets to rebuild the internal cache of paclet data.

## Examples

```wolfram
PacletDataRebuild[]
```

```wolfram
PacletDataRebuild[];
PacletFind["*"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PacletDataRebuild.html) for more details.*
