---
title: AsynchronousTasks
---

`AsynchronousTasks[]` returns a list of running asynchronous tasks.

## Examples

List all async tasks:

```wolfram
AsynchronousTasks[]
(* {} or {AsynchronousTaskObject[...], ...} *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/AsynchronousTasks.html) for more details.*
