---
title: CreatePacletArchive
---

`CreatePacletArchive[source]` creates a paclet archive file from source.

`CreatePacletArchive[source, destdir]` creates a paclet archive file from source and places it in destdir.

## Examples

Create a paclet archive:

```wolfram
CreatePacletArchive["MyPaclet"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CreatePacletArchive.html) for more details.*
