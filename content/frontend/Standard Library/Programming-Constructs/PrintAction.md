---
title: PrintAction
---

`PrintAction` is an option for notebooks that specifies the action taken when a `Print[]` command is evaluated by the kernel.

## Examples

```wolfram
SetOptions[EvaluationNotebook[], PrintAction -> "PrintToNotebook"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PrintAction.html) for more details.*
