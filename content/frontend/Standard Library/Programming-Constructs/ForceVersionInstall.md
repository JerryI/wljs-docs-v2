---
title: ForceVersionInstall
---

`ForceVersionInstall` is an option to PacletInstall and PacletInstallSubmit that specifies whether an older version of a paclet is allowed to be installed if a newer version is already installed.

## Examples

Force installation of a specific version:

```wolfram
PacletInstall["PacletName", ForceVersionInstall -> True]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ForceVersionInstall.html) for more details.*
