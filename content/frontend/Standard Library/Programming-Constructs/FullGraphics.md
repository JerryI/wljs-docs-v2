# FullGraphics

`FullGraphics[g]` takes a graphics object, and generates a new one in which objects specified by graphics options are given as explicit lists of graphics primitives.

## Examples

Convert a plot to explicit graphics primitives:

```wolfram
FullGraphics[Plot[Sin[x], {x, 0, 2 Pi}]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/FullGraphics.html) for more details.*
