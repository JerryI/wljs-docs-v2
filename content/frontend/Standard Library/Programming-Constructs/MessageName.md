---
title: MessageName
---

`symbol::tag` is a name for a message.

## Examples

Define a message:

```wolfram
f::usage = "f[x] computes something.";
```

Access message text:

```wolfram
General::argx
(* "`1` called with `2` arguments; 1 argument is expected." *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MessageName.html) for more details.*
