---
title: DownArrowUpArrow
---

`DownArrowUpArrow[x, y, ...]` displays as x⇵y⇵....

## Examples

Display down-up arrow:

```wolfram
DownArrowUpArrow[a, b]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DownArrowUpArrow.html) for more details.*
