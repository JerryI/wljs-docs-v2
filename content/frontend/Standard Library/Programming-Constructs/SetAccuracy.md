---
title: SetAccuracy
---

`SetAccuracy[expr, a]` yields a version of expr in which all numbers have been set to have accuracy a.

## Examples

```wolfram
SetAccuracy[3.14159, 20]
```

```wolfram
Accuracy[SetAccuracy[1.5, 10]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SetAccuracy.html) for more details.*
