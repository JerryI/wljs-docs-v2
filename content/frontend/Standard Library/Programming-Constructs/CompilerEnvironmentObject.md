---
title: CompilerEnvironmentObject
---

`CompilerEnvironmentObject` represents a collection of definitions that can be included in compilations by `FunctionCompile` and related functions.

## Examples

Create a compiler environment:

```wolfram
env = CreateCompilerEnvironment[];
CompilerEnvironmentObject[env]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CompilerEnvironmentObject.html) for more details.*
