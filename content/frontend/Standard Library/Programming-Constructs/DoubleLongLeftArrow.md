---
title: DoubleLongLeftArrow
---

`DoubleLongLeftArrow[x,y,…]` displays as x⟸y⟸….

## Examples

Display the double long left arrow relation:

```wolfram
DoubleLongLeftArrow[a, b, c]
(* a ⟸ b ⟸ c *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DoubleLongLeftArrow.html) for more details.*
