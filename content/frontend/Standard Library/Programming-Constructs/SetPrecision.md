# SetPrecision

`SetPrecision[expr,p]` yields a version of expr in which all numbers have been set to have precision p.

## Examples

Set a number to 30-digit precision:

```wolfram
SetPrecision[1/3, 30]
(* 0.333333333333333333333333333333 *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SetPrecision.html) for more details.*
