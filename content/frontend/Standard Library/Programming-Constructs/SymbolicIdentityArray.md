---
title: SymbolicIdentityArray
---

`SymbolicIdentityArray[{n1, n2, ...}]` represents an n1×n2×…×n1×n2×… array with elements ai1,i2,…,j1,j2,… equal to 1 if all ik≡jk, and 0 otherwise.

## Examples

```wolfram
SymbolicIdentityArray[{2, 3}]
```

```wolfram
Normal[SymbolicIdentityArray[{2, 2}]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/SymbolicIdentityArray.html) for more details.*
