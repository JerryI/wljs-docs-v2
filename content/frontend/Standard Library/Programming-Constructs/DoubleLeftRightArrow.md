# DoubleLeftRightArrow

`DoubleLeftRightArrow[x, y, ...]` displays as x⇔y⇔....

## Examples

Display double left-right arrow:

```wolfram
DoubleLeftRightArrow[a, b, c]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DoubleLeftRightArrow.html) for more details.*
