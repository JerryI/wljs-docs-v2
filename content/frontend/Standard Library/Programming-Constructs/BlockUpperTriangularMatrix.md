---
title: BlockUpperTriangularMatrix
---

`BlockUpperTriangularMatrix[umat]` represents the block upper triangular matrix umat as a structured array.

## Examples

Create block upper triangular matrix:

```wolfram
BlockUpperTriangularMatrix[{{{1, 2}, {3, 4}}, {{5, 6}, {7, 8}}}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/BlockUpperTriangularMatrix.html) for more details.*
