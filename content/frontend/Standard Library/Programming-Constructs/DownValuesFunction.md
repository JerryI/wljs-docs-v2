---
title: DownValuesFunction
---

`DownValuesFunction[sym]` represents a function that uses definitions attached to sym when compiling.

## Examples

Create a compiled function from DownValues:

```wolfram
DownValuesFunction[f]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DownValuesFunction.html) for more details.*
