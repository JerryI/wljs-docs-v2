# FontSize

`FontSize` is an option for `Style` and `Cell` that specifies the default size in printer's points for text.

## Examples

Large text:

```wolfram
Style["Big", FontSize -> 24]
```

Small text:

```wolfram
Style["Small", FontSize -> 8]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/FontSize.html) for more details.*
