---
title: EndDialogPacket
---

`EndDialogPacket[integer]` is a WSTP packet indicating the end of the Dialog subsession referenced by integer.

## Examples

This is a low-level WSTP packet used internally:

```wolfram
EndDialogPacket[1]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EndDialogPacket.html) for more details.*
