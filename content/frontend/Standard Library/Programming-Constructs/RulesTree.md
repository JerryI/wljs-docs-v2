# RulesTree

`RulesTree[data -> {rule1, rule2, ...}]` gives a tree whose root contains data and that has children specified by the rulei.

## Examples

```wolfram
RulesTree["root" -> {"child1", "child2"}]
```

```wolfram
RulesTree[a -> {b -> {c, d}, e}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/RulesTree.html) for more details.*
