---
title: ResetScheduledTask
---

`ResetScheduledTask[obj,timespec]` resets the timing for a scheduled task to timespec.

`ResetScheduledTask[obj,timespec,offset]` resets the time offset for a scheduled task to offset.

## Examples

```wolfram
ResetScheduledTask[task, 5]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ResetScheduledTask.html) for more details.*
