# BlockLowerTriangularMatrix

`BlockLowerTriangularMatrix[lmat]` represents the block lower triangular matrix lmat as a structured array.

## Examples

Create block lower triangular matrix:

```wolfram
BlockLowerTriangularMatrix[{{{1, 2}, {3, 4}}, {{5, 6}, {7, 8}}}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/BlockLowerTriangularMatrix.html) for more details.*
