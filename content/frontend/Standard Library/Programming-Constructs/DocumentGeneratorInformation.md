# DocumentGeneratorInformation

`DocumentGeneratorInformation[cloudobj]` returns the properties of the `DocumentGenerator` cloudobj.

`DocumentGeneratorInformation[cloudobj, property]` returns the value of the property property.

## Examples

Get information about a document generator:

```wolfram
DocumentGeneratorInformation[docgen]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DocumentGeneratorInformation.html) for more details.*
