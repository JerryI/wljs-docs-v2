---
title: Launch
---

`Launch` is a setting for the `LinkMode` option of `LinkOpen` that causes a link to be created by launching another program.

## Examples

Launch a new kernel:

```wolfram
link = LinkOpen["math -mathlink", LinkMode -> Launch]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Launch.html) for more details.*
