---
title: EvaluatePacket
---

`EvaluatePacket[expr]` is a WSTP packet requesting evaluation of expr.

## Examples

This is a low-level WSTP packet:

```wolfram
EvaluatePacket[1 + 1]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/EvaluatePacket.html) for more details.*
