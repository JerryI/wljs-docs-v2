---
title: PreferencesPath
---

`PreferencesPath` is a global option that specifies which directories are searched for user-specific settings when the Wolfram System is started.

## Examples

Get current preferences path:
```wolfram
$PreferencesPath
```

Check preference directories:
```wolfram
Options[$FrontEnd, PreferencesPath]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PreferencesPath.html) for more details.*
