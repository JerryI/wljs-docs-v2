# Spacer

`Spacer[w]` displays as a spacer w printer's points wide.

`Spacer[{w, h}]` displays as a spacer w points wide and a total of h points high.

## Examples

Create horizontal space:

```wolfram
Row[{"Left", Spacer[50], "Right"}]
```

Create a spacer with specific dimensions:

```wolfram
Row[{"A", Spacer[{20, 10}], "B"}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Spacer.html) for more details.*
