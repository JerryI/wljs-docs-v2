---
title: CompilerOptions
---

`CompilerOptions` is an option for `FunctionCompile` and related functions that allows options for the compilation pipeline to be specified.

## Examples

Set compiler options:

```wolfram
FunctionCompile[fn, CompilerOptions -> {"OptimizationLevel" -> 2}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CompilerOptions.html) for more details.*
