---
title: ForeignPointerLookup
---

`ForeignPointerLookup[lib,fun]` returns the pointer to the function fun in the library lib.

## Examples

Look up a function pointer in a library:

```wolfram
ForeignPointerLookup["libm", "sin"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/ForeignPointerLookup.html) for more details.*
