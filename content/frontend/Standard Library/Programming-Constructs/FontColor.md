---
title: FontColor
---

`FontColor` is an option for `Style`, `Cell`, and related constructs that specifies the default color for rendering text.

## Examples

Red text:

```wolfram
Style["Hello", FontColor -> Red]
```

Custom color:

```wolfram
Style["World", FontColor -> RGBColor[0.2, 0.5, 0.8]]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/FontColor.html) for more details.*
