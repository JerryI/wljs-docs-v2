---
title: IntervalMarkersStyle
---

`IntervalMarkersStyle` is an option for plotting functions that specifies styles in which uncertainty intervals are drawn.

## Examples

```wolfram
ListPlot[Around[{1, 2, 3}, 0.5], IntervalMarkersStyle -> Red]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/IntervalMarkersStyle.html) for more details.*
