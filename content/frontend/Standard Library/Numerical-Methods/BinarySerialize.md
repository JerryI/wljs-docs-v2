# BinarySerialize

`BinarySerialize[expr]` gives a binary representation of any expression expr as a ByteArray object.

## Examples

Serialize an expression to binary:

```wolfram
BinarySerialize[{1, 2, 3}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/BinarySerialize.html) for more details.*
