# CharacterName

`CharacterName["c"]` gives the name of the character c.

`CharacterName[n]` gives the name of the character with character code n.

`CharacterName[c, "type"]` gives a name of the specified type.

## Examples

Get the name of a character:

```wolfram
CharacterName["A"]
(* "LatinCapitalLetterA" *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CharacterName.html) for more details.*
