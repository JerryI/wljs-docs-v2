# Antonyms

`Antonyms["word"]` returns the antonyms associated with the specified word.

## Examples

Find antonyms of a word:

```wolfram
Antonyms["hot"]
(* {"cold", "cool", ...} *)
```

Get antonyms for multiple words:

```wolfram
Antonyms /@ {"big", "fast", "happy"}
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Antonyms.html) for more details.*
