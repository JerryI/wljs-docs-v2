---
title: CharacterEncodingsPath
---

`CharacterEncodingsPath` is a global option that specifies which directories are searched for character encoding files.

## Examples

```wolfram
$CharacterEncodingsPath
```

```wolfram
SystemOptions["CharacterEncodingsPath"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CharacterEncodingsPath.html) for more details.*
