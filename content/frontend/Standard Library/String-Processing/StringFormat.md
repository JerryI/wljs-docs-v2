---
title: StringFormat
---

`StringFormat["string"]` attempts to determine what `ImportString` format could be used to import the string *"string"*.

## Examples

```wolfram
StringFormat["<html><body>Hello</body></html>"]
(* "HTML" *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/StringFormat.html) for more details.*
