---
title: CharacterEncoding
---

`CharacterEncoding` is an option for input and output functions which specifies what raw character encoding should be used.

## Examples

Read a file with specific encoding:

```wolfram
Import["file.txt", CharacterEncoding -> "UTF-8"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/CharacterEncoding.html) for more details.*
