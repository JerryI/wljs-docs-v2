---
title: DigitQ
---

`DigitQ[string]` yields `True` if all characters in the string are digits 0-9, and `False` otherwise.

## Examples

Test digit strings:

```wolfram
DigitQ["12345"]
(* True *)
```

```wolfram
DigitQ["12.34"]
(* False *)
```

```wolfram
DigitQ["abc"]
(* False *)
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DigitQ.html) for more details.*
