---
title: WordTranslation
---

`WordTranslation["word", lang]` gives translations for word into the language lang.

- `WordTranslation["word", lang1 -> lang2]` gives translations for word from lang1 to lang2.

## Examples

```wolfram
WordTranslation["hello", "French"]
```

```wolfram
WordTranslation["cat", "English" -> "Spanish"]
```

```wolfram
WordTranslation["book", {"German", "French", "Italian"}]
```

*See the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/WordTranslation.html) for more details.*
