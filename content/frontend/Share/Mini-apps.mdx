All initialization cells of the notebook are evaluated on startup, and the last input cell becomes the main window of the app. 

<Callout type="idea">Use [WLX cells](./../Cell-types/WLX) for maximum customization</Callout>

<Callout type="idea">You can create new windows with `CellPrint`</Callout>

## How to Prepare a Mini App
In general, you can think of a mini app as if it were an output of a single cell [projected](./../Overview) (see <small>Project</small> feature) to a window. The following rules apply:

<Card>

- The default context (`$Context`) of all symbols is randomly generated and will be unique for each running instance of your app
- __All initialization cells will be executed automatically__ on the startup of an app
- __The output of the last input cell__ will be the first window of your app
- An app will pick the first available computation kernel in your system

</Card>

Apart from that, the program for the widget is just a plain WLJS notebook. You can leave cells there for testing and debugging with no impact.


### Example 1
Let's write the simplest possible interactive widget: 

<WLJSWrapper>
<span className="absolute -inset-1 bg-gradient-to-r from-fd-primary/50 to-purple-500/50 rounded-lg blur-xl opacity-20 group-hover:opacity-50 transition duration-500" />
<wljs-editor display="codemirror" type="Input"  >{`
(* make it initialization cell *)
equation[x_,n_] := Sum[(Sin[2\[Pi](2j - 1) x])/(2j - 1), {j, 1, n}];
Widget = ManipulatePlot[equation[x,n]//Re, {x, -1,1}, {n, 1,10,1}];
`}</wljs-editor>
</WLJSWrapper>

<WLJSWrapper>
<span className="absolute -inset-1 bg-gradient-to-r from-fd-primary/50 to-purple-500/50 rounded-lg blur-xl opacity-20 group-hover:opacity-50 transition duration-500" />
<wljs-editor display="codemirror" type="Input"  >{`
Widget
`}</wljs-editor>
</WLJSWrapper>

Then export it as <small>Mini app</small> and double-click the created file. You can open it anytime on any machine with WLJS Notebook installed.
