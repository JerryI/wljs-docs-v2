This export option converts notebook cells into HTML [web components](https://developer.mozilla.org/en-US/docs/Web/API/Web_components) and associated assets compatible with MDX (Markdown React), making it easy to embed them in a webpage, such as your blog post or note.

## Features

- __Lazy Loading__ - Components and dependencies load progressively, showing meaningful raw content while loading
- __Interactive Content__ - 2D/3D graphics, plots, manipulatable widgets, and more
- __CDN-Ready__ - Single script import; all dependencies load automatically
- __No NPM Dependencies__ - Uses pure web components; no need to install any packages
