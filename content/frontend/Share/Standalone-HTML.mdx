<Callout>No internet connection is required</Callout>

## Use cases
- Share a notebook with a colleague (no WLJS app required)
- Share your work on the internet
- Lecture notes & offline presentations
- Make a report on data analysis, experiment
- Documentation 
- Cross-platform personal notes

</Card>

Local images can be embedded automatically, `NotebookStore[]` is preserved as well as [embedded files](./Embed-Notebook-Files.mdx). You can open the HTML file locally or [post it as a webpage](./Deploy-to-Github-Pages.mdx).

## Importing
The original cell metadata is preserved, __allowing an HTML notebook to be converted back to a normal WLJS notebook__ format upon opening or using deep-links - click on the <span className='inline-flex' ><CircleQuestionMark style={{height:"1rem"}}/></span> icon.
