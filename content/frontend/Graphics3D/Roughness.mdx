sets roughness for the current material

```wolfram
Roughness[i_Real]
```

where `i` is in the range of `0` and `1`. 

## Examples

__rough material__
```wolfram
Graphics3D[{White, Roughness[1], Sphere[], PointLight[Red, {-1,-3,3}]}]
```

__polished__
```wolfram
Graphics3D[{White, Roughness[0], Sphere[], PointLight[Red, {-1,-3,3}]}]
```
