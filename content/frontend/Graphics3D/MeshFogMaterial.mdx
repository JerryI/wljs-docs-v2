<Callout type="warn">
Works only with `"Renderer"->"PathTracing"` in [Graphics3D](../Graphics3D/Graphics3D)
</Callout>

defines a material for volumetric fog effect in [MeshMaterial](../Graphics3D/MeshMaterial)

```wolfram
MeshFogMaterial[density_:0.01]
```

<Callout type="tip">
Enable `"MultipleImportanceSampling"` to get the best results
</Callout>

## Example
Define a sphere-fog and place a [SpotLight](../Graphics3D/SpotLight) to light it up from below

```wolfram
Graphics3D[{
  {MeshMaterial[MeshFogMaterial[0.1]], Sphere[{0,0,0},5]}, {Red, Sphere[{0,0,0}, 1]}, {SpotLight[White, -{5,5,5}]}
}, "Renderer"->"PathTracing", Background->Black, "Lighting"->None]
```
