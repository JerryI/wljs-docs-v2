```wolfram
Graphics3D[{primitives__}, opts___]
```

represents 3D graphical image.

Use lines, polygons, cylinders, spheres, etc. to build up a 3D graphics scene

```wolfram
Graphics3D[{Blue, Cylinder[], Red, Sphere[{0, 0, 2}], Black, Thick, 
  Line[{{-2, 0, 2}, {2, 0, 2}, {0, 0, 4}, {-2, 0, 2}}], 
  Yellow, Polygon[{{-3, -3, -2}, {-3, 3, -2}, {3, 
     3, -2}, {3, -3, -2}}], Green, Opacity[.3], 
  Cuboid[{-2, -2, -2}, {2, 2, -1}]}]
```

Use plot functions to automatically create [Graphics3D](../Graphics3D/Graphics3D) from different types of data

```wolfram
Plot3D[Sin[x y], {x, 0, 3}, {y, 0, 3}, ColorFunction -> "Rainbow", Mesh -> None]
```

## Methods

### `EventHandler`

Attach an event handler to a `Graphics3D` expression to receive `"click"` or
`"mousemove"` events. The handler receives the three-dimensional position on
the intersected rendered surface.

```wolfram
Module[{pos = {0, 0, 0}},
  EventHandler[
    Plot3D[x y, {x, -1, 1}, {y, -1, 1},
      BoxRatios -> {1, 1, 1},
      Epilog -> {Red, Sphere[pos // Offload, 0.1]}
    ],
    {"click" -> Function[point, pos = point]}
  ]
]
```

This also works with plotting functions such as `Plot3D` because they return a
`Graphics3D` expression. See [Handling user input](../Guides/UI-Events-Capture#3d-graphics)
for primitive events such as dragging.

## Dynamic color and opacity

[`RGBColor`](./RGBColor), [`Hue`](./Hue), and [`Opacity`](./Opacity) accept
frontend values supplied through [`Offload`](../Interpreter/Offload). Updating
the source value updates the corresponding directive without rebuilding the
scene:

```wolfram
color = List @@ Pink;
Graphics3D[{RGBColor[color // Offload], Cuboid[]}]
```

```wolfram
color = RandomReal[{0, 1}, 3];
```

## Options

### `ImageSize`
Accepts `_Integer` or `{width_Integer, height_Interger}`

### `Lighting`
Default is `True`. It sets the default ambient lighting

### `Background`
Defines background color, by the default it is transparent

### `ViewPoint`

### `ViewProjection`
Sets the default camera for the scene. Default value is `"Orthographic"`
- `"Orthographic"`
- `"Perspective"`

### `Boxed`
Draws a wireframe box around the objects in the scene. Default is `False`.

### `BoxRatios`
Sets the 3D aspect ratio of the whole scene. By the default [Graphics3D](../Graphics3D/Graphics3D) does not rescale the scene. It accepts `{sx_Real, sy_Real, sz_Real}`, where `sx` are real positive numbers.

### `"SleepAfter"`
Stops rendering after the specified number of milliseconds. The default is `1000`, which limits GPU load. Changes to the camera or scene wake the renderer again.

### `"Renderer"`
Sets the rendering engine
- `"Rasterization"` __default__
- `"PathTracing"` photorealistic images (high computing load to GPU). 

### `"Lightmap"`
Sets an URL to an HDR light-map. __Currently only remote sources are supported__.

### `"AcesToneMapping"`
By the default is `False`

### `"BackgroundAlpha"`
Sets the transparency of the background. By the default is `0`

## Options for `"PathTracing"` 
If [`"Renderer"`](#`"Renderer"`) is set to a photorealistic one, there are more options available to choose from

### `"Bounces"`
Number of bounces for a ray (default is `5`)

### `"FadeDuration"`
If there not enough samples, the renderer falls back to the rasterization and slowly fades into a low-res texture generated by a path-tracer. The default is `300` (milliseconds)

### `"RenderDelay"`
Delay the path-tracer. The default is `100`

### `"MinSamples"`
The default is `5` 

### `"MultipleImportanceSampling"`
By the default is `False`. Set to `True` to work with [MeshFogMaterial](../Graphics3D/MeshFogMaterial), [PointLight](../Graphics3D/PointLight) and [SpotLight](../Graphics3D/SpotLight) primitives. 

### `"SamplesPerFrame"`
The default is `1`

### `"EnvironmentIntensity"`
The artificial ambient lighting intensity. The default is `1`

### Exporting a path-traced image

Path tracing improves progressively as the renderer accumulates samples. Increase `"SleepAfter"` when the default one-second rendering interval is too short, then delay the capture by the same amount with `"ExposureTime"`.

The two options use different units: `"SleepAfter"` is measured in milliseconds, while `"ExposureTime"` is measured in seconds. This example allows two minutes for rendering:

```wolfram
scene = Graphics3D[{Gray, Cuboid[], Red, Sphere[{0, 0, 2}]},
  "Renderer" -> "PathTracing",
  "SleepAfter" -> 2 60 1000
];

image = Rasterize[scene, "ExposureTime" -> 2 60]
```

For a PDF capture, use:

```wolfram
Export["image.pdf", scene, "ExposureTime" -> 2 60]
```

Use the shortest duration that produces the required quality because path tracing places a high load on the GPU. See [`Rasterize`](../Image/Rasterize) and [frontend-rendered PDF export](../File-Operations/Export#frontend-rendered-output) for capture details and Desktop application restrictions.

## Mathematica's native renderer
Using [MMAView](../GUI/MMAView), you can bypass the WLJS pipeline and directly render an expression as it would appear in Wolfram Mathematica **keeping interactivity intact for 3D plots**

```wolfram
With[{p = Plot3D[f[x] y, {x,0,10}, {y,0,10}]},
  MMAView[p]
]
```

<Callout type="note">
Note, that it is important to pass it using `With`, since `MMAView` has `HoldFirst` attribute. Otherwise the direct pass will give your a static plot
</Callout>
