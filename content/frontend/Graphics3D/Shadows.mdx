```wolfram
Shadows[True | False]
```

a scoped parameter like [RGBColor](../Graphics3D/RGBColor) or [Opacity](../Graphics3D/Opacity), that determines if a light source can cast shadows or a primitive can receive shadows as well.

See 

```wolfram
Graphics3D[{Shadows[shadow],  ExampleData[{"Geometry3D","StanfordBunny"}][[1]], SpotLight[White, {{0., -0.4473, 0.4291}, {0,0,0}}, Pi/4], Polygon[ 0.01{{-20,20,-1}, {20,20,-1}, {20,-20,-1}, {-20,-20,-1}}]}, "Lighting"->None] /. {{shadow -> True}, {shadow -> False}}
```
