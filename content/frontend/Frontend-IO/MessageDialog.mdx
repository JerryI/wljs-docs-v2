```wolfram
MessageDialog[expr_]
```

opens a modal window with `expr` displayed in the middle in a *non-blocking way*, where `expr` can be a string, graphics, or any other expression. The current notebook and window are selected automatically:

```wolfram
Button["Message", MessageDialog["Hello"]]
```

<Callout type="note">
It will use [StandardForm](../Formatting/StandardForm) for displaying expressions
</Callout>

## Options

When code runs without an active notebook context, provide the target explicitly.

### `"Notebook"`
Specifies the notebook in which to open the dialog.
