---
title: BulletGauge
---

```wolfram
BulletGauge[value, reference, {min, max}]
BulletGauge[value, reference, {min, m1, m2, ..., max}]
BulletGauge[{value1, value2, ...}, reference, range]
BulletGauge[{value1, value2, ...}, {reference1, reference2, ...}, range]
```

draws one or more bullet gauges. `value` controls the filled bar, `reference`
sets the marker, and intermediate values in the range split the background
into performance regions.

```wolfram
BulletGauge[0.62, 0.8, {0, 0.4, 0.7, 1}]
```

<Callout type="warn">
WLJS implements a frontend-rendered subset of `BulletGauge`. Only the
patterns and options documented on this page are supported; other Wolfram
Language gauge options and layout patterns are ignored.
</Callout>

## Dynamic updates

The first argument can be an [`Offload`](../Interpreter/Offload) expression:

```wolfram
level = 0.2;
BulletGauge[Offload[level], 0.75, {0, 1}]
```

Changing `level` updates the existing gauge. References, range boundaries,
and options are fixed when the gauge is created.

## Options

### `GaugeStyle`

Sets the bar and performance-region accent color. A single color is
supported; lists and other style specifications are not.

```wolfram
BulletGauge[0.62, 0.8, {0, 1}, GaugeStyle -> Green]
```

### `GaugeLabels`

Places a single label beside each gauge. Label lists and placement
specifications are not supported.

```wolfram
BulletGauge[0.62, 0.8, {0, 1}, GaugeLabels -> "Revenue"]
```
