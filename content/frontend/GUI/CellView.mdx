A low-level view component to spawn a cell wrapper (fully functional) 

```wolfram
CellView[content_String, opts___]
```

where `content` is a string, that represents an expression needed by a view component of a cell. View-components are provided by different cell types used by the default to render the notebook in a window.

## Supported output forms
- [StandardForm](../Formatting/StandardForm)
- [WLXForm](../Formatting/WLXForm)

## Options
### `"Display"`
A view-component to render the content. For default cell types it can be
- `"codemirror"` a default view component used in all input cells as well as in [EditorView](../GUI/EditorView)
- `"markdown"` a renderer of [Markdown](./../Cell%20types/Markdown) cells
- `"html"` a renderer of [HTML](./../Cell%20types/HTML)
- `"js"` a renderer of [Javascript](./../Cell%20types/Javascript) cells
- `"mermaid"` a renderer of [Mermaid Diagrams](./../Cell%20types/Misc)
- ...

### `"Class"`
Specify a class names to apply for a container element

### `"Style"`
Specify a style names to apply for a container element

### `ImageSize`
Resizes the container

## Applications
If you want to show mermaid diagrams in your slides

*craft a diagram*
```wolfram
MyDiagram = CellView["
graph LR
    A[Text Header 3200 byte]  --> B[Binary Header 400 byte]
    B --> C1[240 byte 1-st trace header] --> T1[samples of 1-st trace]
    B --> C2[240 byte 2-st trace header] --> T2[samples of 1-st trace]
    B --> CN[240 byte n-st trace header] --> T3[samples of 1-st trace] 
", ImageSize->650, "Display"->"mermaid"] 
```

*make a slide*
```wolfram
.slide

# My slide with a Diagram

<MyDiagram/>
```
