```wolfram
TextView[string_String, opts___]
```

represents a text field used for displaying static or dynamic textual data

## Options
### `"Event"`
__If specified__ it acts like an [InputText](../GUI/InputText). 

## `"Description"`
Adds a description label. Description text recognizes TeX-style `_{...}` and
`^{...}` sequences and converts supported characters to Unicode subscripts or
superscripts.

## `"Placeholder"`
adds placeholder of the given `string` is empty

### `ImageSize`
sets the width in pixels

### `"Label"`
Adds a label to the left of the text field. String labels support the same
TeX-style subscript and superscript notation; for example, `"Boo^{2}"` displays
as `Boo²`.

### `Appearance`
by the default is `Automatic`. By setting to any other value it will remove borders and other styling

## Application

### Show large text blocks
Import a text file and show it as text:

```wolfram
Import["file.txt", "Text"] // TextView
```

Line breaks will also work:

```wolfram
TextView["Hey!\nThere"]
```

Use `ImageSize` to limit maximum size and introduce scroll bars if needed:

```wolfram
TextView["A very long line here", ImageSize->100]
```

### Dynamic indication
There are various of applications. For example to display the current coordinates on a graph

```wolfram
pointer = {0.,0.} // ToString;

Plot[Sinc[x], {x,-10,10}, Prolog->{
  White, EventHandler[Rectangle[{-10,-10}, {10,10}], {"mousemove" -> Function[xy, pointer = xy // ToString]}]
}]

TextView[pointer // Offload]
```
