---
title: NearestFunction
---

`NearestFunction[data]` represents a function whose values give the elements closest to an element that is supplied.

## Examples

Create a nearest function and query it:

```wolfram
nf = Nearest[{1, 2, 5, 8, 10}]
nf[6]
(* {5} *)
```
