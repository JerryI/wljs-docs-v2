---
title: CauchyWindow
---

`CauchyWindow[x]` represents a Cauchy window function of x.

`CauchyWindow[x, α]` uses the parameter α.

## Examples

```wolfram
CauchyWindow[0.5]
(* 0.8 *)
```

```wolfram
Plot[CauchyWindow[x], {x, -1, 1}]
(* Graphics[...] *)
```
