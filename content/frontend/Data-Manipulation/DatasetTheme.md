---
title: DatasetTheme
---

`DatasetTheme` is an option for `Dataset` that specifies an overall theme for a dataset and its elements.

## Examples

Apply a theme to a dataset:

```wolfram
Dataset[{<|"a" -> 1|>, <|"a" -> 2|>}, DatasetTheme -> "AlternatingRowBackgrounds"]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DatasetTheme.html) for more details.*
