---
title: TableAlignments
---

`TableAlignments` is an option for `TableForm` and `MatrixForm` which specifies how entries in each dimension should be aligned.

## Examples

```wolfram
TableForm[{{1, 2}, {3, 4}}, TableAlignments -> Center]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TableAlignments.html) for more details.*
