---
title: TukeyWindow
---

`TukeyWindow[x]` represents a Tukey window function of x.

- `TukeyWindow[x, α]` uses the parameter α.

## Examples

```wolfram
TukeyWindow[0.5]
```

```wolfram
Plot[TukeyWindow[x, 0.5], {x, -1, 1}]
```
