---
title: MissingValuePattern
---

`MissingValuePattern` is an option for `SynthesizeMissingValues` and `ToTabular` to specify which data elements are considered missing.

## Examples

```wolfram
SynthesizeMissingValues[data, MissingValuePattern -> _Missing]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/MissingValuePattern.html) for more details.*
