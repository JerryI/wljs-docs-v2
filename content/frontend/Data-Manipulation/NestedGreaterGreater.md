---
title: NestedGreaterGreater
---

`NestedGreaterGreater[x, y, ...]` displays as x⪢y⪢....

## Examples

Display the nested greater-greater relation:

```wolfram
NestedGreaterGreater[a, b]
```

Multiple arguments:

```wolfram
NestedGreaterGreater[x, y, z]
```

In mathematical notation:

```wolfram
Row[{NestedGreaterGreater[1, 2], " means deeply greater"}]
```
