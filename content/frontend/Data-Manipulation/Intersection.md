---
title: Intersection
---

`Intersection[list1, list2, ...]` gives a sorted list of the elements common to all the lists.

## Examples

Find common elements:

```wolfram
Intersection[{a, b, c, d}, {b, c, d, e}]
(* {b, c, d} *)
```

Multiple lists:

```wolfram
Intersection[{1, 2, 3, 4}, {2, 3, 4, 5}, {3, 4, 5, 6}]
(* {3, 4} *)
```
