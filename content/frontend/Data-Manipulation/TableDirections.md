---
title: TableDirections
---

`TableDirections` is an option for `TableForm` and `MatrixForm` which specifies whether successive dimensions should be arranged as rows or columns.

## Examples

```wolfram
TableForm[{{a, b}, {c, d}}, TableDirections -> {Column, Row}]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/TableDirections.html) for more details.*
