---
title: DeletePermissionsKey
---

`DeletePermissionsKey[key]` deletes a permissions key, rendering it invalid.

`DeletePermissionsKey[{key1, key2, ...}]` deletes several permissions keys.

## Examples

Delete a permissions key:

```wolfram
DeletePermissionsKey[myKey]
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/DeletePermissionsKey.html) for more details.
