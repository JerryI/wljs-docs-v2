---
title: Insert
---

`Insert[list, elem, n]` inserts elem at position n in list.

## Examples

Insert at position 2:

```wolfram
Insert[{a, b, c}, x, 2]
(* {a, x, b, c} *)
```

Insert from the end:

```wolfram
Insert[{a, b, c}, x, -1]
(* {a, b, c, x} *)
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Insert.html) for more details.
