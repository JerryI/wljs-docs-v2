---
title: Prepend
---

`Prepend[expr, elem]` gives expr with elem prepended.

## Examples

Prepend to a list:

```wolfram
Prepend[{b, c, d}, a]
(* {a, b, c, d} *)
```

Operator form:

```wolfram
Prepend[x][{1, 2, 3}]
(* {x, 1, 2, 3} *)
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/Prepend.html) for more details.
