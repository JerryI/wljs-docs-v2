---
title: PartitionGranularity
---

`PartitionGranularity` is an option for audio analysis functions that specifies the partitioning of the audio.

## Examples

Use PartitionGranularity with Spectrogram:

```wolfram
Spectrogram[audio, PartitionGranularity -> 0.1]
```

*Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PartitionGranularity.html) for more details.*
