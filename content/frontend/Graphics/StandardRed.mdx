---
title: StandardRed
---

`StandardRed` represents a curated red color for graphics and style specifications. It is intended to remain visually useful in both light and dark themes.

## Example

```wolfram
Graphics[{StandardRed, Disk[]}]
```

It can also be used with plotting and styling options:

```wolfram
Plot[Sin[x], {x, 0, 2 Pi}, PlotStyle -> StandardRed]
```

See the official [Wolfram Language reference](https://reference.wolfram.com/language/ref/StandardRed.html) for more details.
