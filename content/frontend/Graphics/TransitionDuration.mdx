acts as an option and a context modifier for [Graphics](../Graphics/Graphics) that tells the transition duration for graphics primitives (coordinate changes, and etc) once one of dependencies has been updated

__global__
```wolfram
Graphics[..., "TransitionDuration"->timems_Integer]
```

__local__
```wolfram
Graphics[{Directive["TransitionDuration"->timems_Integer], ...}]
```

Value `timems` is __in milliseconds__.
