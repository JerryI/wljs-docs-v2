---
title: DarkGreen
---

`DarkGreen` represents a dark green color in graphics or style specifications.

## Example

```wolfram
Graphics[{DarkGreen, EdgeForm[Black], Disk[]}]
```

Use it anywhere a color directive is accepted:

```wolfram
Plot[Cos[x], {x, 0, 2 Pi}, PlotStyle -> DarkGreen]
```

See the official [Wolfram Language reference](https://reference.wolfram.com/language/ref/DarkGreen.html) for more details.
