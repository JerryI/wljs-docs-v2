draws a circle with a given radius `r`

```wolfram
Circle[{x_,y_}, r_]
```

for multiple copies

```wolfram
Circle[{{x1_, y1_}, ...}, r_]
```

Here is an example:

```wolfram
Graphics[Table[Circle[RandomReal[{-1,1}, 2], 1], {i,10}]]
```

## Parameters
See [Disk](../Graphics/Disk)

## How to update
Fully support for a radius and coordinates. Use [Offload](../Interpreter/Offload)

```wolfram
pt = {0,0};
EventHandler[Graphics[{
	Red,
	Circle[pt // Offload, 0.08]
}, PlotRange->{{-1,1}, {-1,1}}], {
		"mousemove" -> Function[xy, pt = xy]
}]
```
