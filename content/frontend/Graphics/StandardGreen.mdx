---
title: StandardGreen
---

`StandardGreen` represents a curated green color for graphics and style specifications. It is intended to remain visually useful in both light and dark themes.

## Example

```wolfram
Graphics[{StandardGreen, Disk[]}]
```

It can also be used with plotting and styling options:

```wolfram
Plot[Cos[x], {x, 0, 2 Pi}, PlotStyle -> StandardGreen]
```

See the official [Wolfram Language reference](https://reference.wolfram.com/language/ref/StandardGreen.html) for more details.
