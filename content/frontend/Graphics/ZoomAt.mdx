```wolfram
ZoomAt[k_, position_:{width/2,height/2}]
```

zooms `k` times at the given position `position` (in the coordinate system of the plot). `position` defines the center of view.

```wolfram
ZoomAt[]
```

returns current zoom and panning values.

<Callout type="info">
This has to be called inside the instance of [Graphics](../Graphics/Graphics) using [FrontSubmit](../Frontend-IO/FrontSubmit)
</Callout>

*All transition effects are applied here as well*

## Example
Let us make a simple plot and reference it using [FrontInstanceReference](../Frontend-IO/FrontInstanceReference)

```wolfram
ref = FrontInstanceReference[];
Plot[x, {x,0,1}, Epilog->{ref}]
```

now we can zoom it

```wolfram
FrontSubmit[ZoomAt[1.2, {0.5,0.5}], ref] 
```
