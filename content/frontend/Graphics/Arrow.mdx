Plots an arrow with a fixed head-size from point 1 to point 2

```wolfram
Graphics[{
  Arrow[{{0,0}, {1,1}}]
}]
```

<Callout type="warn">
Does work only with [Graphics](../Graphics/Graphics) (2D). Dynamics is not supported for now
</Callout>

## Dynamics
Fully supports. Use [Offload](../Interpreter/Offload) keyword for that

## Attach to other primitives

### `BezierCurve`
### `Line`

You can wrap it over the corresponding object to attach an arrow-marker to the end
```wolfram
Arrow[Line[...], 0.04]
```

## Options
Not available at the moment
