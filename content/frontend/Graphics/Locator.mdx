represents a draggable graphics primitive (2D or 3D), that generates `"drag"` event

```wolfram
Locator[{x,y}]
```

sets a locator to `{x,y}` initial position

## Using `Locator` with `Manipulate`

`Locator` can be used as a [`Manipulate`](../GUI/Manipulate#locator-controls)
control specification:

```wolfram
Manipulate[expr, {{position, {0.0, 0.0}}, Locator}]
```

Use a list of positions as the initial value when one control should provide
multiple locators. The manipulated result must be a two-dimensional `Graphics`
expression. See [`Manipulate`](../GUI/Manipulate#locator-controls) for complete
examples and performance guidance.

## Methods

### `EventHandler`
Use it to assign a handler function for generated events:

```wolfram
  location = {0.3,0.7};
	Plot[x, {x,0,1}, Epilog->{
	  EventHandler[Locator[location], {
	    "drag"->Function[xy, location = xy]
	  }]
	}]
	
	Refresh[NumberForm[location, {3,2}], 1/2]
```
