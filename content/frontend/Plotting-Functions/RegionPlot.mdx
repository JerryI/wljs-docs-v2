---
title: RegionPlot
---

`RegionPlot[pred, {x, xmin, xmax}, {y, ymin, ymax}]` makes a plot showing the region where pred is True.

## Examples

Plot a circular region:

```wolfram
RegionPlot[x^2 + y^2 < 1, {x, -1.5, 1.5}, {y, -1.5, 1.5}]
```

Multiple regions:

```wolfram
RegionPlot[{x^2 + y^2 < 1, x + y < 0}, {x, -2, 2}, {y, -2, 2}]
```
