---
title: InputForm
env:
  - Wolfram Kernel
---

```wolfram
InputForm[expr_]
```

reveals true form of a given expression avoiding any transformations. It is one-dimensional output, suitable to be typed as lines of Wolfram Language input.

<Callout>Standard output form of WLJS notebook output cells is decorated `InputForm`</Callout>

For example:

```wolfram
Red
Red // InputForm
```

```wolfram
RGBColor[1, 0, 0]
```


or as an input string:

```wolfram
ToString[Red, InputForm]
```

```wolfram
"RGBColor[1, 0, 0]"
```
