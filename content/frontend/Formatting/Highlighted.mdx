```wolfram
Highlighted[expr_, effect_]
```

highlights given expression

```wolfram
Highlighted[expr_, effect_]
```

applies `effect` on expression

<Callout type="warn">
`effect` is not supported for now
</Callout>

## Examples
Highlight with yellow color

```wolfram
Highlighted[4]
```
