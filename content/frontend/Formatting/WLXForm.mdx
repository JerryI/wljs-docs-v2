title: WLXForm

---

A standard form used for representing Wolfram expressions on [Slides](frontend/Advanced/Slides/Slides) and in [WLX](frontend/Cell%20types/WLX) cells.

By the default it applies `ToString` transformation. The use cases are the same as for [StandardForm](../Formatting/StandardForm). 

## Example
### Strings
Try the simples example:

```wolfram
Sym /: MakeBoxes[Sym, f: StandardForm] := MakeBoxes["Hooray", f]

Sym /: MakeBoxes[Sym, f: WLXForm] := MakeBoxes["Didly-Didly", f]
```

### Complex
Depending on where an expression is displayed, one can change its visual representation using [MakeBoxes](../Formatting/MakeBoxes) tagset, i.e.

```wolfram
SpecialOne /: MakeBoxes[SpecialOne, StandardForm] := With[{
	o = Graphics[{Red, Disk[]}] 
},
	MakeBoxes[o, StandardForm]
]

SpecialOne /: MakeBoxes[SpecialOne, WLXForm] := With[{
	o = Graphics[{Blue, Disk[]}]
},
	MakeBoxes[o, WLXForm]
]
```
