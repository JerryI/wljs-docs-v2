```wolfram
Interpretation[display_, expression_]
```
allows to alter the displayed expression

__An expression will be revealed after 1 evaluation__

<Callout type="tip">
For the best performance optimization __apply__ [CreateFrontEndObject](../Frontend%20Objects/CreateFrontEndObject) if you use interactive objects as `display` value.

For example

```wolfram
Interpretation[TextView["Hello"], 1]
```
has __more overhead__ than

```wolfram
Interpretation[TextView["Hello"] // CreateFrontEndObject, 1]
```

It will help interpreter to bypass extra layers of complexity.

Note that you don't need to do this for [Graphics](../Graphics/Graphics), [Graphics3D](../Graphics3D/Graphics3D), [Image](../Image/Image) and input elements, since it is done __automatically__
</Callout>

<Callout type="info">
By the default [Interpretation](../Formatting/Interpretation) applies [StandardForm](../Formatting/StandardForm) to `display` expression before printing it to an output cell
</Callout>
## Example
Have a look at the following example

```wolfram
Interpretation[Red, 1]
```

## Supported output forms
- [StandardForm](../Formatting/StandardForm)
