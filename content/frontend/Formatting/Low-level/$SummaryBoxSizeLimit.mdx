```wolfram
BoxForm`$SummaryBoxSizeLimit
```

limits the size of [ArrangeSummaryBox](../../Formatting/ArrangeSummaryBox) stored in the notebook in bytes. If an expression exceeds it, it will be stored on Kernel (in memory) and a reference will be provided instead.

The default system value is `40000`.

<Callout type="tip">
You can set it globally from the settings menu (Editor section)
</Callout>
