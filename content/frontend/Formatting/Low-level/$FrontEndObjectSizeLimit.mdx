```wolfram
Internal`Kernel`$FrontEndObjectSizeLimit
```

limits the size of [Frontend Objects](frontend/Advanced/Frontend%20interpretation/Frontend%20Objects) in megabytes (sound, 2d, 3d images).

The default system value is `8`.

<Callout type="tip">
You can set it globally from the settings menu (Editor section)
</Callout>
