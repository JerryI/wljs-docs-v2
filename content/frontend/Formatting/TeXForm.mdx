---
title: TeXForm
---
Exports an expression to TeX format

```wolfram
TeXForm[expr_]
```

## Examples
```wolfram
Series[Sin[x], {x,0,5}] // Normal // TeXForm
```

```wolfram title="output"
"\\frac{x^5}{120}-\\frac{x^3}{6}+x"
```

One can directly render it using built-in LaTeX support in [Markdown](./../Cell%20types/Markdown) cells or [LaTeX cells](./../Cell%20types/Misc). Or alternatively via `CellView`

```wolfram
CellView[StringJoin[
  TeXForm[Series[Sin[x], {x,0,7}] // Normal]
], "Display"->"latex"]
```

## Back-conversion
Using `ToExpression` one can parse TeX to Wolfram Language

```wolfram
ToExpression["\\frac{x^5}{120}-\\frac{x^3}{6}+x", TeXForm]
```
