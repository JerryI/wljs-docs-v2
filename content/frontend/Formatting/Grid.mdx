Spawns a grid of WL editors with an arbitrary objects inside
```wolfram
Grid[Table[x, {4}, {7}]]
```

## Options
### Dividers
it has to be explicitly set

```wolfram
Grid[Table[x, {3}, {7}], 
 Dividers -> {{False, False, True}, {False, True}}]
```

### Spacings
Sets the horizontal and vertical spacing between cells. A pair specifies the spacing in each direction.

```wolfram
Grid[Table[x, {3}, {5}], Spacings -> {5, 0}]
```

### Alignment
Aligns the contents of the cells. Use a pair for the horizontal and vertical alignment, or nested lists to specify alignment by row and column.

```wolfram
Grid[{{1, 2}, {3, 4}}, Alignment -> {{Right, Left}, {Bottom, Top}}]
```

### ImageSize
Specifies the size of the grid in pixels.

```wolfram
Grid[Table[x, {3}, {5}], ImageSize -> 300]
```

### BaselinePosition
Controls the vertical position of the grid relative to surrounding content.

```wolfram
Grid[{{Orange}, {Yellow}}, BaselinePosition -> Center]
```

## Modifiers
- [`Item`](../Formatting/Item)

`Item` being placed inside `Grid` modifies the outer container

```wolfram
a = {{1, 2}, {3, 4}};
Grid[KroneckerProduct[IdentityMatrix[5], a]] /. {0 -> 0, 
   x_?NumberQ -> Item[x, Background -> Orange]}
```
