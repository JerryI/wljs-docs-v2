---
title: ReshapeLayer
---

`ReshapeLayer[spec]` represents a net layer that reshapes the input array according to the specification spec.

## Examples

```wolfram
ReshapeLayer[{2, 3}]
```

```wolfram
ReshapeLayer[{4, 4}][RandomReal[1, {2, 8}]]
```
