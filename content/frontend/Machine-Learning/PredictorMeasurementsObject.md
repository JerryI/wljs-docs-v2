---
title: PredictorMeasurementsObject
---

`PredictorMeasurementsObject[...]` represents an object generated by `PredictorMeasurements` that can be applied to properties.

## Examples

Get measurements from a predictor:

```wolfram
predictor = Predict[{1 -> 2, 2 -> 4, 3 -> 6}];
measurements = PredictorMeasurements[predictor, {4 -> 8, 5 -> 10}]
(* PredictorMeasurementsObject[...] *)
measurements["RSquared"]
(* 1. *)
```

Please visit the official [Wolfram Language Reference](https://reference.wolfram.com/language/ref/PredictorMeasurementsObject.html) for more details.
