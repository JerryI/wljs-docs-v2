```wolfram
Paste[opts___]
```

pushes the content of a clipboard to a notebook as a new cell.

## Options
In a case of a lost window context provide (executed by a timer or an external event)

### `"Window"`
Specify explicitly window from which to read a clipboard content. By the default is [CurrentWindow](../Frontend%20IO/CurrentWindow)
