We successfully tested the MCP server with our notebook interface on the development branch. This means you can now use your favorite AI tool to communicate with WLJS and get the same benefits currently provided by our built-in Copilot.

The question is: does it still make sense to keep the built-in WLJS chat window? Our current Copilot implementation consumes much more tokens and requires an API key, which can be expensive. For that reason, we are considering removing the built-in Copilot feature in favor of MCP support.

What do you think?
